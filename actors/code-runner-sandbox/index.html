Code Runner — Run Python & JavaScript with Input Data

Run Python 3.12 or JavaScript (Node 22) code in a sandboxed run: pass JSON input or dataset rows, install pip/npm packages, get stdout, stderr, exit code and returned rows. For data pipelines and AI agents (MCP). $0.0003 per execution plus run time.

What it does

Run a Python or JavaScript snippet on Apify and get its output back as data: no server, no Lambda, no notebook. Paste code, pick Python 3.12 or JavaScript (Node.js 22), pass parameters as Input JSON and, optionally, an Apify dataset to process. Your code sees them as the variables input and rows, can return a list that becomes dataset rows (one per item), and can install pip or npm packages (pandas, requests, lodash, dayjs, cheerio…) at runtime. Every run returns stdout, stderr, exit code, duration and the returned value, so you always see what happened.

Built for pipelines and AI agents. Use it as the "code step" between scrapers: reshape, filter, score, dedupe or enrich a scraper's dataset, compute stats, call an API and reformat the response, then feed the rows to Make, n8n, Zapier, Clay or the next actor. AI agents and MCP clients (Claude, ChatGPT, Cursor and other assistants connected to Apify) can call it as a code-execution tool: set outputMode to result-row and every call returns exactly one row with status, stdout, stderr, exitCode, durationMs and result. Errors never crash the run: you get status error with the message, the line number and the traceback (or turn on failOnError to fail the run and stop a pipeline).

Limits and honest notes

  • Runtimes: Python 3.12 (Alpine Linux, musl) and Node.js 22. Most popular pip packages ship compatible wheels (pandas, numpy, requests, beautifulsoup4, pydantic…); packages that must compile C code may fail to install. Installation is limited to 180 seconds and its time counts as run time.
  • The default memory is 256 MB, which also means a small CPU share. For pandas/numpy work or large datasets raise the run memory (up to 4 GB); run-time charges scale with memory (GB-seconds).
  • Timeout: 1–900 seconds per execution (default 60). It is lowered automatically so the run stays within your maximum charge and the run timeout. On timeout the code and its child processes are killed and status is "timeout".
  • stdout and stderr are kept up to 100,000 characters each in the row (1 MB per stream is read; the rest is discarded). A returned value is limited to 200 MB, a single row to 8 MB, and the result field to 2 MB of JSON.
  • Input dataset: up to 100,000 items are loaded into memory as rows. The run can read only the dataset you pick (or pass by ID in the API input).
  • The code has normal outbound internet access from the run (for APIs and downloads). It runs as your own Apify run, so anything it does uses your account; do not paste untrusted code you would not run yourself.
  • Files written by the code are not kept after the run; return the data (or rows) you need. Python's input() is replaced by the input variable — read stdin with sys.stdin instead.
  • Each execution starts a fresh environment: nothing is cached between runs, so packages are reinstalled each time.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~code-runner-sandbox/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"language": "python", "code": "# `input` = the Input JSON, `rows` = rows from the dataset (if any).\n# Return a list of dicts -> one dataset row each. print() goes to stdout.\nnames = input.get(\"names\", [\"Ada\", \"Grace\", \"Linus\"])\nprint(f\"Processing {len(names)} names\")\nreturn [{\"name\": n, \"length\": len(n), \"upper\": n.upper()} for n in names]\n", "input": {"names": ["Ada", "Grace", "Linus"]}}'

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "language": "python",
    "code": "# `input` = the Input JSON, `rows` = rows from the dataset (if any).\n# Return a list of dicts -> one dataset row each. print() goes to stdout.\nnames = input.get(\"names\", [\"Ada\", \"Grace\", \"Linus\"])\nprint(f\"Processing {len(names)} names\")\nreturn [{\"name\": n, \"length\": len(n), \"upper\": n.upper()} for n in names]\n",
    "input": {
        "names": [
            "Ada",
            "Grace",
            "Linus"
        ]
    }
}

run = client.actor("actor-forge/code-runner-sandbox").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
