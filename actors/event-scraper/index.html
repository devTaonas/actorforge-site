Event Scraper — Luma Tech, AI & Startup Events by City

Scrape upcoming events from Luma (lu.ma) only: tech, AI, crypto and startup events by city, category or keyword. Dates, venue, ticket price, free/sold-out, spots left, guest count, organiser and description. No login. $1.50 per 1,000 events.

Run on Apify →See pricing

What it does

Scrape upcoming events from Luma (lu.ma / luma.com) only: it does not cover Eventbrite, Meetup, Facebook Events or other event sites. Luma is the platform behind most tech, AI, startup and crypto meetups, so this is the event scraper for finding those events as clean structured data. Filter by city (London, New York, San Francisco, Berlin, Singapore and ~90 more), category (tech and AI by default; also crypto, climate, food, arts, running, wellness…), keyword ('hackathon', 'founders') or any latitude/longitude. Each row has the event name, start/end time and timezone, venue and city, online/in-person, ticket price, free or paid, sold-out status, spots remaining, approval required, guest count, organiser and link, plus the full description and category tags (on by default). No login or cookies. Use it for event-lead prospecting, developer-relations and community outreach, sponsorship research, event newsletters and local-scene calendars, or as an events tool for AI agents. Built for privacy: individual hosts and guests are never returned (counts only), and hidden addresses stay hidden. $1.50 per 1,000 events.

Limits and honest notes

  • Luma only. Events on Eventbrite, Meetup, Facebook or other platforms are not included unless they are also listed on Luma.
  • Returns upcoming public events that appear in Luma's discover feeds. Private, invite-only and unlisted events are not included.
  • City names must be Luma discover cities (~90 worldwide); the run log shows examples of valid names. Anywhere else, use latitude/longitude.
  • Without a city or coordinates, Luma picks events near the server's location, so set a location unless you're running a keyword search.
  • Host and guest identities are never returned, only counts. Organiser names come only from organisation calendars, never personal ones. Exact addresses and coordinates are omitted when the organiser hides them.
  • Ticket price is the cheapest and most expensive public ticket in major currency units (e.g. 25 = $25.00). Flexible 'pay what you want' tickets report their minimum.
  • Duplicate events across cities and categories are removed and never charged twice. Events skipped by the free-only filter are not charged.
  • Respects your run budget: set a maximum total charge and the actor stops cleanly at the cap.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~event-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"cities": ["New York"], "categories": ["ai"], "maxEvents": 10}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "cities": [
    "New York"
  ],
  "categories": [
    "ai"
  ],
  "maxEvents": 10
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~event-scraper/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "cities": [
        "New York"
    ],
    "categories": [
        "ai"
    ],
    "maxEvents": 10
}

run = client.actor("actor-forge/event-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
