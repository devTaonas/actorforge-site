YouTube Scraper via the Official API — Video Details, Search and Stats

Paste video links or IDs and get views, likes, comment counts, duration and tags from the official YouTube Data API v3, under your own free key.

Run on Apify →See pricing

What it does

Most YouTube scrapers load youtube.com pages through proxies and break whenever the page layout or bot checks change. This actor takes a different route: it calls the official YouTube Data API v3 with an API key you create yourself in a free Google Cloud project. Nothing is scraped from youtube.com, and there are no proxies, cookies or logins involved.

The default videos mode accepts watch URLs, youtu.be links, Shorts, embed and live links or bare 11-character IDs, and returns one row per video: title, description, channel, published date, duration in seconds, view, like and comment counts, tags, category, default language, thumbnails, live status, made-for-kids flag and topic categories. IDs are batched 50 per API call, so one quota unit covers 50 videos. The same actor also switches to search, channel or comments mode through the mode field.

It suits analysts building YouTube dashboards, marketers doing competitor and trend research, and developers who want a stable feed into Sheets, Make, n8n or Zapier. Pricing is $0.40 per 1,000 video rows, and the free quota on one key covers about 500,000 video lookups a day. ActorForge is not affiliated with or endorsed by YouTube or Google.

How it works

  1. You paste your own YouTube Data API v3 key into the secret apiKey field; Apify stores it encrypted and the actor never logs it or writes it to the output.
  2. Video URLs and IDs are normalised, duplicates are removed, and the IDs are sent to videos.list in batches of 50.
  3. Each video comes back as a schema-validated row with stats, duration in seconds and an isShort heuristic (3 minutes or less and not live).
  4. Invalid, private, deleted or missing videos become free error rows instead of failing the run.
  5. If your key hits a 403 quotaExceeded error, the run stops cleanly, keeps the rows already delivered and does not charge for the failed call.

Limits and honest notes

  • You need your own free YouTube Data API v3 key (see the 4-step guide above). Without one the run stops at once with instructions, and nothing is charged.
  • Quota is per Google Cloud project: 10,000 units/day for free. Unit costs: videos.list, channels.list, playlistItems.list, commentThreads.list and comments.list cost 1 unit each, and search.list costs 100. A quotaExceeded error stops the run cleanly; rows already delivered are kept, and the failed call is free.
  • Only public data the API returns for an API key: no private or unlisted-by-ID-only details, no dislike counts (removed by YouTube), no revenue, no watch time, and no subscriber lists. Channels that hide their subscriber count give subscriberCount: null.
  • Like counts that the creator hides come back as null. Counts are YouTube's own; subscriber counts are rounded by YouTube to 3 significant figures.
  • Free rows (type error) cover invalid inputs, videos and channels that are not found, private or deleted, and videos with comments disabled.
  • You must refresh or delete stored API data within 30 days (YouTube Developer Policies III.E.4). We keep nothing after the run.
  • The run's spend limit is respected: each page of rows is charged before it is delivered, and the run stops cleanly at the cap.
  • Search returns at most about 500 results per query (a YouTube limit), and results can differ from what youtube.com shows in a browser. isShort is a heuristic (3 minutes or less and not live), because the API does not flag Shorts.

FAQ

Do I need my own YouTube API key to use this scraper?

Yes. There is no built-in or shared key. You create a free YouTube Data API v3 key in the Google Cloud Console in about a minute, with no billing account, and paste it into the apiKey field. Without a key the run stops immediately with instructions and nothing is charged.

How many YouTube videos can I look up per day on the free quota?

Each Google Cloud project gets 10,000 free quota units per day, reset at midnight Pacific Time. Video lookups cost 1 unit per 50 videos, which works out to about 500,000 video rows a day on one key.

Can it get YouTube dislike counts or watch time?

No. The public API does not return dislike counts (YouTube removed them), watch time, revenue or subscriber lists. Like counts that a creator hides come back as null.

How does it know if a video is a YouTube Short?

The API does not flag Shorts, so isShort is a heuristic: 3 minutes or less and not live. Treat it as a good guess rather than YouTube's own label.

What happens when my YouTube API quota runs out mid-run?

The actor stops cleanly on a 403 quotaExceeded error, keeps every row already delivered and does not charge for the failed call. It never retries against an exhausted quota, so you can simply run again after the daily reset.

Do I have to delete the YouTube data after some time?

YouTube's Developer Policies require stored API data to be refreshed or deleted at least every 30 days. ActorForge keeps no copy after the run, so set a retention period on your datasets or re-run to refresh them.
