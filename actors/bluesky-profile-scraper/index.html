Bluesky Profile Scraper: Profiles, Follower Counts & Posts

Scrape Bluesky profiles and their latest posts: name, bio, follower, following and post counts, verification, pinned post, plus each post with likes, reposts, replies, hashtags, links and media. Find profiles by keyword. No login. $1 per 1,000 profiles, $0.40 per 1,000 posts.

Run on Apify →See pricing

What it does

A Bluesky profile scraper that needs no account. Give it handles or profile URLs (or keywords to find profiles), and get one clean row per profile: handle, display name, bio, followers, following and post counts, lists, feeds and starter packs, verification, avatar and banner, account creation date and the pinned post. Each profile is followed by its latest posts: text, likes, reposts, replies, quotes and bookmarks, hashtags, links, mentions, images and video, quoted post, link card, language, and reply and repost flags. You can filter by post type and date. Use it for influencer and creator research, brand and competitor monitoring, audience-size tracking over time, journalism and academic research, and building lists of accounts in a niche. It reads Bluesky's official public AppView API, the same one the Bluesky web app uses for logged-out visitors. $1 per 1,000 profiles and $0.40 per 1,000 posts, with no compute bill on top; problems return a free status row instead of failing. Need keyword search across all posts instead? Use our Bluesky Posts Search.

Limits and honest notes

  • Responsible use: posts and bios are personal content. Use the data in line with Bluesky's terms and community guidelines and with data-protection law (GDPR/UK GDPR/CCPA), for example for research, monitoring and analytics, not for spam or harassment. This actor is not affiliated with, endorsed by or sponsored by Bluesky Social PBC.
  • It uses only the keyless public AppView API (public.api.bsky.app, whose robots.txt allows everything), one request at a time with at least 0.25 s between requests and an honest user agent (ActorForge-BlueskyProfiles). There is no login, no cookies and no proxies.
  • Accounts that ask not to be shown to logged-out visitors (the !no-unauthenticated label) are skipped, together with their posts. E-mail addresses and phone numbers are removed from bios. Follower and following lists are not collected; only the counts are.
  • Profile keyword search matches names, handles and bios (Bluesky's own directory search). It does not search post text; our Bluesky Posts Search does that.
  • If Bluesky answers with a block or rate limit, the run stops, keeps the rows already delivered and adds a free status row. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap. Unknown or deleted handles return a free status row.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~bluesky-profile-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"handles": ["bsky.app"], "maxPostsPerProfile": 10}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "handles": [
    "bsky.app"
  ],
  "maxPostsPerProfile": 10
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~bluesky-profile-scraper/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "handles": [
        "bsky.app"
    ],
    "maxPostsPerProfile": 10
}

run = client.actor("actor-forge/bluesky-profile-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
