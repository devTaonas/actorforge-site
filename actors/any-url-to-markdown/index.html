Any URL to Markdown: Web Pages, PDF, Word and Excel for LLMs

One link in, LLM-ready Markdown out, whether the link is a web page, a PDF, an Office file or a scanned image.

What it does

AI agents and RAG pipelines keep running into links they cannot read directly: a PDF report, a linked spreadsheet, a slide deck, an article page full of navigation. Each format usually means another library. Any URL to Markdown works out what the link actually is and routes it to the right converter, so your code only ever handles Markdown.

It handles web pages (main content kept with Mozilla Readability, robots.txt respected), PDFs (text layer read with heading and paragraph detection), Word, Excel and PowerPoint, OpenDocument, EPUB, CSV and JSON. Images and PDF pages without a text layer go through Tesseract OCR in 7 languages. Headings, lists, tables and links are kept, and every result includes a title, metadata, the route used and a tokenEstimate.

Pricing follows what was converted: $1 per 1,000 web pages, $2 per 1,000 documents (a PDF counts once per started 50 text pages) and $3 per 1,000 OCR pages. Failed downloads, unsupported files, robots-blocked pages and empty results are not charged. It fits MCP clients, LangChain or LlamaIndex pipelines, Clay enrichments and n8n, Make or Zapier flows.

How it works

  1. You pass a single url, or a list in urls (up to 1,000 per run, duplicates removed).
  2. The actor checks robots.txt (on by default), downloads the link and detects its real format rather than trusting the file extension.
  3. It routes the file to a converter: Readability for HTML, a layout-aware PDF text reader, Office and EPUB converters, or Tesseract OCR for images and scanned pages when ocr is on.
  4. The result is one row per URL with markdown, title, detectedFormat, route, tokenEstimate and metadata such as author, dates and page count.
  5. Limits such as maxPdfPages, maxOcrPages and maxRowsPerSheet keep large files in check, and truncated results are flagged.

Limits and honest notes

  • Web pages are fetched as static HTML, with no browser. Pages that build their content with JavaScript (an empty app shell) are reported, not charged; use a browser-based crawler for those. This actor converts the URLs you give it and does not crawl sites (see Website to Markdown for that).
  • PDF pages with a text layer are read exactly; pages without one are read by OCR when it is on (up to 20 per PDF by default, set by maxOcrPages). OCR covers 7 languages (English, German, French, Spanish, Italian, Portuguese, Dutch). Handwriting and low-resolution photos come out poorly. For 29 languages, word boxes and per-page output, use OCR to Text.
  • Legacy binary Office files (.doc, .xls, .ppt), RTF, OpenDocument presentations (.odp), HEIC/AVIF images and SVG are not supported. They are reported with a clear reason and never charged.
  • Spreadsheets are cut at 1,000 rows per sheet by default (maxRowsPerSheet), and very large results are cut at about 3.5 million characters. Cut rows are marked truncated: true.
  • Files up to 50 MB. Password-protected PDFs and pages behind a login can't be read.
  • Polite by design: it sends an honest crawler user agent (ActorForge-AnyUrlToMarkdown) and does not pose as a browser. When a site answers 429 (rate limited) or 403 (refused), that URL is retried at most once (429 only, after Retry-After up to 30 s) and the remaining URLs on the same host are skipped as free error rows.
  • tokenEstimate is characters divided by 4. That is a good guide for English with GPT and Claude tokenizers, not an exact count.
  • Respects your run budget: set a maximum total charge and processing stops cleanly at the cap. No result is delivered without being paid for, and none is charged twice.

FAQ

How do I convert a URL to Markdown for an LLM?

Pass the link as url and read the markdown field of the result. The actor detects whether it is a web page, PDF, Office file, EPUB, CSV, JSON or image and picks the converter for you.

How accurate is the token estimate?

tokenEstimate is the character count divided by 4. It is a good guide for English text with GPT and Claude tokenizers, but not an exact count.

Which files can it not convert?

Legacy binary Office files (.doc, .xls, .ppt), RTF, OpenDocument presentations, HEIC/AVIF images and SVG are not supported. Password-protected PDFs and pages behind a login cannot be read either. These are reported with a reason and never charged.

How much does converting a long PDF cost?

A PDF is charged $0.002 per started 50 text pages, so a 15-page PDF costs $0.002 and a 120-page PDF costs $0.006. Scanned pages read by OCR cost $0.003 each, up to maxOcrPages (20 by default) per PDF.

Can I turn off OCR to keep costs predictable?

Yes. Set ocr to false and images or scanned pages are reported as errors instead of being read, at no charge. For 29 OCR languages and word boxes, use OCR to Text.

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "url": "https://arxiv.org/pdf/1706.03762",
    "urls": [
        "https://en.wikipedia.org/wiki/Retrieval-augmented_generation",
        "https://calibre-ebook.com/downloads/demos/demo.docx"
    ],
    "onlyMainContent": True,
    "ocr": True,
    "ocrLanguages": [
        "eng"
    ],
    "maxPdfPages": 500,
    "respectRobotsTxt": True
}

run = client.actor("actor-forge/any-url-to-markdown").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
