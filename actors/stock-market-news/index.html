Stock Market News Scraper — Ticker Headlines & SEC Filings

Recent news headlines and SEC filings for a list of stock tickers (AAPL, TSLA, 7203.T, VOD.L…): source, time, URL, sentiment, related tickers, 8-K items. Global markets, deduped, no API key. For traders, analysts and alert bots. $1.20 per 1,000 rows.

What it does

A news feed for your stock watchlist: type tickers, get what was published about each company. Enter symbols the way you already write them (AAPL, TSLA, BRK.B, 7203.T, VOD.L, 0700.HK, SAP.DE, SHOP.TO, RELIANCE.NS, about 40 exchange suffixes) and get, per ticker, the latest news headlines (last 24 hours by default, up to 7 days) from thousands of outlets worldwide plus the company's SEC filings (8-K current reports with plain-English item descriptions such as "Results of operations and financial condition" or "Departure or appointment of directors or officers", 10-Q, 10-K, proxies, 5%+ stakes). Each row has the ticker, company, headline, source, publish time, URL, summary (filings), a lexicon sentiment label (positive / negative / neutral), related tickers from your list and cashtags named in the headline. Tickers are resolved to company names automatically (SEC list for US symbols, OpenFIGI for other markets), headlines are kept only when they name the company (no passing mentions, no classified-ad spam), and syndicated copies of the same story are deduplicated with the other outlets listed. Use it for morning briefings, watchlist alerts, trading and research dashboards, event studies, investor-relations monitoring and LLM pipelines. $1.20 per 1,000 rows, no API key, no compute bill on top; unknown tickers and empty days cost nothing.

Limits and honest notes

  • News comes from The GDELT Project's open news index (credit: The GDELT Project) and filings from SEC EDGAR (US public domain). This actor is not affiliated with or endorsed by GDELT, the SEC, OpenFIGI/Bloomberg, or any exchange. Headlines link to the original publishers; respect their copyright when you republish.
  • News rows carry the headline, outlet, the 15-minute batch in which the news index first saw the article, URL, language, share image and the index's article tone, but no article text or summary (the summary field is filled for SEC filings). The sentiment label is a simple finance-word lexicon applied to the headline, not a model: treat it as a hint; tone is the index's whole-article score.
  • News is read from the open 15-minute news files of the last N hours (default 24, up to 7 days), so time and cost grow with the window: roughly 1 to 2 minutes per day of news, much less when every ticker reaches its headline limit early. The non-English feed is scanned over at most 24 hours, and names must appear in Latin script to match. Headlines are matched on the page title, so an article that only mentions the company in its body is skipped unless you switch off the headline filter.
  • Company names come from the SEC list (US) or OpenFIGI (other markets). Short or common-word names can match unrelated headlines (e.g. a fruit called apple is excluded only because it is lower case); add a better name or aliases with TICKER=Name|Alias. SEC filings are only available for companies that file with the SEC (US listings and many ADRs: for Toyota use TM to get its 6-K/20-F filings).
  • Not investment advice. No proxies, no logins, no paywalled content. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~stock-market-news/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tickers": ["AAPL"], "newsLookbackHours": 6, "maxNewsPerTicker": 10}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "tickers": [
    "AAPL"
  ],
  "newsLookbackHours": 6,
  "maxNewsPerTicker": 10
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~stock-market-news/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "tickers": [
        "AAPL"
    ],
    "newsLookbackHours": 6,
    "maxNewsPerTicker": 10
}

run = client.actor("actor-forge/stock-market-news").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
