Brand Assets Extractor - Logo, Favicon, Colors & Fonts

Get any company's brand kit from its domain: ranked logo candidates (SVG/PNG), favicon and Apple touch icon, share image, theme colour, brand colour palette from its CSS, fonts (Google Fonts, @font-face) and company social profiles. Optional download to storage. $0.60 per 1,000 domains.

What it does

Get a company's logo, icons, colours and fonts from just its domain. Give it a list of domains (or website URLs, or business email addresses) and get one brand kit per company: ranked logo candidates (JSON-LD logo, the header logo image, SVG icons, Apple touch icon, web-app manifest icons, mask icon, favicon) with the best one picked for you, the favicon, Apple touch icon, social share image (og:image), the theme colour, a brand colour palette counted from the site's own CSS (custom properties like --brand-primary weighted up, near-duplicates merged, whites/greys/blacks listed separately), the fonts the site loads (Google Fonts, @font-face, font-family usage) and the company's own social profiles (LinkedIn company page, X, Facebook, Instagram, YouTube, GitHub, TikTok). Turn on download to save the logo and icons to storage. Use it to show company logos in a CRM, SaaS app or directory, enrich leads in Clay, n8n, Make or Zapier, theme white-label dashboards and pitch decks to a prospect's colours, build competitor style references, and fill AI agents' company cards. Static HTML only (no browser), robots.txt respected. $0.60 per 1,000 domains; unreachable or blocked domains are free.

Limits and honest notes

  • Logos and brand assets are trademarks of their owners. The output identifies and links to them for lawful uses such as showing a company's logo next to its name; check the owner's brand guidelines before other uses.
  • No browser: the home page is read as static HTML plus up to 4 stylesheets. Sites that render everything with JavaScript may yield fewer candidates (a free "nothing-extracted" row when there is nothing at all). Pages behind bot walls are not supported and the actor does not try to get around them (no proxies, no fingerprints).
  • The colour palette is a heuristic from CSS frequency, not a design-system export: check it against the brand's guidelines for exact values. Fonts are the families the site declares; commercial fonts are reported by name only and never downloaded.
  • Only company social profiles are returned. Personal profiles (for example linkedin.com/in/…) and personal contact details are never collected.
  • robots.txt is respected by default (RFC 9309), requests identify themselves honestly as ActorForge-BrandAssets, and internal or private network addresses are refused at every redirect hop.
  • downloadAssets stores image files up to 2 MB each in the run's key-value store (kept per your Apify storage retention).

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~brand-assets-extractor/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"domains": ["apify.com", "stripe.com"]}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "domains": [
    "apify.com",
    "stripe.com"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~brand-assets-extractor/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "domains": [
        "apify.com",
        "stripe.com"
    ]
}

run = client.actor("actor-forge/brand-assets-extractor").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
