Bulk Domain Availability Checker — RDAP, Any TLD & Expiry

Check if domains are available to register, in bulk: paste domains or combine names with any TLD list. Registry RDAP plus DNS gives available/registered, and for taken names the registrar, creation and expiry dates and status. $0.50 per 1,000 checks.

Run on Apify →See pricing

What it does

Find out which domain names are free to register, in bulk, across any TLD. Paste full domains, or give brand names plus a list of TLDs and every combination is checked for you (10 names × 8 TLDs = 80 checks in one run). Each domain is checked against the registry's own RDAP service (the official successor to WHOIS, located through IANA's bootstrap list) with a DNS nameserver check as a second signal, and you get a clear availability value: available, registered, likely-available, unknown-tld-no-rdap or error, with a confidence level and the method used. For taken names you also get the registrar, creation and expiry dates, days to expiry, EPP status codes and a pendingDelete flag for names in redemption that may drop soon. Use it to brainstorm startup and product names, check a naming shortlist across .com/.io/.ai/.app/.dev at once, monitor expiring domains you want, or clean a domain list for outreach. Simple pricing: $0.50 per 1,000 checks, with no compute bill on top. Invalid inputs, duplicates, unknown and failed checks are never charged.

Limits and honest notes

  • available means the registry's RDAP service has no record of the name. It is a strong signal, not a guarantee: premium, reserved or blocked names can still be unregistrable or cost more, and a name can be taken between the check and your purchase.
  • Registries that publish no RDAP service (for example .it, .es, .jp, .eu, .us at the time of writing) and registries whose robots.txt refuses automated access (for example CentralNic TLDs such as .xyz, and .uk, .nl, .co, .no) are not queried. For those, DNS decides: delegated names are registered, names that do not exist in DNS are likely-available (medium confidence), anything else is unknown-tld-no-rdap and is not charged. Registration dates are only available where RDAP was used.
  • Registry RDAP services are queried politely: at most 2 requests at a time per registry with a gap between them, Retry-After honoured on HTTP 429, and a registry that keeps rate-limiting is not asked again in that run (its domains fall back to DNS). Large runs on one TLD therefore take a few minutes. Up to 2,000 checks per run.
  • Privacy: registrant, admin, tech and abuse contact details are never read or returned, and no port-43 WHOIS servers are queried. Only the registrar's name and IANA ID are included.
  • Some registries publish less: .de has no creation or expiry dates and no registrar.
  • Use the results for your own domain research. Registries' terms forbid using registration data for unsolicited marketing.
  • Respects your run budget: set a maximum total charge and the run checks only what it covers, stopping cleanly at the cap.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~domain-availability-checker/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \

const input = {
  "domains": [

    "my-unregistered-idea-123.com"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~domain-availability-checker/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "domains": [
        "apify.com",
        "my-unregistered-idea-123.com"
    ]
}

run = client.actor("actor-forge/domain-availability-checker").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
