Article Extractor - News & Blog Text, Author, Date, Image

Extract news and blog articles from URLs or a site's home/section page: headline, authors, published and modified dates, lead image, language, site, section, tags, word count, paywall flag, clean text and Markdown. No browser, robots.txt respected. $0.40 per 1,000 articles.

Run on Apify →See pricing

What it does

Turn news and blog article URLs into clean, structured data. Give it article links, or just a site's home or section page (it finds the articles linked from it), and get one row per article with the headline, authors, published and modified dates (ISO 8601), lead image, description, language, site name, section, tags, word count, reading time, a paywall flag, and the full body as clean text and Markdown with ads, navigation, cookie banners and related-story boxes removed. Metadata comes from the page's own JSON-LD (NewsArticle, BlogPosting, Article), Open Graph and article meta tags, with the reader-view body from Mozilla Readability (the engine behind Firefox Reader View). Use it for news monitoring and media intelligence, content research, SEO and competitor content audits, building LLM / RAG datasets from articles, archiving, and feeding AI agents clean article text. It works with WordPress, Ghost, Substack, Medium-style blogs and most news sites that serve HTML. It runs with limited permissions and pay-per-event pricing, so it suits automations and AI agents: $0.40 per 1,000 articles; section pages, failed pages and non-articles are free.

Limits and honest notes

  • No browser: pages are fetched as static HTML. Sites that build articles with JavaScript only get a free "needs-javascript" status row. Pages behind logins, CAPTCHAs or bot walls are not supported, and the actor does not try to get around them (no proxies, no browser fingerprints).
  • Paywalled articles: only the text the site serves publicly is returned; isPaywalled is true when the page declares it (JSON-LD isAccessibleForFree: false) or shows paywall markup with a short body.
  • Discovery follows one level of same-site links that look like articles (slugs with words, dated paths or numeric IDs); tag, category, author and utility pages are skipped. For full archives, give article URLs directly (for example from Sitemap Extractor or RSS Feed Reader).
  • Authors are the public bylines the publisher puts on the article; no other personal data is collected.
  • robots.txt is respected by default (RFC 9309), and requests identify themselves honestly as ActorForge-ArticleExtractor. Internal and private network addresses are refused at every redirect hop.
  • Dates are converted to ISO 8601 UTC; date-only values stay YYYY-MM-DD. Duplicate articles (same canonical URL) are delivered once.
  • Article text is copyrighted by its publishers: use the output for analysis, research, indexing and other lawful purposes, and respect each site's terms.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~article-extractor/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"startUrls": [{"url": "https://blog.apify.com/"}], "maxArticles": 2}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "startUrls": [
    {
      "url": "https://blog.apify.com/"
    }
  ],
  "maxArticles": 2
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~article-extractor/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "startUrls": [
        {
            "url": "https://blog.apify.com/"
        }
    ],
    "maxArticles": 2
}

run = client.actor("actor-forge/article-extractor").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
