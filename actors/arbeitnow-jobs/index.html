What it does

An Arbeitnow scraper for jobs in Germany, Europe and the UK. Arbeitnow is a job board for English-speaking and visa-sponsored jobs in Germany and Europe, fed directly by employers' applicant tracking systems (Greenhouse, SmartRecruiters, Join, Recruitee, Teamtailor and others). This actor reads Arbeitnow's free public job API and gives you one clean row per job: title (gender suffixes such as (m/w/d) removed), company, location with parsed city and country, remote flag, visa-sponsorship flag, job type, seniority, Arbeitnow tags, salary range with currency and period when the description states one, description language, posted date, the Arbeitnow job link and the full description as plain text. Filter by keyword, city or country (German or English names), remote or on-site, visa sponsorship, tags, job type (Vollzeit, Teilzeit, Werkstudent… are recognised), seniority, description language (find English-speaking jobs in Germany), salary and posting age. Rows are deduped across pages and across the Germany/Europe and UK feeds. Use it for job boards and newsletters for expats, recruiting and sourcing in the DACH region, hiring-signal lead lists, salary benchmarking and labour-market research. $0.40 per 1,000 jobs, with no compute bill on top; problems return a free status row instead of failing.

Limits and honest notes

  • Data source and attribution: job data comes from Arbeitnow's free public job board API. Arbeitnow asks API users to credit and link back to Arbeitnow: every row carries a plain-text attribution and the job's Arbeitnow page in url, so please keep both when you republish jobs. You are responsible for using the data in line with Arbeitnow's terms and with data-protection law (GDPR). This actor is not affiliated with, endorsed by or sponsored by Arbeitnow.
  • It uses only the public, keyless API endpoints (/api/job-board-api on the German and UK sites). No login, no cookies, no proxies and no CAPTCHA solving; it sends an honest user agent (ActorForge-ArbeitnowJobs), waits at least 1 s between requests and checks robots.txt before each one.
  • The API has no keyword, location or salary search: the actor scans the newest pages (about 300 jobs each for Germany/Europe, 100 for the UK) and filters them itself. Raise "Max pages per market" to look further back; the API's own filter is visa sponsorship only.
  • Arbeitnow lists no structured salary: salaries are read from the description text when it states an amount with a currency (no FX conversion). City, country, seniority and description language are derived by the actor and can be empty when the listing is unclear. visaSponsorship is true for jobs read from the visa-sponsorship feed and empty otherwise; mentionsVisaSupport flags descriptions that talk about visa support.
  • E-mail addresses and phone numbers are removed from descriptions; no recruiter contact details are collected. If the site answers with a block, the run stops at once, keeps the jobs already delivered and adds a free status row. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap. A run with no results returns one free status row.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~arbeitnow-jobs/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"markets": ["germany-europe"], "keywords": ["engineer"], "maxItems": 20}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "markets": [
    "germany-europe"
  ],
  "keywords": [
    "engineer"
  ],
  "maxItems": 20

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~arbeitnow-jobs/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "markets": [
        "germany-europe"
    ],
    "keywords": [
        "engineer"
    ],
    "maxItems": 20
}

run = client.actor("actor-forge/arbeitnow-jobs").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
