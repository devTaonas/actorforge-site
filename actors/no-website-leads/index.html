No Website Leads — Local Businesses Without a Website

Local businesses with no website of their own, by city and category, for web-design and marketing agencies: name, category, address, phone, email and social links from open Overture Maps data. Social-only pages flagged. No scraping. $1.20 per 1,000 leads.

Run on Apify →See pricing

What it does

No website leads for web-design and marketing agencies. Type a city and a business type ("restaurants in Austin", "plumbers in Leeds", "hair salons in Berlin") and get the local businesses that list no website of their own: name, category, full address, latitude/longitude, phone numbers, email and social links, plus a plain Google Maps search link. Each row says why it qualifies: websiteStatus no-website (no website listed at all) or social-only (the only "website" is a Facebook, Instagram, linktree, WhatsApp, delivery or directory page) — exactly the businesses an agency can sell a first website to. The data comes from the open Overture Maps Foundation places dataset (80M+ businesses worldwide, refreshed monthly). Nothing is scraped and no website is fetched, so there are no blocks or CAPTCHAs, and the licences (CDLA-Permissive-2.0, Apache-2.0, CC0) let you store and resell the leads. $1.20 per 1,000 leads plus $0.003 per area query.

Read this first: "no website in Overture" is not proof that the business has no website. Some businesses have a site that Overture's sources do not list; when a row's email is on a business domain (info@acme.com), that domain is given in possibleWebsiteDomain so you can filter those out. There are no Google reviews, star ratings, opening hours or photos.

Limits and honest notes

  • Open data, not Google: no reviews, ratings, review counts, opening hours, photos, popular times or price levels. The Google Maps link in each row is a plain search URL built from the name and address; nothing is fetched from Google.
  • "No website" means none is listed in Overture Maps. A business can still have a site its sources missed, especially well-known ones. Check possibleWebsiteDomain (set when the business email is on its own domain), raise minConfidence, or spot-check before you pitch. No website is ever fetched to verify.
  • social-only rows list a link that is not the business's own site: Facebook, Instagram, linktree and other link-in-bio pages, WhatsApp, Telegram, X, TikTok, YouTube, LinkedIn, Yelp, Tripadvisor, OpenTable, delivery platforms (Uber Eats, DoorDash, Toast...) and Google Business Profile links.
  • In a 10-restaurant Austin test every row had a phone; emails were present for about 40%. Rural areas and parts of Africa and Asia are thinner.
  • Business contacts only: phones, emails and socials are the business's published contacts. Free-mail addresses that do not contain the business name and off-domain personal-looking addresses are removed (counted in droppedPersonalEmails). You remain responsible for how you use the data under GDPR, CAN-SPAM and similar laws.
  • One query per run, up to 1.5 x 1.5 degrees (about one metro area). For a region, run once per city. City names resolve offline from 32,000+ built-in cities; smaller towns need a region or country.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~no-website-leads/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"location": "Austin, TX", "categories": ["restaurant"], "maxPlaces": 10}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "location": "Austin, TX",
  "categories": [
    "restaurant"
  ],
  "maxPlaces": 10
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~no-website-leads/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "location": "Austin, TX",
    "categories": [
        "restaurant"
    ],
    "maxPlaces": 10
}

run = client.actor("actor-forge/no-website-leads").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
