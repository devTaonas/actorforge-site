Google Ads Scraper — Ads Transparency by Domain or Advertiser

Google Ads scraper for competitor research: every Search, YouTube, Display and Shopping ad a domain or advertiser runs, read from the public Google Ads Transparency Center. Format, first/last shown, regions, impressions, ad copy, images, video. $0.60 per 1,000 ads.

What it does

A Google Ads scraper for competitor research: give it a competitor's domain (nike.com), an advertiser name (HubSpot) or a Google advertiser ID, and get one clean row for every ad Google lists for them: Search (text), YouTube (video), Display and Shopping (image) ads. Each row has the advertiser (company name, ID, country), creative ID, format, first and last shown dates, days running, countries, impression ranges, best-effort ad copy (headline and description), image and video URLs, landing domain and a link to the ad's public page. Filter by country, date range and format.

Where the data comes from: the public Google Ads Transparency Center (adstransparency.google.com), Google's own ad library. It is the same source every "Google Ads Scraper" on the Store reads. It is not a scraper of live Google search results pages: it shows which ads an advertiser runs and where, not the ad positions for a keyword.

Limits and honest notes

  • Source: the public Google Ads Transparency Center only. This actor does not scrape live Google search results pages (no keyword ad positions, no SERP ads) and does not use the Google Ads API (no spend, clicks or keywords).
  • No CAPTCHA solving and no protection bypass. If Google serves a CAPTCHA or its "unusual traffic" page (or keeps answering 429/403), the run stops at once, keeps the ads already delivered, and says so in the status message and RUN_SUMMARY. Blocked requests are never charged; a run stopped before any ad is delivered returns one free status row. Google can do this to automated traffic from busy IP ranges, so re-run later.
  • Requests use an honest user agent naming this actor, with no browser imitation and no proxy rotation. You can set your own proxy for your own reasons; the default is none. Data comes from the same keyless JSON calls the public Transparency Center page makes (its robots.txt has no rules), paced at most 2 at a time, 0.8-2 s apart, with backoff on errors.
  • Ad copy (headline/description) needs 'Include ad details' and is best-effort: many Google text ads are published only as a rendered snapshot image (returned as previewImageUrl), and image ads have no text.
  • There is no ad-text keyword search in the Transparency Center: search by domain, advertiser name or advertiser ID. A domain search returns ads from every advertiser that advertises that domain (agencies and resellers included).
  • Advertiser country is filled for advertiser-name searches (from Google's advertiser search); domain and ID searches leave it empty.
  • Advertisers are businesses. Where Google lists a verified individual as the advertiser, only the name Google itself publishes is returned. No other personal data is collected.
  • 'Max ads per domain / advertiser' counts ads read, newest first, so a daily monitor stays fast and cheap. Already-seen ads (monitoring), filtered-out formats and errors are never charged.
  • Respects your run budget: set a maximum total charge and the actor stops cleanly at the cap.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~google-ads-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"domains": ["nike.com"], "maxAdsPerAdvertiser": 5, "maxResults": 5}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "domains": [
    "nike.com"
  ],
  "maxAdsPerAdvertiser": 5,
  "maxResults": 5
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~google-ads-scraper/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "domains": [
        "nike.com"
    ],
    "maxAdsPerAdvertiser": 5,
    "maxResults": 5
}

run = client.actor("actor-forge/google-ads-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
