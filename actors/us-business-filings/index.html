US Business Entity Search — New LLC & Corporation Leads

New and existing US business registrations from official state open data (NY, CO, CT, OR, TX, PA): filter by state, formation date (e.g. last 7 days), entity type, name, city or ZIP. One clean schema, organisation-level fields. $0.80 per 1,000 entities.

What it does

A US business entity search and new-business lead feed, straight from official state open data. Six states publish their business registries as open data: New York (Department of State), Colorado (Secretary of State), Connecticut (Secretary of the State), Oregon (Corporation Division), Texas (Comptroller franchise-tax file with the SOS file number and charter date) and Pennsylvania (Department of State). This actor queries all six through their public APIs and returns one clean schema: state, entity number, name, entity type and kind (LLC, corporation, nonprofit, partnership, trust), domestic or foreign, status, formation date, jurisdiction of formation, county, the business address (principal office, registered office or taxpayer address, as each state publishes it) and the registered agent when it is an organisation (for example a registered-agent company), plus the NAICS industry for Connecticut. Filter by state, formation date (e.g. formed in the last 7 days), entity kind, domestic/foreign, name keyword, city and ZIP code, sort newest first, and schedule it for a weekly new LLC and new corporation lead list. Use it for B2B prospecting (accountants, insurance, banking, payroll, web design, signage, office supply), KYC and vendor checks, market and competitor research, and local economic monitoring. $0.80 per 1,000 entities, with no compute bill on top; problems return a free status row instead of failing.

Limits and honest notes

  • Coverage is six states (NY, CO, CT, OR, TX, PA): the states that publish their business registry as open data with an API. States whose registry sits behind a CAPTCHA or bot wall (for example Florida, California, Delaware) are not covered, because this actor never bypasses protections.
  • What each state publishes differs. NY, OR and PA publish active entities only; CO, CT and TX also list dissolved or forfeited ones (turn off Active only to see them). Texas comes from the Comptroller's franchise-tax file: it has the Secretary of State file number and charter date and the taxpayer mailing address, but no registered agent. Pennsylvania gives the registered office and county; Connecticut adds a NAICS industry where the business supplied one.
  • Freshness: the portals refresh daily (NY, CO, CT, OR) to weekly (TX, PA), so filings from the last few days may not be in yet. A 'formed in the last 7 days' run is best scheduled weekly with a 10-day window and de-duplicated by id.
  • Privacy by design: only organisation-level fields are requested from the APIs. Officer, organizer, member and chairman names, e-mail addresses, phone numbers and agents' residence addresses are never requested or output. A registered agent's name and address are shown only when the agent is an organisation; for an individual agent the actor outputs registeredAgentIsIndividual: true and nothing else. In New York, a service-of-process address that is addressed to a person keeps only its city, state and ZIP. The business's own published address is output: for very small businesses this can be the owner's home, so use the data responsibly and in line with US law (TCPA, CAN-SPAM, state privacy laws).
  • It uses the official Socrata open-data APIs (data.ny.gov, data.colorado.gov, data.ct.gov, data.oregon.gov, data.texas.gov, data.pa.gov), which robots.txt allows, at about one request per second per portal (their crawl delay), with an honest user agent (ActorForge-USBusiness). No login, cookies or proxies. An optional free Socrata app token raises the rate limit for very large pulls.
  • Data: New York State Department of State, Colorado Secretary of State, Connecticut Secretary of the State, Oregon Secretary of State Corporation Division, Texas Comptroller of Public Accounts and Pennsylvania Department of State, via their open-data portals. This actor is not affiliated with or endorsed by any of them. Registry records are not legal certificates of good standing: confirm with the state before relying on a status.
  • Respects your run budget: set a maximum total charge and the run stops cleanly at the cap. If a portal refuses a request the run stops, keeps the rows already delivered and adds a free status row. A search with no matches returns one free status row.

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "states": [
        "NY"
    ],
    "nameContains": "bakery",
    "maxItems": 20
}

run = client.actor("actor-forge/us-business-filings").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
