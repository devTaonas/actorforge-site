What it does

Document intake is rarely tidy. One supplier emails a scanned PDF, another sends a phone photo of the same invoice, the fax gateway produces TIFFs and a support form uploads screenshots. Building a separate path for each format is busywork. The OCR to Text actor takes all of them in one urls list and returns text in a consistent row format.

It accepts PDF, PNG, JPEG, TIFF, WebP, GIF, BMP and JPEG 2000. Each image counts as one page; each PDF is read page by page, with pages that already have a text layer read directly at a tenth of the OCR price. By default you get one row per file with all its text, which keeps downstream code simple whatever the input type.

Under the hood it runs Tesseract 5 with LSTM models in 29 languages, up to 4 per run. That makes it a good fit for automation work: back-office pipelines, AI agents that need a reliable OCR tool, and scheduled batch jobs where a run budget cap matters. Failed downloads, unreadable files and blank pages are never charged.

How it works

  1. You submit a list of file links in urls, mixing PDFs and image formats freely, and optionally cap the batch with maxFiles.
  2. The actor detects each file's type; images go straight to OCR, PDFs are split into pages and text-layer pages are read without OCR in auto mode.
  3. Tesseract 5 recognises the image pages in your chosen languages, dropping low-confidence words if you set minWordConfidence.
  4. Each file becomes one dataset row by default (outputMode document), or one row per PDF page if you switch to pages.
  5. Charges are per page read, and the run stops cleanly when it reaches the maximum total charge you set.

Use cases

Back-office document intake

Route every incoming attachment, whatever its format, to one OCR call and store the text next to the file. Because each file comes back as one row with fileType, pagesOcr and confidence, the same parser handles invoices, letters and forms.

OCR tool for AI agents

Give an agent one tool that turns any document link into text instead of separate image and PDF tools. The confidence score lets the agent decide when to ask a human to check a result.

Migrating a document store

When moving years of scans out of an old document management system, export file links in batches of up to 10,000 per run with maxFiles and keep the returned text for search in the new system.

Scheduled nightly OCR jobs

Run the actor on a schedule against the day's new uploads and set a maximum total charge. If a batch is unexpectedly large the run stops at the cap rather than overrunning your budget.

Limits and honest notes

  • Tesseract reads printed and typed text very well (95%+ confidence on clean scans); handwriting, low-resolution photos, heavy stamps and decorative fonts come out poorly. The confidence score tells you which pages to check.
  • Output is plain text in reading order with line and paragraph breaks. Tables come out as lines of text, not structured tables. Images and charts have no text to extract.
  • Pages rotated by 90° or 180° are not auto-rotated; slightly skewed scans are fine.
  • Up to 4 languages per run; picking only the languages your documents use is faster and more accurate. Modern Greek is not available.
  • HEIC/AVIF photos and SVG are not supported (convert photos to JPEG). Files up to 100 MB; PDFs up to 2,000 pages each (200 by default).
  • Password-protected PDFs need the password input. Links that return a web page instead of a file are reported and not charged.
  • Respects your run budget: set a maximum total charge and processing stops cleanly at the cap, with no page charged twice.

FAQ

Can I send PDFs and images to the same OCR API call?

Yes. Put any mix of PDF, PNG, JPEG, TIFF, WebP, GIF, BMP and JPEG 2000 links in urls. Images are always one row each; PDFs are one row per file by default or one row per page with outputMode set to pages.

Which OCR languages are supported and how many can I use at once?

29 languages, including English, German, French, Spanish, Arabic, Hebrew, Hindi, Russian, Chinese (simplified and traditional), Japanese, Korean and Thai. You can select up to 4 per run. Modern Greek is not available.

How many files can one run handle?

maxFiles defaults to 1,000 and can be raised to 10,000 per run. Individual files can be up to 100 MB, and PDFs up to 2,000 pages each (200 by default via maxPagesPerPdf).

Am I charged for files that fail?

No. Failed downloads, unreadable files, blank pages and links that return a web page instead of a file are reported in the dataset and not charged. You pay $0.003 per OCR'd page and $0.0003 per PDF page read from its text layer.

How do I cut noise from stamps and stains?

Set minWordConfidence to drop words Tesseract is unsure about. The README suggests 40 to 60 removes most noise from stains and stamps; 0 keeps everything.

  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "urls": [
        "https://raw.githubusercontent.com/ocrmypdf/OCRmyPDF/main/tests/resources/linn.pdf",
        "https://raw.githubusercontent.com/tesseract-ocr/test/main/testing/phototest.tif",
        "https://github.com/tesseract-ocr/tessdoc/raw/main/images/eurotext.png"
    ],
    "languages": [
        "eng",
        "fra"
    ],
    "pdfMode": "auto",
    "outputMode": "document",
    "minWordConfidence": 40,
    "maxFiles": 5000
}

run = client.actor("actor-forge/ocr-to-text").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
