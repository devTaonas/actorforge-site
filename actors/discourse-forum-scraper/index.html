Discourse Forum Scraper — Topics, Threads & Posts

Scrape topics and full threads from any public Discourse forum: titles, categories, tags, views, likes and every post's text and links. Latest, top, category, tag or topic URLs. Robots.txt and each forum's terms checked. No login. $0.30 per 1,000 posts.

Run on Apify →See pricing

What it does

A Discourse forum scraper for the thousands of public product, open-source and community forums built on Discourse. Give it a forum, category, tag or topic URL and get clean rows from the forum's own JSON endpoints: topics with title, category, tags, opening author handle, created and last-activity dates, posts, replies, views, likes and participants, pinned/closed/solved flags; and full threads, one row per post with clean text (quotes and image clutter removed), likes, reads, reply links, accepted-answer flag and the links each post contains. Pick latest activity or top topics by period, filter titles by keywords and skip stale topics by date. Use it for voice-of-customer and feature-request research, support and documentation gap analysis, community health reporting, competitive research on rival products' forums, and building Q&A datasets. Every forum's robots.txt and terms of service are checked first and the content licence the forum states is attached to each row. $0.40 per 1,000 topics and $0.30 per 1,000 posts, no compute bill on top; skipped forums and problems are free status rows.

Limits and honest notes

  • Forum rules come first. Before reading a forum, the actor fetches its robots.txt (RFC 9309) and its /tos page. Forums whose terms forbid automated access are skipped with a free status row. Discourse's current default terms do forbid it, so many forums are skipped; forums on the older default terms (for example several large open-source language forums) and forums with no such clause can be read. A terms page that only points elsewhere is followed once; terms that cannot be read are treated as a refusal. This check reads text automatically and is not legal advice: you remain responsible for using each forum's content within its terms and stated licence.
  • Content licences: each row carries the licence named in the forum's terms (for example CC BY-NC-SA 3.0 or MIT OR Apache-2.0) when one is stated. Non-commercial licences restrict how you may reuse the text.
  • Search is not offered because Discourse's default robots.txt disallows /search; use title keywords, categories or tags instead. Private, login-only and members-only forums or categories are not read (free status row). Whispers, moderator actions, hidden and deleted posts are skipped.
  • Only topic and post content is returned. Usernames appear as public handles; real names, avatars, profile pages, badges and user statistics are never collected, and e-mail addresses in post text are removed. Do not use the data for spam or harassment.
  • Plain HTTPS requests with an honest user agent (ActorForge-Discourse), at most one request per second per forum, retries with back-off on HTTP 429/503, no login, cookies or proxies. Requests to private or internal network addresses are refused. Not affiliated with, endorsed by or sponsored by Discourse or any forum. Set a maximum total charge and the run stops cleanly at the cap.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~discourse-forum-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"startUrls": ["https://users.rust-lang.org"], "maxTopicsPerSource": 3, "maxPostsPerTopic": 5}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "startUrls": [
    "https://users.rust-lang.org"
  ],
  "maxTopicsPerSource": 3,
  "maxPostsPerTopic": 5
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~discourse-forum-scraper/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "startUrls": [
        "https://users.rust-lang.org"
    ],
    "maxTopicsPerSource": 3,
    "maxPostsPerTopic": 5
}

run = client.actor("actor-forge/discourse-forum-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
