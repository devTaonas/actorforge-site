AI Image Upscaler — 2x/4x Real-ESRGAN, Photo & Anime

Upscale images 2× or 4× with AI (Real-ESRGAN compact models): sharper detail, fewer JPEG artefacts. Photo and anime models, PNG/JPG/WebP output, bulk image URLs. Pay per image.

What it does

Upscale images 2× or 4× with AI and get sharper, cleaner results than a plain resize. Paste image URLs and get each one back enlarged by Real-ESRGAN, the widely used open-source super-resolution network, with a direct download link and a row showing the original and new dimensions and processing time. Two compact models are built in: Photo (Real-ESRGAN general x4v3) for photos, product shots, scans and screenshots; it also cleans up JPEG artefacts and mild noise. Anime (Real-ESRGAN animevideo v3) for anime, cartoons, illustrations, logos and flat graphics. Output as PNG (lossless, keeps transparency), JPG or WebP. Transparent images keep their alpha channel. Use it to enlarge small product photos for e-commerce listings, restore old low-resolution pictures, upscale AI-generated or anime art, prepare images for print, or as an upscaling step for AI agents and automation pipelines. It runs on CPU with no GPU queue and no sign-up anywhere else, and needs no API key. $0.006 per image up to 0.25 megapixels (e.g. 500×500 → 2000×2000), plus $0.006 per further 0.25 MP of input, so a 1000×1000 photo costs $0.024. No face restoration or generative "hallucinated" detail: the networks sharpen what is there. Failed and oversized images are never charged.

Limits and honest notes

  • Input: direct image URLs (JPEG, PNG, WebP, AVIF, TIFF, the first frame of GIFs). Up to 20 MB per file. To grab every image on a web page first, use our Bulk Image Downloader.
  • Input size is capped by 'Max input size' (1 MP by default, at most 4 MP, e.g. 2000×2000). Larger images are reported as errors and not charged; shrink them first with our Image Converter. The output is 2× or 4× the input, so a 4 MP input at 4× becomes a 64 MP (8000×8000) image.
  • Speed: the AI runs on CPU. With the default 2 GB of memory, a 500×500 image takes about 5 seconds and a 1000×1000 image about a minute. With 8 GB, images are processed about 4× faster (1000×1000 in about 16 seconds). The price is the same at any memory size.
  • 2× uses the same 4× network and then downsamples with Lanczos, exactly like the original Real-ESRGAN tools, so 2× and 4× cost the same.
  • These are compact Real-ESRGAN networks, chosen for speed. They sharpen edges and remove compression artefacts but do not invent new detail the way diffusion upscalers do, and there is no face restoration. Very blurry or tiny faces stay soft.
  • Transparency is upscaled with Lanczos (the AI enhances the colour channels). JPG output fills transparent areas with white.
  • EXIF orientation is applied (photos come out upright); other metadata is not copied to the output. Colours are converted to sRGB.
  • Download links work for the lifetime of the run's storage (Apify's data retention for your plan).
  • Models: Real-ESRGAN general x4v3 and animevideo v3 by Xintao Wang et al., BSD-3-Clause licence, converted to ONNX.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~image-upscaler/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"imageUrls": ["https://upload.wikimedia.org/wikipedia/commons/thumb/9/97/The_Earth_seen_from_Apollo_17.jpg/250px-The_Earth_seen_from_Apollo_17.jpg"], "scale": "2"}'

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "imageUrls": [
        "https://upload.wikimedia.org/wikipedia/commons/thumb/9/97/The_Earth_seen_from_Apollo_17.jpg/250px-The_Earth_seen_from_Apollo_17.jpg"
    ],
    "scale": "2"
}

run = client.actor("actor-forge/image-upscaler").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
