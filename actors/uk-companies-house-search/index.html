What it does

Build UK company lists straight from the official Companies House register. Don't have company numbers yet? This Companies House search actor finds them for you: combine SIC code (industry), town, city or postcode, company status (active, dissolved, in liquidation, administration…), company type (Ltd, PLC, LLP, CIC…), incorporation date and dissolution date ranges and name includes / excludes — e.g. *every software company (SIC 62012) incorporated in Manchester in the last 30 days*, *all active scaffolding firms (SIC 43991) in LS postcodes*, or *companies dissolved this month*. Dates can be relative ("30 days", "2 weeks"), SIC codes can be typed as codes, prefixes ("6201") or descriptions ("software development"), and several locations are searched and deduplicated in one run. Each row has the company number, name, status, type, incorporation and dissolution dates, SIC codes with their official descriptions, the structured registered office address and a link to the register page.

The Companies House API returns at most 10,000 results per search. Bigger queries are split by incorporation date automatically, so one run can return up to 50,000 companies.

Limits and honest notes

  • Official Companies House data only: companies registered in England, Wales, Scotland and Northern Ireland.
  • Company data only. Officers (directors, secretaries) are not included. Get them with the UK Companies House Enrichment actor, which takes this actor's companyNumber values.
  • The Companies House API returns at most 10,000 companies per search. Larger result sets are split by incorporation date automatically. Companies with no incorporation date on record can be missed when a split happens, and a single day matching more than 10,000 companies (only possible with very broad filters) is capped at 10,000.
  • Location matching is done by Companies House on the registered office address (town, postcode or postcode district). It is not a trading address and not a radius search.
  • Companies that match several of your locations are returned once, under the first location that matched.
  • Up to 50,000 companies per run. Throughput is about 5,000 companies per API request, so most runs finish in seconds to a couple of minutes.
  • Requests are throttled to stay inside the Companies House rate limit (600 requests / 5 minutes per key). Add your own free API key in the input for dedicated throughput.
  • SIC descriptions come from the SIC 2007 condensed list published by Companies House (Open Government Licence). Older codes not on that list have a null description.
  • You are only charged for companies delivered. Set a maximum total charge and the actor stops cleanly at your cap.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~uk-companies-house-search/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"sicCodes": ["62012"], "incorporatedFrom": "30 days"}'

  }

const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {

run = client.actor("actor-forge/uk-companies-house-search").call(run_input=run_input)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
