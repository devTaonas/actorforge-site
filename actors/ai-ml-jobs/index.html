What it does

Find AI, machine-learning and data jobs straight from the career sites of the companies building AI, fresher and more complete than general job boards. This AI jobs scraper / ML jobs API scans a built-in list of 136 AI employers (frontier labs such as OpenAI, Anthropic, xAI, Cohere and Hugging Face; AI infrastructure such as Databricks, Together AI, CoreWeave, Cerebras and Modal; AI products such as Perplexity, Harvey, Cursor, Sierra and ElevenLabs; robotics and autonomy such as Figure, Waymo and Wayve; AI biotech, AI training-data companies and data platforms such as Snowflake and ClickHouse) and returns only the roles you care about, newest first across all companies. Every row is classified: role family (research scientist/engineer, ML engineer, applied AI/LLM/agents, ML infrastructure/inference/GPU, data science, data engineering, analytics, AI product, AI training data), AI domains (LLM, agents, computer vision, speech, robotics, RL, safety, GPU performance…), seniority (intern to VP), remote/hybrid/onsite, and the published salary range (Greenhouse pay-transparency ranges and Ashby/Lever compensation, e.g. 584 of Anthropic's 674 postings carry a range). Add any other company's careers URL on 13 ATS (Greenhouse, Lever, Ashby, Workday, Workable, SmartRecruiters, Oracle and more) and it is classified the same way. Use it for AI job hunting and alerts, AI-talent sourcing, job-board and newsletter feeds, compensation research, or hiring-signal tracking ('who is hiring inference engineers?'). $1.50 per 1,000 jobs.

Limits and honest notes

  • The built-in list holds 136 AI / ML / data employers whose public Greenhouse, Lever, Ashby or Workable boards were verified live on 2026-11-11. Companies with custom-built careers pages (e.g. Google DeepMind, Meta, Microsoft) are not included; Workday, Oracle and SmartRecruiters employers (e.g. NVIDIA) work when you add their careers URL.
  • Role family, AI domains and seniority are assigned by transparent title / department rules, not by an LLM. They are right for the vast majority of postings, but unusual titles can land in a neighbouring family; 'Member of Technical Staff' with no specialism counts as ML engineering only at frontier labs.
  • Seniority is read from the title only. Titles without a level (most mid-level roles) return null; use 'Not stated' in the seniority filter to keep them.
  • Salary is returned only where the employer publishes it in structured form (Greenhouse pay-transparency ranges, Ashby and Lever compensation, Rippling pay). Several ranges (e.g. per location zone) are merged into the overall min/max, and every range is kept in salaryText. No salary is ever estimated.
  • Results are ranked newest first across all scanned companies, so the run scans every selected board before delivering. A full scan of the built-in list takes about 30 to 60 seconds; descriptions make it slower.
  • Lists only currently open, publicly listed jobs, exactly what each company's careers page shows. Recruiter names, job mailboxes and application-form fields are never returned.
  • Filtered-out jobs and companies without a public board are never charged. An empty search returns one free row with status 'no-results'.
  • Respects your run budget: set a maximum total charge and the actor stops cleanly at the cap.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~ai-ml-jobs/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"postedWithinDays": 30, "maxJobs": 50}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "postedWithinDays": 30,
  "maxJobs": 50
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~ai-ml-jobs/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "postedWithinDays": 30,
    "maxJobs": 50
}

run = client.actor("actor-forge/ai-ml-jobs").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
