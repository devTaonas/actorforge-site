Domain Email Finder — Company Emails from a List of Domains

Paste a list of company domains and get the role mailboxes each company publishes on its own website (info@, sales@, support@, press@ …), with the page each address was found on. Personal addresses are never returned. $3 per 1,000 domains with an email found; the rest are free.

Run on Apify →See pricing

What it does

Find the email addresses a company publishes, for a whole list of domains at once. Paste domains (or website URLs, or work emails) and the actor reads each company's own website: the home page plus up to four of its contact, imprint/Impressum, about, support, privacy and legal pages. You get one row per domain with the primary email, every company role mailbox it found (info@, hello@, sales@, support@, press@, partnerships@, privacy@ …) and the page and method each address came from (mailto link, JSON-LD, footer, page text), so every email can be checked.

Company mailboxes only. An address is kept only when it is a role or department mailbox on the company's own domain. Anything that looks like a person (jane@, j.smith@, initials) is dropped and only counted, never returned. This is the "domains in, generic company emails out" job for outreach lists, supplier and partner contact sheets, CRM clean-up and Clay or Zapier enrichment columns, without guessing patterns or verifying addresses.

Limits and honest notes

  • Company contacts only: an email is kept only when its local part is a role or department (info, sales, support, hello, contact, press, office, billing, careers, privacy and about 200 more, in several languages) and it sits on the company's own domain, or on a free-mail domain with the brand name in it (acmeplumbing@gmail.com). Name-like addresses are dropped and counted in personalEmailsDropped. This is not a people email finder: it never guesses or builds addresses (first.last@) and never returns named people.
  • Many companies publish no email at all, only contact forms. Expect an email for roughly half of company websites; the others come back as free no-emails rows.
  • Emails are not verified by SMTP: they are exactly what the company published on its own pages, with the source page in emailSources.
  • Reads static HTML only (no browser). Contacts that a site injects with JavaScript, or shows only as images, are not seen. Only the simple obfuscations are decoded: Cloudflare email protection and "[at]" / "(at)" / "[dot]" spellings.
  • robots.txt is respected for every page. A 403, 429 or CAPTCHA page on the home page gives a free blocked row; on a later page the scan of that site stops (scanStoppedBy) and the row keeps what was already found. No proxies are used.
  • The run's spend limit is respected: each domain is charged once, before its row is delivered; when the limit is reached the run stops.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~domain-email-finder/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"domains": ["stripe.com", "shopify.com", "notion.so"]}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "domains": [
    "stripe.com",
    "shopify.com",
    "notion.so"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~domain-email-finder/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "domains": [
        "stripe.com",
        "shopify.com",
        "notion.so"
    ]
}

run = client.actor("actor-forge/domain-email-finder").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
