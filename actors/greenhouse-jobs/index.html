Scrape Greenhouse job boards to clean JSON: title, company, department, location, remote/hybrid, posted date, apply link and optional full description. Pass board URLs or search a 235-company index by keyword and location. $1.50 per 1,000 jobs.

What it does

Scrape Greenhouse job boards to JSON without an API key. This Greenhouse jobs scraper reads the same public job-board feed the company's careers page uses and returns every open posting in one clean schema: title, company, department, team, location, country, remote/hybrid/onsite, employment type, salary min/max/currency where published, posted date and apply link, with an optional full plain-text description. You get departments, office location and first-published date. Pass board URLs, or switch on *Search the whole built-in company index* to scan 235 Greenhouse companies (Stripe, Anthropic, Databricks, Cloudflare, SpaceX and YC startups) by keyword, location, remote and recency. Filter by keyword, excluded words, location, remote and posted-within-days; filtered-out jobs are free. Use it for recruiting and sourcing, job-board and newsletter feeds, hiring-signal sales prospecting, labour-market research, or as a jobs tool in Clay, Make, n8n and AI-agent workflows. The same engine also reads Greenhouse, Lever, Ashby, Workday, Workable, Recruitee, Teamtailor, Personio and BambooHR URLs. $1.50 per 1,000 jobs, with no compute bill on top.

Limits and honest notes

  • Supports Workday (*.myworkdayjobs.com), Greenhouse, Lever, Ashby (incl. EU Greenhouse/Lever hosts), Workable, Recruitee (*.recruitee.com), Teamtailor (*.teamtailor.com), Personio (*.jobs.personio.de/.com) and BambooHR (*.bamboohr.com). SmartRecruiters and custom-built careers pages are not supported.
  • The built-in index lists 811 Greenhouse/Lever/Ashby companies verified on 2026-10-18 (YC companies plus well-known employers). Workday and the other ATS work when you pass the company's careers URL; the actor never guesses company slugs.
  • Workday: one detail request per job (that is where the real posting date and description live), at most 5 requests at a time per company, so a 300-job site takes about a minute. Workday searches stop at 2,000 results; larger sites are split by job family or location automatically. A site whose robots.txt disallows its job pages is skipped and not charged.
  • Salary is only returned where the employer publishes it in structured form (common on Ashby, sometimes Lever/Recruitee, rare elsewhere). Otherwise the salary fields are null.
  • Lists only currently open, publicly listed jobs, exactly what the company's careers page shows. Recruiter names, job mailboxes and application-form fields are never returned.
  • Keyword/location filters are case-insensitive substring matches on title, department, team, location and country.
  • Filtered-out jobs and companies without a public board are never charged.
  • Respects your run budget: set a maximum total charge and the actor stops cleanly at the cap.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~greenhouse-jobs/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"companies": ["https://boards.greenhouse.io/anthropic", "https://job-boards.greenhouse.io/stripe", "https://boards.greenhouse.io/cloudflare"], "keywords": ["engineer"]}'

const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "companies": [
        "https://boards.greenhouse.io/anthropic",
        "https://job-boards.greenhouse.io/stripe",
        "https://boards.greenhouse.io/cloudflare"
    ],
    "keywords": [
        "engineer"
    ]
}

run = client.actor("actor-forge/greenhouse-jobs").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
