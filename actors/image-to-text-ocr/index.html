Image to Text OCR: Extract Text from Photos and Screenshots

Paste image links and get the text inside them back with line breaks, a confidence score and, if you want, the pixel box of every word.

Run on Apify →See pricing

What it does

Text trapped in pictures is everywhere: screenshots pasted into tickets, photos of whiteboards and letters, receipts, product labels, memes. Copying it out by hand does not scale. The Image to Text OCR actor reads those images in bulk and returns the text with its line and paragraph breaks.

It takes PNG, JPEG, TIFF, WebP, GIF, BMP and JPEG 2000 links. Each image becomes one row with the recognised text, a word count and an OCR confidence score, so you can tell a crisp screenshot from a blurry phone photo at a glance. Turn on includeWords and every word also comes with its own confidence and pixel box, which is what you need for redaction or highlighting.

Recognition uses Tesseract 5 in 29 languages, up to 4 per run. Pricing is $3 per 1,000 images with no compute bill on top, and failed downloads or blank images are not charged. It is built for developers adding an image-to-text step to an app, analysts working through screenshot collections, and automations in tools like Make, n8n and Zapier.

How it works

  1. You list image links in urls; scanned PDFs are accepted too and are read page by page.
  2. Each image is downloaded and passed to Tesseract 5 with your chosen languages and pageSegmentation mode.
  3. For screenshots and forms with scattered text, the sparse segmentation mode looks for text anywhere on the image; single-block suits receipts and snippets.
  4. Each image returns one row with text, word count and confidence, plus word boxes when includeWords is on and minWordConfidence filtering if set.
  5. Blank or unreadable images and failed downloads are reported free of charge.

Use cases

Text from support screenshots

Customers often paste screenshots of error dialogs instead of copying the message. Extract the text so tickets become searchable and the exact error string can be matched against known issues.

Receipt and label photos

Pull the printed text off photographed receipts or product labels for expense tools or catalogue checks. Use the single-block segmentation mode for small, dense blocks of text.

Redacting text in images

With includeWords on, every word comes with its pixel box (left, top, width, height) and confidence. That is enough to locate an account number or name in a screenshot and black it out before sharing.

Researching image-based posts

Collections of memes, infographics or social posts carry their message in the picture. OCR them in bulk to search, count or classify the text without opening each image.

Limits and honest notes

  • Tesseract reads printed and typed text very well (95%+ confidence on clean scans); handwriting, low-resolution photos, heavy stamps and decorative fonts come out poorly. The confidence score tells you which pages to check.
  • Output is plain text in reading order with line and paragraph breaks. Tables come out as lines of text, not structured tables. Images and charts have no text to extract.
  • Pages rotated by 90° or 180° are not auto-rotated; slightly skewed scans are fine.
  • Up to 4 languages per run; picking only the languages your documents use is faster and more accurate. Modern Greek is not available.
  • HEIC/AVIF photos and SVG are not supported (convert photos to JPEG). Files up to 100 MB; PDFs up to 2,000 pages each (200 by default).
  • Password-protected PDFs need the password input. Links that return a web page instead of a file are reported and not charged.
  • Respects your run budget: set a maximum total charge and processing stops cleanly at the cap, with no page charged twice.

FAQ

How do I extract text from a screenshot automatically?

Send the screenshot's URL in urls. For UI screenshots where text is scattered across the image, set pageSegmentation to sparse. The text comes back with line breaks plus a confidence score.

Can it read text from iPhone photos?

Only if they are JPEG, PNG or another supported format. HEIC and AVIF photos are not supported, so export or convert them to JPEG first.

Does it read handwriting?

Not well. Tesseract is strong on printed and typed text but handwriting, low-resolution photos and decorative fonts come out poorly. Check the confidence score to see which images to review.

How do I get the position of each word in the image?

Set includeWords to true. Each recognised word is returned with its confidence and pixel box (left, top, width, height). Combine it with minWordConfidence to drop uncertain words.

What does image OCR cost per image?

$0.003 per image read by OCR, so 1,000 images cost $3, with no separate compute charge. Images that fail to download or are blank are not charged.

run = client.actor("actor-forge/image-to-text-ocr").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
