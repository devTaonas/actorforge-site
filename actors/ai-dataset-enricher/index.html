AI Dataset Enricher - Bulk LLM Classify, Tag & Summarise

Run one AI prompt over every row of an Apify dataset, CSV/Excel/JSON file or pasted rows: classify, tag, score sentiment, summarise, translate or extract into typed fields you define. Cheap LLM via Apify's OpenRouter, billed at cost to your account. $0.70 per 1,000 rows plus tokens.

What it does

Run one AI prompt over every row of your data, in bulk. Point it at an Apify dataset (reviews, jobs, leads, products, posts, tickets…), a CSV, Excel or JSON file or rows pasted as JSON, write what you want in plain English (*"Classify the review's sentiment and main topic"*, *"Write a 20-word summary"*, *"Translate to English"*, *"Extract seniority and remote/on-site"*, *"Score this lead 1-10 for B2B SaaS fit"*), list the output fields you want (or give a JSON Schema), and get every row back with new, typed columns (numbers, booleans and lists are converted). It sends only the fields you choose, retries a bad reply once, caps the AI spend per run, and can estimate the cost first without calling the model. Use it for bulk sentiment analysis, text classification and tagging, lead scoring and qualification, data cleaning and normalisation, summarisation, translation, entity extraction and categorising products, inside Apify pipelines or from Make, n8n, Zapier and AI agents. Default model Google Gemini 2.5 Flash Lite; any OpenRouter model works (GPT-5 nano, GPT-4o mini, Gemini 2.5 Flash, Claude, Llama, Mistral…). $0.70 per 1,000 rows plus the AI tokens at cost.

Limits and honest notes

  • AI tokens are a second, separate charge on your own Apify account, made by apify/openrouter at OpenRouter's rates (10× on the Apify free plan). They are not part of this actor's pay-per-event price and are not limited by the run's maximum total charge: use maxLlmCostUsd (default $0.10) to cap them, and estimateOnly to preview the cost. Each row's _llmCostUsd is an estimate from the usage OpenRouter reports; your Apify billing page is authoritative.
  • AI models make mistakes. The model is told to use only the row's content and to return null when unsure, but check results that matter, especially classifications used for decisions about people.
  • Row content is treated as data: the model is told to ignore instructions inside rows (prompt-injection defence), but no defence is perfect. Use inputFields to keep private columns out of the prompt.
  • Personal data: by default the model is told not to output private individuals' contact details and personal-looking emails in its output are replaced. Only switch allowPersonalData on with a lawful basis.
  • Datasets: with limited permissions the run can read only the dataset picked in the Dataset field (or passed by ID via the API). Files up to 50 MB; private and internal network addresses are refused at every redirect hop.
  • If the AI service rejects the request (no credit, rate limit, unknown model id, outage), the run stops with one free status row "llm-unavailable" explaining why, and still finishes as SUCCEEDED.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~ai-dataset-enricher/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"rows": [{"text": "Great product, slow delivery"}], "prompt": "Classify sentiment (positive/neutral/negative) and the main topic", "outputSchema": {"sentiment": "string", "topic": "string"}, "maxLlmCostUsd": 0.005, "maxOutputTokens": 150}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "rows": [
    {
      "text": "Great product, slow delivery"
    }
  ],
  "prompt": "Classify sentiment (positive/neutral/negative) and the main topic",
  "outputSchema": {
    "sentiment": "string",
    "topic": "string"
  },
  "maxLlmCostUsd": 0.005,
  "maxOutputTokens": 150
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~ai-dataset-enricher/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "rows": [
        {
            "text": "Great product, slow delivery"
        }
    ],
    "prompt": "Classify sentiment (positive/neutral/negative) and the main topic",
    "outputSchema": {
        "sentiment": "string",
        "topic": "string"
    },
    "maxLlmCostUsd": 0.005,
    "maxOutputTokens": 150
}

run = client.actor("actor-forge/ai-dataset-enricher").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
