Excel to JSON Converter — XLSX, ODS & CSV to JSON Rows

Convert Excel (.xlsx/.xlsm), OpenDocument (.ods) and CSV/TSV files from URLs to clean JSON: every sheet as typed rows keyed by column name, real ISO dates instead of Excel serial numbers, formula results, plus a Markdown table per sheet. $3 per 1,000 workbooks.

Run on Apify →See pricing

What it does

Convert Excel spreadsheets to JSON in bulk. Paste links to .xlsx, .xlsm, .ods, .csv or .tsv files (or a web page that links to them) and get one row per workbook with every sheet as JSON rows keyed by column name. Values are typed: numbers stay numbers, TRUE/FALSE become booleans, formulas return their saved results, and Excel's date serial numbers become real ISO dates (2026-03-31, 14:30:00) using each cell's number format. Headers are cleaned and made unique, empty rows and trailing filler columns are dropped, hidden Excel sheets are skipped unless you want them, and each sheet also comes as a Markdown table for LLMs. CSV files get delimiter detection (comma, semicolon, tab, pipe) and Windows-1252/UTF-16 decoding, and keep values as text so postcodes and IDs keep their leading zeros. Use it to load government statistics and supplier price lists into databases, feed spreadsheets to AI agents and RAG, or replace manual "Save as CSV" steps in Make, n8n and Zapier workflows. Simple pricing: $3 per 1,000 workbooks, every sheet included (the leading Excel-to-JSON actor charges $30 per 1,000), with no compute bill on top. Failed downloads, unsupported or corrupt files and duplicates are never charged.

Limits and honest notes

  • Supported: .docx/.docm, .pptx/.pptm, .xlsx/.xlsm, .odt, .ods, .epub, .csv, .tsv, .md and .txt. Legacy binary files (.doc, .xls, .ppt), .odp, RTF and password-protected documents are reported and not charged. PDFs have their own actor: PDF to Markdown.
  • Images, charts and SmartArt are skipped (they have no text or URL to keep). Bold and italic survive in Word files; colours, fonts and layout do not.
  • Excel formulas return the value saved in the file (the last calculated result); they are not recalculated. Merged cells keep their value in the first cell only.
  • CSV values stay as text so postcodes, IDs and phone numbers keep their leading zeros. Excel and OpenDocument cells are typed.
  • Files up to 100 MB. Spreadsheets return up to 100,000 rows per sheet (10,000 by default). Very large results move to a linked file, with a preview kept in the row.
  • Web pages in the input are scanned for links to documents (one level deep, robots.txt respected). If a site's robots.txt can't be fetched (HTTP 5xx or a network error, after one retry), the documents linked on that site are skipped (RFC 9309) and the page gets a free row saying why. Pages behind a login are not supported.
  • Respects your run budget: set a maximum total charge and conversion stops cleanly at the cap, with no document charged twice.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~excel-to-json/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"urls": ["https://raw.githubusercontent.com/apache/poi/trunk/test-data/spreadsheet/SampleSS.xlsx"]}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "urls": [
    "https://raw.githubusercontent.com/apache/poi/trunk/test-data/spreadsheet/SampleSS.xlsx"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~excel-to-json/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "urls": [
        "https://raw.githubusercontent.com/apache/poi/trunk/test-data/spreadsheet/SampleSS.xlsx"
    ]
}

run = client.actor("actor-forge/excel-to-json").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
