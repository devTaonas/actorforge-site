Steam Game Data: Prices, Discounts, Player Counts & Details

Steam games by app ID, store URL, name search or the top-sellers and new-releases charts: price and discount in any country, release date, developer, publisher, genres, tags, Metacritic, recommendations and live player count. No login, no key. $1 per 1,000 games.

What it does

Steam store data plus live player counts, with no login or API key. Give it app IDs or store URLs, game names, or pull the current top sellers and popular new releases charts, and get one clean row per game: price, original price and discount in the currency of any Steam country, free-to-play flag, release date and coming-soon flag, developers and publishers, genres and store categories (single-player, co-op, controller support...), platforms, Metacritic score, recommendation count, achievements, DLC count, age rating, supported languages, short description, header image, website, and the number of players in game right now. Use it for game market research, price and discount tracking across regions, competitor and genre analysis, publisher lead lists, and player-count dashboards. $1 per 1,000 games, with no compute bill on top; problems return a free status row instead of failing.

Limits and honest notes

  • Responsible use: use the data in line with the Steam Subscriber Agreement and the Steam Web API Terms of Use. This actor is not affiliated with, endorsed by or sponsored by Valve Corporation or Steam.
  • It reads the Steam store's public JSON endpoints (which the store's robots.txt allows) and the official Steam Web API for player counts, with no login, cookies or proxies, at least 1.5 s between store requests and an honest user agent (ActorForge-SteamGames). Steam limits store details to roughly 200 apps per 5 minutes, so large runs take a while.
  • Player reviews and review scores are not included (Steam redirects that endpoint for automated clients); the recommendation count is the closest public figure. Prices are for the chosen country and include current sales.
  • If Steam refuses a request or rate-limits the run, the run stops, keeps the games already delivered and adds a free status row. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap. Unknown or region-locked apps return a free status row.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~steam-game-data/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"appIds": ["730", "570", "1245620"]}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "appIds": [
    "730",
    "570",
    "1245620"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~steam-game-data/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "appIds": [
        "730",
        "570",
        "1245620"
    ]
}

run = client.actor("actor-forge/steam-game-data").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
