Grants Search — Grants.gov, NIH, NSF & EU Funding Calls

What it does

Find grants to apply for and see who already got funded, in one clean table. This actor searches four official public grant databases at once and returns every result in the same shape: Grants.gov (all US federal grant opportunities: forecasted, open now and closed), the EU Funding & Tenders Portal (Horizon Europe, Digital Europe, LIFE, Erasmus+, EU4Health and other EU calls, EuropeAid calls for proposals and EU cascade-funding open calls for SMEs and start-ups), NIH RePORTER (funded US health research projects worldwide) and NSF Awards (funded science and engineering projects). Each row: source, ID and number, title, funder and agency, programme, status (forecasted / posted / closed / awarded), open date and application deadline, award ceiling, floor and total funding, number of awards, eligible applicant types and eligibility text, CFDA / assistance listing, category, funding instrument, a description summary and the link to the official page. Awarded projects add the recipient organisation, city, country, award amount, dates and the principal investigator's name as published (no contact details). Filter by keywords, source, status, funder or agency, deadline window, applicant type (nonprofit, university, small business, tribal, local government and more) and amount range. Built for grant writers, nonprofits, research offices, startups (SBIR/STTR, EU cascade funding) and consultants: run it on a schedule in monitor mode for a weekly new-grants alert in Slack, Sheets, Make, n8n or Zapier, or use it as a tool for AI agents. $1 per 1,000 results, no compute bill on top; explanation rows are free.

Limits and honest notes

  • Sources: Grants.gov (U.S. Department of Health and Human Services; not endorsed or certified by HHS), NIH RePORTER (National Institutes of Health), NSF Award Search (National Science Foundation), all public U.S. Government data, and the EU Funding & Tenders Portal (© European Union, reuse authorised with acknowledgement). Read through their official public APIs; no website is scraped and no key is needed. Not affiliated with any of these agencies.
  • Grants.gov and the EU portal list opportunities (forecasted, open, closed). NIH and NSF list projects that have already been awarded; they need the "Awarded" status and use the "Awarded since / until" window (default: the last year). UK Research and Innovation data is not included because its site does not allow automated access.
  • Eligibility filters work on Grants.gov only; the other sources do not publish structured applicant types. EU calls carry eligibility in their call documents: open the link.
  • Amounts are per grant in the source's currency (USD or EUR, never converted). EU topics show the per-project EU contribution and total topic budget; EuropeAid and cascade calls show the total call budget only. With an amount filter set, rows without a published amount are left out.
  • Grants.gov search results only have title, agency and dates, so each Grants.gov row costs one extra API call for its details (about half a second). Switch "Full Grants.gov details" off for very large pulls. Descriptions are cut at about 2,000 characters.
  • The EU search index sometimes keeps calls marked open after their deadline; this actor marks anything past its deadline as closed. Two-stage EU calls show their first deadline.
  • Agency contact persons, e-mail addresses and phone numbers are never output. Awarded projects show the organisation and the lead investigator's name exactly as the funder publishes it, nothing more.
  • Maximum results are shared evenly across the chosen sources. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap. Runs with no matches return one free status row explaining why.

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "keywords": "health",
    "sources": [
        "grants-gov"
    ],
    "statuses": [

}

run = client.actor("actor-forge/grants-funding-search").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
