What it does

Douyin (抖音) is the Chinese version of TikTok, and its hot list (抖音热榜) shows which topics, challenges and events are driving short-video traffic in China right now. For content strategists and brands, it is a direct read on what Chinese audiences are watching, but the board is in Chinese and changes constantly.

This actor captures the live Douyin hot list and returns each trending topic with its rank, heat value (热度), Douyin's badge in English (hot, new, first, exclusive or live), topic ID, cover image and a direct search link. The pinned slot is excluded, so rank is the board position starting at 1. There is no login, no cookies and nothing to configure.

It is aimed at social listening, influencer and content strategy, brand monitoring in China, trend detection and cross-border e-commerce product discovery. Topics cost $2 per 1,000, so a top-50 snapshot is $0.10.

How it works

  1. The actor reads Douyin's live public hot list; no login, cookies or configuration are needed.
  2. The pinned slot is excluded so ranks run from 1 at the top of the board.
  3. Each topic is returned with rank, title, heat score, English label, topic ID, cover image and search URL.
  4. Use keywords to keep only topics mentioning your terms; filtered-out topics are not charged.
  5. If Douyin is temporarily unavailable, the run fails cleanly and nothing is charged.

Limits and honest notes

  • Topics are returned in their original language (mostly Simplified Chinese). Titles are not machine-translated, so pass them to your own translator or LLM if needed.
  • Each board holds roughly 50 topics at a time. Max topics above the board size returns what the board has.
  • The pinned slot is excluded, so rank is the board position (1 = top).
  • heatScore is each platform's own popularity metric.
  • label is Douyin's badge in English (hot, new, first, exclusive, live) or null.
  • Topics, ranks and heat only. No user accounts, profiles or personal data are collected.
  • If Douyin is temporarily unavailable, the run fails cleanly and nothing is charged.
  • Respects your run budget: set a maximum total charge and the actor stops cleanly at the cap.

FAQ

What is the Douyin hot list (抖音热榜)?

It is Douyin's live trending board, the Chinese TikTok equivalent of a trending page, ranking topics by Douyin's own heat value. The actor returns roughly the 50 topics the board holds at any moment.

What do the labels in the Douyin data mean?

label is Douyin's own badge, returned in English: hot, new, first, exclusive or live, or null when a topic has none.

Does it scrape Douyin videos or user profiles?

No. It returns topics, ranks and heat only, plus a search link for each topic. No user accounts, profiles or personal data are collected.

Do I need a Douyin account or cookies?

No. The actor uses Douyin's public hot list data and needs no login, no cookies and no configuration.

Is the heat value comparable with Weibo or Baidu?

No. heatScore is each platform's own metric. Use it to compare topics within the Douyin board, and use rank when comparing against other platforms.

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
