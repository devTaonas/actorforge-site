Sitemap URL Extractor — All Page URLs, Lastmod & Hreflang

Get every page URL of a website from its XML sitemaps: robots.txt discovery, sitemap indexes, .gz, text and RSS sitemaps. Each URL comes with lastmod, changefreq, priority, images, videos, news and hreflang alternates. Filters, dedupe, change detection. $0.40 per 1,000 URLs.

What it does

Get all URLs of a website from its XML sitemaps, with all the metadata. This sitemap extractor (sitemap URL extractor / XML sitemap parser / sitemap scraper) takes a domain, a home page or a sitemap URL and returns one row per page URL. It finds the sitemaps for you (the Sitemap: lines in robots.txt, then /sitemap.xml, /sitemap_index.xml, /wp-sitemap.xml and other common paths), follows sitemap indexes to any depth with a cycle guard, and reads gzip (.xml.gz), text (sitemap.txt) and RSS/Atom feeds used as sitemaps. Each URL comes with lastmod (ISO 8601), changefreq and priority, plus the extensions other extractors drop: images (image:image loc, title, caption), videos (title, thumbnail, content and player URLs, duration), Google News (title, publication, date) and hreflang alternates (xhtml:link language versions). Filter by URL pattern and by lastmod date ("modified in the last 7 days"; old child sitemaps are not even downloaded), remove duplicates across sitemaps, optionally check each URL's HTTP status (200/301/404), and turn on change detection to get only new and updated URLs on scheduled runs, with removed URLs listed in the summary. The run summary shows the sitemap tree with URL counts per sitemap, a lastmod histogram by month and any errors. Huge sitemaps (50 MB / 50,000+ URLs per file) are streamed, not loaded whole, and malformed XML is read leniently. Use it for SEO audits, site migrations, content inventories, feeding crawlers and RAG pipelines, monitoring competitors' new pages, and hreflang checks. $0.40 per 1,000 URLs, with no compute bill on top (Apify's own sitemap extractor is $0.50 per 1,000).

Limits and honest notes

  • Reads only what the site publishes in its sitemaps: pages missing from them are not found (there is no link crawling). Sites with no sitemap at all are reported in the summary, free.
  • Robots policy: sitemaps listed in the site's robots.txt Sitemap: lines are always read (the owner published them for crawlers). Any other sitemap URL, whether you give it, it is guessed at a common path or linked from an index, is skipped when robots.txt disallows it for our user agent or *. If robots.txt itself can't be fetched (HTTP 5xx or a network error, after one retry), RFC 9309 says to treat the site as off-limits; there is then no Sitemap: list to go by, so on that site only the sitemap URLs you give explicitly are read (no discovery, guessed paths or index children), and the reason is listed in the run's errors. Page URLs are never fetched unless you turn on status checks.
  • A domain or page URL stands for its whole site (all of example.com's sitemaps); use 'Only URLs matching' to keep one section.
  • Polite by design: at most 2 requests at a time per host, and 429/5xx answers are retried up to 3 times (honouring Retry-After). Status checks therefore run at roughly 10-20 URLs per second per site.
  • Sitemap files up to 100 MB downloaded (300 MB uncompressed) are streamed; indexes are followed up to 10 levels deep; at most 'Max sitemap files' files per run (default 500). Truncated .gz files yield the URLs before the cut.
  • lastmod values are normalised to ISO 8601 UTC; time-zone-less values are read as UTC, and placeholder or impossible dates (1970, 0000-00-00) become null.
  • URLs on internal network addresses (localhost, private IPs, cloud metadata) are never requested and never charged.
  • Respects your run budget: set a maximum total charge and the run stops cleanly at the cap, delivering exactly the URLs that were charged. A run restarted by the platform skips URLs it already delivered.

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "urls": [
        "https://crawlee.dev"
    ]
}

run = client.actor("actor-forge/sitemap-extractor").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
