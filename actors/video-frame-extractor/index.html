Video Frame Extractor - Thumbnails, Scenes & Contact Sheet

Extract still frames from direct video file URLs (MP4, MOV, WebM, MKV): N evenly spaced, every N seconds, at scene changes or exact timestamps, as JPG/PNG/WebP, plus a contact sheet, GIF preview and media metadata. ffmpeg, no API key. $0.60 per 1,000 frames + $0.001 per video.

What it does

Turn video files into still images, automatically and in bulk. Give it direct links to your video files (MP4, MOV, WebM, MKV, AVI, M4V from your CDN, S3, Google Cloud Storage, a CMS or any public URL) and get frames as JPG, PNG or WebP: N evenly spaced thumbnails, one frame every N seconds, a frame at every scene change (shot detection), or frames at exact timestamps. Each video also gets a contact sheet (all frames tiled in one image), an optional animated GIF preview, and its media metadata: duration, resolution, frame rate, video and audio codecs, bitrate, container and rotation. Frames are saved to the run's storage with public links, timestamps and timecodes, ready for video thumbnails and poster images, content moderation and AI vision pipelines (feed frames to GPT-4o, Gemini or Claude), visual search indexing, ad and creative QA, e-learning chapter images, dataset building and archiving. Powered by ffmpeg with fast input seeking, so long files are not decoded from the start. No API key, no browser. $0.60 per 1,000 frames plus $0.001 per video (contact sheet and GIF included); videos that cannot be processed are free.

Limits and honest notes

  • Direct video file URLs only. Pages on YouTube, TikTok, Instagram, Facebook, Vimeo, X and similar platforms are refused (free status row): their terms forbid downloading. HLS (.m3u8) and DASH (.mpd) streaming playlists are not supported.
  • Each video is downloaded once to the run's disk (up to maxFileSizeMb, default 500 MB) and ffmpeg only reads that local copy. Private and internal network addresses are refused at every redirect hop, robots.txt is respected by default, and requests identify themselves honestly as ActorForge-VideoFrames.
  • Scene detection decodes the whole video, so it is limited to videos up to 60 minutes and takes roughly real-time/10 on the default memory. Evenly, interval and timestamp modes seek directly and are fast even for long files.
  • Frames, contact sheets and GIFs are stored in the run's key-value store and kept according to your Apify storage retention; download them or copy the links you need.
  • Only process videos you have the right to use. Frame images keep the copyright of the original video.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~video-frame-extractor/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"videoUrls": [{"url": "https://samplelib.com/mp4/sample-5s.mp4"}], "mode": "evenly", "frameCount": 3}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "videoUrls": [
    {
      "url": "https://samplelib.com/mp4/sample-5s.mp4"
    }
  ],
  "mode": "evenly",
  "frameCount": 3
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~video-frame-extractor/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "videoUrls": [
        {
            "url": "https://samplelib.com/mp4/sample-5s.mp4"
        }
    ],
    "mode": "evenly",
    "frameCount": 3
}

run = client.actor("actor-forge/video-frame-extractor").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
