Domain WHOIS & DNS Lookup — Bulk RDAP, SPF/DMARC, SSL Expiry

Bulk domain intelligence: registrar, creation and expiry dates, domain age, status and DNSSEC via RDAP (modern WHOIS), plus A/AAAA/MX/NS/TXT/CNAME/SOA/CAA records, parsed SPF and DMARC, SSL certificate expiry and availability. Paste domains, URLs or emails. $1 per 1,000 domains.

What it does

Bulk domain intelligence in one row per domain. Paste domains, website URLs or email addresses (each is reduced to its registrable domain and deduplicated) and get registration data from the registry's RDAP service, the modern replacement for WHOIS: registrar and IANA ID, creation, update and expiry dates, domain age and days to expiry, EPP status codes, nameservers and DNSSEC. Each row also has DNS records (A, AAAA, MX, NS, TXT, CNAME, SOA, CAA) with SPF and DMARC parsed into fields (policy, all qualifier, includes, lookup count, report addresses), the SSL certificate on port 443 (issuer, valid from/to, days to expiry, SAN count, trusted or not) and an availability check (registered true/false from RDAP and NXDOMAIN). Use it to monitor domain and certificate expiry across a portfolio, audit email deliverability (SPF/DMARC) for lead lists, enrich CRM records with company domain age and hosting, spot newly registered or lookalike domains for fraud and brand protection, or check which names are free. Simple pricing: $1 per 1,000 domains, with no compute bill on top. Invalid inputs, duplicates and failed lookups are never charged.

Limits and honest notes

  • Privacy (GDPR): registrant, admin, tech, billing and abuse contact details (names, emails, phones, addresses, organisations) are never returned, even where the registry publishes them. Only the registrar's name and IANA ID are included.
  • Registration data comes from RDAP only (no port-43 WHOIS). All gTLDs (.com, .net, .org, .dev, .app…) and many ccTLDs (.uk, .io, .de, .fr, .nl, .ch, .br, .au, .ca, .pl, .us…) are covered. TLDs without a public RDAP service (e.g. .it, .es, .eu, .jp, .co, .me) return DNS, SSL and availability only, with a warning. Some registries publish less: .de has no creation or expiry date and no registrar.
  • registered: false means the registry has no record (RDAP 404) or the domain does not exist in DNS (NXDOMAIN). It is a strong hint, not a guarantee: premium, reserved or recently deleted names may still be unavailable to register.
  • DNS is queried at the registrable domain only (subdomains in the input are reduced to it) through public resolvers 1.1.1.1 and 8.8.8.8. DKIM selectors are not guessed.
  • RDAP servers are queried at most 2 at a time each, and rate-limit answers (HTTP 429) are retried with backoff, so very large runs on one TLD take longer. Up to 10,000 domains per run.
  • Respects your run budget: set a maximum total charge and the run stops cleanly at the cap, with every delivered row charged exactly once.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~domain-lookup/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"domains": ["example.com", "bbc.co.uk", "https://www.notion.so/product", "info@apify.com"]}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "domains": [
    "example.com",
    "bbc.co.uk",
    "https://www.notion.so/product",
    "info@apify.com"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~domain-lookup/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "domains": [
        "example.com",
        "bbc.co.uk",
        "https://www.notion.so/product",
        "info@apify.com"
    ]
}

run = client.actor("actor-forge/domain-lookup").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
