YouTube Video Details (Official API) — Views & Likes by URL

Bring your own free YouTube API key. Paste video URLs or IDs and get each video's views, likes, comment count, duration, tags, category, language, captions flag and publish date from the official YouTube Data API v3. 50 videos per quota unit. $0.40 per 1,000 videos.

What it does

Bring your own free YouTube API key and turn a list of YouTube links into a spreadsheet of video stats, from the official YouTube Data API v3: no scraping, no proxies, no blocks. Paste watch URLs, youtu.be links, Shorts, embed or live links, or bare video IDs, and get one row per video with views, likes, comment count, duration (ISO and seconds), title, description, tags, category, default and audio language, captions flag, HD/SD, made-for-kids flag, live status, thumbnails, topic categories and the publish date.

Built for bulk lookups: campaign and influencer reporting, refreshing the view counts of a content library, checking which videos in a sheet are private or deleted (they come back as free error rows), or enriching a list of links for analysis in Sheets, Make, n8n or Zapier.

Limits and honest notes

  • Lookups by video URL or ID only. To find videos by keyword, channel or playlist, use the related YouTube listings below with the same key.
  • Private, deleted and invalid videos are free rows of type error and are never charged.
  • You need your own free YouTube Data API v3 key (see the 4-step guide above). Without one the run finishes at once with a free row of instructions, and nothing is charged.
  • Only public data the API returns for an API key: no dislike counts (removed by YouTube), no revenue and no watch time. Like counts hidden by the creator come back as null.
  • You must refresh or delete stored API data within 30 days (YouTube Developer Policies III.E.4). We keep nothing after the run.
  • The run's spend limit is respected: each page of videos is charged before it is delivered, and the run stops cleanly at the cap. If your key's quota runs out, the run stops cleanly and keeps what was delivered.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~youtube-video-details-api/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"videoUrls": ["https://www.youtube.com/watch?v=dQw4w9WgXcQ"]}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "videoUrls": [
    "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~youtube-video-details-api/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "videoUrls": [
        "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
    ]
}

run = client.actor("actor-forge/youtube-video-details-api").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
