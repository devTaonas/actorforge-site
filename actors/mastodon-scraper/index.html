Mastodon Scraper: Profiles, Posts, Hashtags & Trends

Scrape Mastodon and the fediverse from any instance's public API: profiles with follower counts and bio, posts with boosts, favourites, replies, hashtags, media and link cards, hashtag timelines, and trending tags, posts and links. Opt-outs honoured. No login. From $0.30 per 1,000 posts.

Run on Apify →See pricing

What it does

A Mastodon scraper for the whole fediverse, with no account. Point it at any Mastodon (or Mastodon-compatible) server and get clean rows from the server's own public API: profiles with display name, bio, profile links (with verification), follower, following and post counts, last post date and bot/group flags; posts from accounts and hashtag timelines with text, content warning, language, favourites, boosts, replies and quotes, hashtags, mentions, media and link cards; and the server's trending hashtags, posts and links with daily and weekly usage. Filter by date, include or skip replies and boosts. Use it for brand and topic monitoring, open-source and tech community research, social listening beyond X, journalism and academic studies of the fediverse. $0.30 per 1,000 posts or trends and $1 per 1,000 profiles, with no compute bill on top; problems return a free status row instead of failing.

Limits and honest notes

  • Responsible use: posts and profiles are personal content. Follow each server's rules and data-protection law (GDPR/UK GDPR), use the data for research, monitoring and analytics, and never for spam or harassment. This actor is not affiliated with, endorsed by or sponsored by Mastodon gGmbH or any server.
  • Consent is honoured: accounts that set noindex (asked not to be indexed) or did not opt in to searchable posts (indexable: false) are skipped together with their posts, and only public posts are returned. E-mail addresses and phone numbers are removed from bios and profile fields.
  • It reads only each server's public REST API, checks robots.txt on every server, waits at least 1 s between requests per server and sends an honest user agent (ActorForge-Mastodon). There is no login, no cookies and no proxies. Requests to private or internal network addresses are refused.
  • Some servers require a login for hashtag timelines or trends; those sources return a free status row and the run continues. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~mastodon-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"instance": "mastodon.social", "hashtags": ["opensource"], "maxPostsPerSource": 20}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "instance": "mastodon.social",
  "hashtags": [
    "opensource"
  ],
  "maxPostsPerSource": 20
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~mastodon-scraper/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "instance": "mastodon.social",
    "hashtags": [
        "opensource"
    ],
    "maxPostsPerSource": 20
}

run = client.actor("actor-forge/mastodon-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
