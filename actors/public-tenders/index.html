Public Tenders - UK, US, Australia, Brazil, Ukraine Contracts

Government tenders and contract awards from official open-data APIs: UK Find a Tender and Contracts Finder, Australia AusTender, Brazil PNCP, Ukraine Prozorro, US USAspending (and SAM.gov with your key). Buyer, values, winners, deadlines, CPV/NAICS. $1.20 per 1,000 notices.

What it does

Government tenders and contract awards from five countries in one clean table, straight from the official open-data APIs. Pick sources and a date window and get every new public procurement notice: UK Find a Tender (above-threshold tenders, awards and contracts) and UK Contracts Finder (lower-value UK opportunities and awards), Australia AusTender (every Australian Government contract notice), Brazil PNCP (licitações, pregões and dispensas from all Brazilian public bodies), Ukraine Prozorro (tenders and awards) and US USAspending (federal contract awards), plus SAM.gov federal opportunities if you add your own free API key. Each row: title, description, buyer and location, estimated and awarded value with currency, winning suppliers, bid deadline, status, procedure, CPV / UNSPSC / NAICS / PSC codes and a link to the official notice. Filter by keywords, notice type (open tenders, awards, contracts, planning), minimum value and buyer name. Switch on monitor mode for daily schedules and each run returns only notices you haven't seen yet: a cheap tender alert and bid-sourcing feed for sales teams, bid writers, consultancies and SMEs, plus market intelligence on who wins public contracts and data for AI agents. Works with Make, n8n, Zapier and Slack. Sibling of our EU Tenders (TED) actor with the same row style. $1.20 per 1,000 notices, no compute bill on top; runs that find nothing return a free status row.

Limits and honest notes

  • Sources and licences (each row's dataLicense names it; please keep the attribution when you republish): UK Find a Tender and Contracts Finder, Cabinet Office, Open Government Licence v3.0 ("Contains public sector information licensed under the Open Government Licence v3.0"). AusTender, Department of Finance, CC BY 3.0 AU. Brazil PNCP public consultation API. Ukraine Prozorro public API. USAspending.gov, U.S. Treasury (public domain). SAM.gov Contract Opportunities (GSA), with your own API key. Not affiliated with any of these bodies.
  • SAM.gov needs a free personal API key (samApiKey). Without one, the SAM source is skipped with a note in the run summary and the run continues with the others; it never fails. Personal keys have a small daily request quota, so the actor asks for 1,000 opportunities per request.
  • Each source is paced under its own limits (about 1 request per second for the UK, AusTender, USAspending and SAM, 2/s for PNCP, 4/s for Prozorro), with Retry-After honoured. Prozorro lists tenders only by modification time, so its details are fetched one by one (up to 1,000 per run).
  • What each source covers: AusTender's open-data API publishes contract notices (awarded contracts), not open approaches to market. USAspending gives federal contract awards (not open solicitations; use SAM.gov for those). PNCP needs a modality per request (default: pregão eletrônico, concorrência eletrônica, dispensa). UK sources include tenders, awards and contracts.
  • Keywords are matched in the title and description in the notice's language (USAspending also searches server-side). Values are in each notice's own currency, with no conversion.
  • maxResults is split evenly between the selected sources, newest first; a source with fewer matches leaves its share unused.
  • Contact persons, e-mail addresses and phone numbers in notices are never output; buyers and winning suppliers are organisations as published.
  • Respects your run budget: set a maximum total charge and the run stops cleanly at the cap, with nothing charged twice. A run with no matches returns one free status row explaining why.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~public-tenders/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"sources": ["uk-find-a-tender", "australia-austender"], "publishedFrom": "3 days", "maxResults": 10}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "sources": [
    "uk-find-a-tender",
    "australia-austender"
  ],
  "publishedFrom": "3 days",
  "maxResults": 10
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~public-tenders/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "sources": [
        "uk-find-a-tender",
        "australia-austender"
    ],
    "publishedFrom": "3 days",
    "maxResults": 10
}

run = client.actor("actor-forge/public-tenders").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
