YouTube Shorts Scraper (Official API) — By Keyword & Channel

Bring your own free YouTube API key. Get YouTube Shorts from any channel (YouTube's own Shorts list, not a guess) or by keyword, with views, likes, comments, duration, tags and publish date, via the official YouTube Data API v3. No scraping, no blocks. $1.20 per 1,000 Shorts.

What it does

Bring your own free YouTube API key and get YouTube Shorts from the official YouTube Data API v3, with no scraping, no proxies and no blocks. Two ways in, in one run:

- Shorts by channel: paste channel URLs, @handles or channel IDs. Each channel's Shorts come from YouTube's own Shorts playlist for that channel, so the list is exact (Shorts only, no long videos, no guessing from the Shorts tab), newest first. If a channel has no Shorts playlist, its uploads are checked by duration instead, and every row says which method was used (shortSource). - Shorts by keyword: search terms run through YouTube search with the *short* length filter, then each result is checked: only videos of 3 minutes or less that are not live are kept (YouTube allows Shorts up to 3 minutes since October 2024). Optional region, language, date range and sort order.

Limits and honest notes

  • You need your own free YouTube Data API v3 key (see the 4-step guide above). Without one the run finishes at once with a single free row of instructions, and nothing is charged.
  • Quota is per Google Cloud project: 10,000 units/day for free. channels.list, playlistItems.list and videos.list cost 1 unit each, and search.list costs 100. A quotaExceeded error stops the run cleanly; Shorts already delivered are kept, and the failed call is free.
  • Channel Shorts come from YouTube's per-channel Shorts playlist (UUSH…). It is a system playlist YouTube does not document, so it could change; if it is missing for a channel, the actor falls back to checking uploads by duration (3 minutes or less, not live) and marks those rows shortSource: duration-heuristic. The fallback scans at most 250 uploads (or 5 × Max Shorts per channel) so a long-form channel cannot eat your quota.
  • Keyword results use the duration check, because the API has no Shorts flag in search: a regular video of 3 minutes or less can appear. Results longer than 3 minutes are dropped and never charged, so a keyword can return fewer Shorts than Max search results.
  • Only public data the API returns for an API key: no dislike counts (removed by YouTube), no revenue, no watch time, no audio/sound name and no Shorts remix data. Like counts hidden by the creator come back as null.
  • Search returns at most about 500 results per keyword (a YouTube limit), and results can differ from what the YouTube app shows.
  • You must refresh or delete stored API data within 30 days (YouTube Developer Policies III.E.4). We keep nothing after the run.
  • The run's spend limit is respected: each page of Shorts is charged before it is delivered, and the run stops cleanly at the cap. Free rows (type error) cover invalid inputs and channels that are not found.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~youtube-shorts-api/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"channels": ["https://www.youtube.com/@MrBeast"], "maxVideosPerChannel": 10}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "channels": [
    "https://www.youtube.com/@MrBeast"
  ],
  "maxVideosPerChannel": 10
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~youtube-shorts-api/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "channels": [
        "https://www.youtube.com/@MrBeast"
    ],
    "maxVideosPerChannel": 10
}

run = client.actor("actor-forge/youtube-shorts-api").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
