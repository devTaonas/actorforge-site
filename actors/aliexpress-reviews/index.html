AliExpress Reviews Scraper: Ratings, Photos, Countries

Get AliExpress buyer reviews for any product ID or URL: star rating, review text, English translation, buyer country, SKU bought, date, review photos, follow-up reviews, plus the product's rating breakdown. No browser, no login. $0.40 per 1,000 reviews.

Run on Apify →See pricing

What it does

Pull AliExpress product reviews in bulk, with English translations, without a browser or a login. Give it AliExpress product IDs or item URLs and it returns every buyer review AliExpress shows: star rating (1–5), the review text, AliExpress's English translation, the buyer's country, the SKU bought (colour, size, version), the review date, buyer photos, helpful votes, the shipping method, and follow-up reviews written days later. Each run also saves the product's rating breakdown (average, total, five-star to one-star counts, positive %). Filter to reviews with photos or with follow-ups. Use it for dropshipping and sourcing due diligence (check quality before you list a product), product research and competitor analysis, sentiment analysis and AI summaries of buyer feedback, finding recurring defects, and review datasets for analysis or AI agents. Pair it with the AliExpress Product Search Scraper to review the products you find. Buyer names stay masked as AliExpress shows them. $0.40 per 1,000 reviews, with no compute bill on top; products without reviews return a free status row.

Limits and honest notes

  • Responsible use: you are responsible for using the data in line with AliExpress's terms and with data-protection law where you are. Reviews are written by private buyers: do not use them to profile people. This actor is not affiliated with, endorsed by or sponsored by AliExpress or Alibaba Group.
  • It reads the public review data that AliExpress product pages load (feedback.aliexpress.com, which publishes no robots.txt; www.aliexpress.com's robots.txt explicitly allows its reviews API). There is no login, no cookies, no proxies and no CAPTCHA solving; it sends an honest user agent (ActorForge-AliExpressReviews) and waits at least 1 s between requests.
  • Buyer names are shown masked by AliExpress (for example "a***r"); anonymous buyers have no name. Buyer avatars and gender are never collected.
  • The English translation is AliExpress's own machine translation; it is left empty when the review is already in English.
  • AliExpress shows a limited number of reviews per product (usually the most relevant few thousand). The review endpoint is undocumented and may change; if it does, runs return a free page-changed row.
  • If AliExpress answers with a block, the run stops at once, keeps the reviews already delivered and adds a free status row.
  • Respects your run budget: set a maximum total charge and the run stops cleanly at the cap, with nothing charged twice.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~aliexpress-reviews/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"products": ["1005006177200517"], "maxReviewsPerProduct": 20}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "products": [
    "1005006177200517"
  ],
  "maxReviewsPerProduct": 20
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~aliexpress-reviews/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "products": [
        "1005006177200517"
    ],
    "maxReviewsPerProduct": 20
}

run = client.actor("actor-forge/aliexpress-reviews").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
