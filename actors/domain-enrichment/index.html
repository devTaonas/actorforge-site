What it does

Domain enrichment in one call: give a domain, get a company row. Made for Clay enrichment columns, CRMs and AI agents: map your Domain column to the single domain field (a URL or a work email works too) and get back company enrichment from the domain. You get the company name (JSON-LD Organization or og:site_name), description and language, a company logo with ranked candidates (JSON-LD logo, header logo, apple-touch-icon, web-manifest icons, SVG icon, og:image, favicon), so it works as a free company logo API replacement for Clearbit Logo. It also returns the theme colour, the company's own social links (LinkedIn company page, X/Twitter handle, Facebook page, Instagram, YouTube, GitHub org, TikTok), the contact page and generic company emails only (info@, sales@, support@). On the infrastructure side you get the tech stack (CMS, e-commerce platform, analytics and 7,600+ technologies from the open Wappalyzer fingerprints), MX / email provider (Google Workspace, Microsoft 365…), SPF and DMARC policy, RDAP (WHOIS) registrar, registration date and domain age, SSL issuer and expiry, HTTP status, final URL, redirect chain, response time, and whether robots.txt, a sitemap and a web manifest exist. One row replaces 3-4 single-purpose Clay columns (tech lookup, WHOIS, logo, socials). It uses plain HTTP (no browser) at 256 MB, respects robots.txt and never returns people data: no personal profiles, no first.last@ addresses, no registrant contacts. $4 per 1,000 domains, charged only when the homepage loaded; unreachable, bot-blocked and robots-disallowed domains are free.

Limits and honest notes

  • Reads static HTML (one homepage request, plus robots.txt, the web manifest, a sitemap probe and the contact page). Social links, logos or emails that a site injects only with JavaScript are not seen.
  • Emails: only generic role mailboxes on the company's own domain (info@, hello@, sales@, support@, press@, careers@ and similar) are returned. Anything that looks personal (firstname@, first.last@, initials) and addresses on other domains are dropped. Many companies publish no email at all.
  • Social links are company profiles only: LinkedIn /company/ pages (never /in/ people), the site's X/Twitter handle, Facebook pages, Instagram, YouTube channels, GitHub organisations and TikTok accounts. Share buttons and posts are ignored.
  • Logo candidates are URLs taken from the site itself (no third-party favicon service). The top candidate is a heuristic: JSON-LD logo, then a header logo image, then the largest touch/manifest icon. Check logoCandidates when you need a specific format.
  • Sites behind bot protection (Cloudflare challenge, 403) are returned as blocked and not charged. robots.txt is respected for every page: a disallowed homepage gives a free robots-disallowed row.
  • RDAP (WHOIS) data depends on the registry: some ccTLDs (for example .so, .es) have no public RDAP service, so registrar and dates stay empty. Registrant and contact data are never read.
  • Technologies come from webappanalyzer fingerprints matched against headers, cookies, HTML and DNS; browser-only signals are not checked.
  • The run's spend limit is respected: each domain is charged once, before its row is delivered; when the limit is reached the run stops.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~domain-enrichment/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"domain": "stripe.com"}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "domain": "stripe.com"
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~domain-enrichment/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "domain": "stripe.com"
}

run = client.actor("actor-forge/domain-enrichment").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
