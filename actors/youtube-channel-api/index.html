Get All Videos From a YouTube Channel, Plus Channel Stats

Paste an @handle, channel URL or channel ID and get the channel's stats row followed by its uploads, newest first, each with full video stats.

Run on Apify →See pricing

What it does

YouTube Studio only exports your own channel, and the youtube.com page for someone else's channel loads videos a screen at a time. This actor lists a channel's uploads through the official YouTube Data API v3 instead, using a free API key you create yourself, so you get a complete, structured list without scrolling or copying.

For each channel you get one channel row (title, @handle, description, country, subscriber count, total views, video count, created date, uploads playlist ID, avatar and topic categories), followed by one row per upload with title, description, published date, duration, views, likes, comment count, tags, category, thumbnails, live status and made-for-kids flag. Input can be youtube.com/@handle, /channel/UC… or /user/name URLs, bare @handles or channel IDs.

It is built for influencer vetting, competitor channel tracking, content audits and YouTube analytics dashboards. Channel rows cost $0.50 per 1,000 and video rows $0.40 per 1,000, and one free key covers about 250,000 channel-mode video rows a day.

How it works

  1. Each channel input is resolved to a channel ID with channels.list, which also returns the channel's stats and uploads playlist.
  2. The uploads playlist is paged with playlistItems.list, newest first, until maxVideosPerChannel is reached or an upload is older than publishedAfter.
  3. Video IDs are enriched with videos.list in batches of 50, so every upload row carries duration, tags and engagement counts.
  4. With includeShorts off, videos of 3 minutes or less that are not live are dropped, because the API itself does not flag Shorts.
  5. Channels that are not found produce a free error row, and a channel with no public uploads still returns its channel row.

Use cases

Vet an influencer before a deal

Pull a creator's last 100 or 200 uploads and look at views, likes and comments per video rather than the headline subscriber number. Upload frequency and recent performance are visible straight from the published dates and stats.

Track competitor channels

Schedule a run over a list of competitor @handles with publishedAfter set to last week, so each run only pages through new uploads. Paging stops at older videos, which keeps quota use low.

Audit your own back catalogue

Export every public upload with tags, category, duration and engagement into one table to find old videos worth updating, tag gaps, or formats that consistently underperform.

Channel stats only, at scale

Set maxVideosPerChannel to 0 to get just the channel row: subscribers, total views, video count, country and created date. That is a cheap way to size a long list of channels before deciding which to dig into.

Limits and honest notes

  • You need your own free YouTube Data API v3 key (see the 4-step guide above). Without one the run stops at once with instructions, and nothing is charged.
  • Quota is per Google Cloud project: 10,000 units/day for free. Unit costs: videos.list, channels.list, playlistItems.list, commentThreads.list and comments.list cost 1 unit each, and search.list costs 100. A quotaExceeded error stops the run cleanly; rows already delivered are kept, and the failed call is free.
  • Only public data the API returns for an API key: no private or unlisted-by-ID-only details, no dislike counts (removed by YouTube), no revenue, no watch time, and no subscriber lists. Channels that hide their subscriber count give subscriberCount: null.
  • Like counts that the creator hides come back as null. Counts are YouTube's own; subscriber counts are rounded by YouTube to 3 significant figures.
  • Free rows (type error) cover invalid inputs, videos and channels that are not found, private or deleted, and videos with comments disabled.
  • You must refresh or delete stored API data within 30 days (YouTube Developer Policies III.E.4). We keep nothing after the run.
  • The run's spend limit is respected: each page of rows is charged before it is delivered, and the run stops cleanly at the cap.
  • The uploads list contains public videos only. A channel with no public uploads gives the channel row and no videos. Custom /c/name URLs are resolved as the @handle with the same name; if that fails, paste the @handle or channel ID instead.
  • isShort is a heuristic (3 minutes or less and not live), because the API does not flag Shorts. Turning includeShorts off also drops regular videos of 3 minutes or less.

FAQ

How do I download a list of all videos from a YouTube channel?

Paste the channel's @handle, URL or ID into channels, set maxVideosPerChannel high enough to cover the catalogue, and run. You get a channel row and then one row per public upload, newest first, which you can download as CSV, JSON or Excel from the dataset.

Can I get only recent uploads from a channel?

Yes. Set publishedAfter to a date such as 2026-01-01. The actor stops paging once it reaches older uploads, which also saves quota.

Does it include unlisted or private videos?

No. The uploads list contains public videos only. A channel with no public uploads gives the channel row and no video rows.

Why is the subscriber count rounded or empty?

YouTube rounds subscriber counts to 3 significant figures in the API, and channels that hide their subscriber count return subscriberCount: null. These are YouTube's own figures.

Do custom /c/ channel URLs work?

Custom /c/name URLs are resolved as the @handle with the same name. If that does not find the right channel, paste the @handle or the UC… channel ID instead.
