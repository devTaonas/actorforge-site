Airbnb Listing Details by URL: Amenities, Ratings, Host, Map

Turn Airbnb room URLs or listing IDs into full listing rows: title, property type, guests, bedrooms, beds, baths, amenities, rating and category ratings, review count, host summary, map location, house rules and photos. No browser, no login. $1.50 per 1,000 listings.

What it does

Get the full details of any Airbnb listing from its URL, without a browser, a login or a proxy bill. Paste Airbnb room URLs (any country domain) or plain listing IDs, from your own lists, a spreadsheet, or another tool, and get one clean row per listing: title, property type, room type, guest capacity, bedrooms, beds and bathrooms, the full amenities list (grouped, plus what is not included), overall rating and the six category ratings (cleanliness, accuracy, check-in, communication, location, value), review count, Guest favourite and Superhost flags, a host summary (first name, years hosting, host rating and review count, response rate and time, business or individual host), map coordinates and area, breadcrumbs (country → region → district), house rules, safety notes, sleeping arrangements, highlights, the description as plain text, and photo URLs. Use it for short-term rental market research, competitor and portfolio monitoring for property managers, enriching listing lists with amenities and ratings, investment analysis, and building rental datasets for analysis or AI agents. Removed or private listings come back as free status rows. $1.50 per 1,000 listings, with no compute bill on top.

Limits and honest notes

  • Responsible use: you are responsible for using the data in line with Airbnb's terms and with data-protection law (such as the GDPR) where you are. Host first names are personal data: do not use them to profile or contact people. This actor is not affiliated with, endorsed by or sponsored by Airbnb.
  • Input is room URLs or IDs only. Airbnb's robots.txt disallows its search pages and APIs, so this actor does not search by city or dates. Find listings first (for example from your own lists or Airbnb's shared links), then enrich them here.
  • No nightly prices or availability: exact prices need travel dates and come from Airbnb's booking API, which robots.txt disallows.
  • Only the room page is read (robots.txt is checked first). There is no login, no cookies, no proxies and no CAPTCHA solving; it sends an honest user agent (ActorForge-AirbnbListing) and waits at least 2 s between pages, so expect about 25 listings per minute.
  • If Airbnb answers with a block or a challenge, the run stops at once, keeps the listings already delivered and adds a free status row. Removed, private or unknown listings give a free not-found row.
  • Coordinates are Airbnb's public map point, which is usually approximate (isExactLocation says so). No reviews text, host contact details or host profile photos are collected.
  • The domain sets the language: airbnb.de gives German text, airbnb.com English. Airbnb may redirect a domain to your region's site; the actor follows that once.
  • Respects your run budget: set a maximum total charge and the run stops cleanly at the cap, with nothing charged twice.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~airbnb-listing-details/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"roomUrls": ["https://www.airbnb.com/rooms/20669368"]}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "roomUrls": [
    "https://www.airbnb.com/rooms/20669368"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~airbnb-listing-details/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "roomUrls": [
        "https://www.airbnb.com/rooms/20669368"
    ]
}

run = client.actor("actor-forge/airbnb-listing-details").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
