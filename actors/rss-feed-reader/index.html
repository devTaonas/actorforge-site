RSS Feed Reader — RSS, Atom & JSON Feed to JSON

Read RSS 2.0, RSS 1.0/RDF, Atom and JSON Feed into clean JSON rows: title, link, author, dates, categories, summary, image, podcast enclosure and duration. Paste a website and its feed is found automatically. Filter by date and keywords, dedupe across feeds. $0.40 per 1,000 items.

Run on Apify →See pricing

What it does

Turn any RSS, Atom or JSON feed into clean JSON rows. Paste feed URLs, or just a website or blog address: the feed is found automatically from the page's feed link tags, or at the usual paths like /feed and /rss.xml. Every item comes back in one consistent shape, whatever the format (RSS 2.0, RSS 1.0/RDF, Atom 1.0, JSON Feed 1.1): title, link, guid, author byline, published and updated dates normalised to ISO 8601, categories, a plain-text summary, the item image (media:thumbnail, media:content, itunes:image), plus feed title, link and language. Podcast feeds also give you the audio enclosure (URL, type, size), duration in seconds, and episode and season numbers. Optionally add the full article content as plain text and HTML. Filter by publish date ("7 days", "24 hours" or a date) and keywords, take the newest N items per feed, and remove duplicates across feeds. Broken markup, CDATA, HTML entities, odd date formats, relative links and non-UTF-8 encodings like windows-1252 are handled for you. Use it for news monitoring, content aggregation, alerting, podcast catalogues, AI agents and RAG pipelines. $0.40 per 1,000 items, with only the negligible platform start fee and no compute bill on top. Feeds that fail and duplicates you filter out are never charged.

Limits and honest notes

  • Reads public feeds only. Feeds behind a login, paywall token or bot check are reported as an error row (free).
  • Returns what the feed currently contains, usually the latest 10 to 100 items. Older items that have dropped out of the feed can't be recovered.
  • Website URLs are checked one level deep: the feed links on that page, then /feed, /rss, /rss.xml, /atom.xml, /feed.xml and /index.xml at the site root. robots.txt is respected for discovered feeds. If a site's robots.txt can't be fetched (HTTP 5xx or a network error, after one retry), no feeds are discovered on that site (RFC 9309) and the URL gets a free error row saying why.
  • Feeds up to 40 MB. Feeds over 6 MB (large podcast archives) are read from their first 500 items, or twice your per-feed maximum if that's higher. Items are taken newest first.
  • The summary is plain text up to 1,000 characters. Full content (when enabled) is capped at 200,000 characters per item.
  • Author fields are bylines only: email addresses in feed author fields are removed.
  • With a publish-date filter, items without any date are left out.
  • Respects your run budget: set a maximum total charge and the run stops cleanly at the cap, with no item charged twice.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~rss-feed-reader/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"feeds": ["https://hnrss.org/frontpage", "https://feeds.bbci.co.uk/news/rss.xml"]}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "feeds": [
    "https://hnrss.org/frontpage",
    "https://feeds.bbci.co.uk/news/rss.xml"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~rss-feed-reader/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "feeds": [
        "https://hnrss.org/frontpage",
        "https://feeds.bbci.co.uk/news/rss.xml"
    ]
}

run = client.actor("actor-forge/rss-feed-reader").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
