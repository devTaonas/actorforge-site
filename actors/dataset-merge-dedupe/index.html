Merge & Deduplicate Datasets - Only New Items, Join, CSV/XLSX

Merge Apify datasets, CSV, JSON, JSONL or Excel files and pasted rows into one clean dataset: remove duplicates by any fields (case and whitespace normalised), keep only items new since your last run, left/inner join on a key, flatten nested JSON. $0.05 per 1,000 rows out.

Run on Apify →See pricing

What it does

Combine scraper outputs into one clean, duplicate-free dataset, reliably. Pick any number of Apify datasets, add CSV, TSV, JSON, JSON Lines or Excel (XLSX) file URLs or paste rows as JSON, and get one merged dataset with duplicates removed by the fields you choose (email, URL, product ID, company name + city, or the whole row). Values are normalised before comparing, so " ACME Ltd" and "acme ltd", or 42 and "42", count as the same, while your rows stay exactly as they were. Turn on only new items and the actor remembers what it delivered (in a store on your own account), so a scheduled scrape outputs only the listings, jobs, leads or prices that are new since the last run, perfect for alerts, CRMs and Slack/Make/n8n/Zapier pipelines. Add a left or inner join on a key (e.g. enrich leads with a company lookup table by domain), flatten nested JSON into spreadsheet columns, keep or drop fields, and tag each row with its source. It streams datasets page by page, so millions of rows work, and it runs with limited permissions: it can read only the datasets you pick. Export the result as CSV, Excel, JSON, JSONL or XML from the dataset. $0.05 per 1,000 rows delivered; duplicates and skipped rows are free.

Limits and honest notes

  • Sources are read in order (pasted rows, then datasets, then files) and the first occurrence of each key is kept. Rows whose dedupe fields are all empty are never treated as duplicates.
  • Dedupe keys are kept in memory as 53-bit hashes: about 5–10 million unique keys per run at 1 GB (raise the memory for more). The chance of two different keys colliding is negligible (about 1 in 10,000 at 1 million keys).
  • Only new items: the remembered keys live in the key-value store "dataset-merge-dedupe-history" on your own account (one record per history name, newest 5 million keys). Delete the record to start over. Rows not delivered (for example after hitting the spend limit) are not remembered.
  • Datasets: with limited permissions the run can read only the datasets selected in the Datasets / lookup dataset fields (or passed by ID in the API input). A dataset that cannot be read is reported in the run summary and the other sources are still merged.
  • Files are downloaded once (up to 100 MB each) and parsed in memory. CSV values stay text (no type guessing, so IDs, postcodes and phone numbers keep their leading zeros); XLSX reads the first visible sheet with typed values and ISO dates. Private and internal network addresses are refused at every redirect hop.
  • Joins hold the lookup side in memory (up to 500,000 rows; the first row per key wins). Lookup fields fill only fields that are missing or empty in the row; use a prefix to keep both.
  • When a run delivers nothing (no sources, empty sources, all duplicates or nothing new), it adds one free row with _status and _message explaining why and still succeeds.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~dataset-merge-dedupe/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"rows": [{"id": 1, "name": "a"}, {"id": 1, "name": "a"}, {"id": 2, "name": "b"}], "dedupeFields": ["id"]}'

JavaScript (Node.js)

      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",

    body: JSON.stringify(input),
  }

const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "rows": [
        {
            "id": 1,
            "name": "a"
        },
        {
            "id": 1,
            "name": "a"
        },
        {
            "id": 2,
            "name": "b"
        }
    ],
    "dedupeFields": [
        "id"
    ]
}

run = client.actor("actor-forge/dataset-merge-dedupe").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
