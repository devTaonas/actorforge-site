Otodom, Storia & Imovirtual Property Scraper (PL, RO, PT)

Scrape property listings from Otodom (Poland), Storia (Romania) and Imovirtual (Portugal) search results: price, price per m², admin fee, area, rooms, floor, street, district, city, agency or developer, private-owner flag, photos and dates. No browser. $0.60 per 1,000 listings.

Run on Apify →See pricing

What it does

One scraper for the OLX Group property portals in Poland, Romania and Portugal: Otodom, Storia and Imovirtual. Run a search on otodom.pl, storia.ro or imovirtual.com (city, district, price, size, rooms, market, sort…), paste the URL, and get one clean row per property from the public results pages: title, total price and currency (PLN or EUR), price per m², the monthly admin fee (czynsz), area and plot area in m², rooms, floor, estate type (flat, house, plot…) and transaction (sale or rent), street, neighbourhood, district, city and region, feature tags (balcony, garage, lift…), advertiser type (private, agency or developer), the agency or developer name and development name, promoted and exclusive flags, photo URLs, and the listing and refresh dates. Use it for Polish, Romanian and Portuguese property price research, price-per-m² maps by district, rental market analysis, tracking new developments and developers, agency competitor monitoring, and real-estate datasets for analysis or AI agents. Private owners' names and agents' personal names are never collected. $0.60 per 1,000 listings, with no compute bill on top; problems return a free status row instead of failing.

Limits and honest notes

  • Responsible use: you are responsible for using the data in line with the terms of Otodom, Storia and Imovirtual and with data-protection law (GDPR). This actor is not affiliated with, endorsed by or sponsored by OLX Group, Otodom, Storia or Imovirtual.
  • It reads only the public results pages, which the sites' robots.txt allow, and checks robots.txt before every page; it never calls the disallowed /api/query endpoint or map views. There is no login, no cookies, no proxies and no CAPTCHA solving; it sends an honest user agent (ActorForge-Otodom) and waits at least 1.5 s between pages.
  • Results-page data only (36 listings per page): no full description, contact phone or detail-page attributes such as heating or year built.
  • Personal data is left out: for private owners there is no name, and agencies' named staff members are dropped. Agency and developer names are business data. Streets are given only when the advertiser publishes them.
  • If a site answers with a block (the OLX Group sites sit behind a CloudFront firewall), the run stops at once, keeps the listings already delivered and adds a free status row. Try again later or with fewer pages.
  • Texts are in the site's language (Polish, Romanian or Portuguese); rooms and floors are also given as numbers where the site uses a fixed scale.
  • Respects your run budget: set a maximum total charge and the run stops cleanly at the cap, with nothing charged twice. A run with no results returns one free status row.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~otodom-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"searchUrls": ["https://www.otodom.pl/pl/wyniki/sprzedaz/mieszkanie/mazowieckie/warszawa/warszawa/warszawa"], "maxItems": 36, "maxPagesPerSearch": 1}'

const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "searchUrls": [
        "https://www.otodom.pl/pl/wyniki/sprzedaz/mieszkanie/mazowieckie/warszawa/warszawa/warszawa"
    ],
    "maxItems": 36,
    "maxPagesPerSearch": 1
}

run = client.actor("actor-forge/otodom-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
