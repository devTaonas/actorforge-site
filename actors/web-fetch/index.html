Web Fetch — Any URL to Markdown or Text for AI Agents

Fetch any URL as clean Markdown and plain text for AI agents, MCP and RAG: web pages, PDF, Word, Excel, PowerPoint, EPUB, CSV and JSON. One url in, one result with title and token estimate out. Static HTML, no JavaScript rendering. $1 per 1,000 pages.

What it does

Fetch any URL and get it back as clean Markdown and plain text: one URL in, one result out. It is a web fetch tool for AI agents, MCP clients (Claude, Cursor, ChatGPT), LangChain/LlamaIndex RAG pipelines and n8n/Make/Zapier flows. Give it a url (or a list) and it works out what the link really is, then returns LLM-ready Markdown and plain text in the same row, with the title, metadata, a tokenEstimate and the route used. Web pages keep only the main content (Mozilla Readability), with headings, lists, tables and links. Documents work in the same call: PDFs (text layer, up to 100 pages by default), Word, Excel and PowerPoint, OpenDocument, EPUB, CSV and JSON. OCR for images and scanned PDFs is one toggle away, off by default so calls stay fast and cheap. What it does not do: it fetches static HTML with no browser, so it does not render JavaScript and does not get around bot protection, CAPTCHAs or logins; app-shell pages and refused requests come back as free error rows. It sends an honest crawler user agent and respects robots.txt. $1 per 1,000 web pages, $2 per 1,000 documents ($3 per 1,000 OCR pages when you turn OCR on), with no compute bill on top. Failed fetches, unsupported files, pages blocked by robots.txt and empty results are never charged.

Limits and honest notes

  • Web pages are fetched as static HTML, with no browser. Pages that build their content with JavaScript (an empty app shell) are reported, not charged; use a browser-based crawler for those. This actor converts the URLs you give it and does not crawl sites (see Website to Markdown for that).
  • OCR is off by default in this listing. With it off, images and PDF pages without a text layer are reported with a clear reason and not charged. Turn on "ocr" to read them (up to 20 scanned pages per PDF by default, set by maxOcrPages; 7 languages). For 29 languages and word boxes, use OCR to Text.
  • Legacy binary Office files (.doc, .xls, .ppt), RTF, OpenDocument presentations (.odp), HEIC/AVIF images and SVG are not supported. They are reported with a clear reason and never charged.
  • Spreadsheets are cut at 1,000 rows per sheet by default (maxRowsPerSheet), and very large results are cut at about 3.5 million characters. Cut rows are marked truncated: true.
  • PDFs are read up to their first 100 pages by default in this listing; raise maxPdfPages (up to 2,000) for longer PDFs.
  • Files up to 50 MB. Password-protected PDFs and pages behind a login can't be read.
  • Polite by design: it sends an honest crawler user agent (ActorForge-AnyUrlToMarkdown) and does not pose as a browser. When a site answers 429 (rate limited) or 403 (refused), that URL is retried at most once (429 only, after Retry-After up to 30 s) and the remaining URLs on the same host are skipped as free error rows.
  • tokenEstimate is characters divided by 4. That is a good guide for English with GPT and Claude tokenizers, not an exact count.
  • Respects your run budget: set a maximum total charge and processing stops cleanly at the cap. No result is delivered without being paid for, and none is charged twice.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~web-fetch/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://en.wikipedia.org/wiki/Markdown"}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "url": "https://en.wikipedia.org/wiki/Markdown"
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~web-fetch/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "url": "https://en.wikipedia.org/wiki/Markdown"
}

run = client.actor("actor-forge/web-fetch").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
