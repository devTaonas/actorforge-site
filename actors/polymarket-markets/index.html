Polymarket Markets Scraper: Prices, Volume, Liquidity & History

Polymarket prediction-market data from the official public API: every market's outcomes and prices (implied probability), bid/ask, 1h/24h/1w price change, volume, liquidity, dates, event and tags, plus optional price history. Search, tags or event URLs. $1 per 1,000 markets.

Run on Apify →See pricing

What it does

Polymarket data in clean rows, from Polymarket's own public API. List the biggest markets by 24-hour volume (or by liquidity, total volume or end date), or narrow it down with search terms, tags or event URLs. Every row is one market: the question, each outcome with its current price (the market's implied probability, 0 to 1), yes and no price, last trade, best bid and ask, spread, 1-hour, 24-hour and 1-week price change, total, 24h, 1-week and 1-month volume, liquidity, start and end dates, open/closed and accepting-orders flags, parent event, tags, resolution source and optionally the full resolution rules and a price history series. Filter by status, minimum volume or liquidity and end-date window. Use it for forecasting research and journalism, dashboards and alerts, academic studies of prediction markets, and comparing crowd forecasts with polls or models. $1 per 1,000 markets, with no compute bill on top; problems return a free status row instead of failing.

Limits and honest notes

  • Responsible use: this is market data only. Nothing in it is financial, investment or betting advice, and prices are not predictions by ActorForge. Prediction-market trading is restricted or illegal in some countries; follow your local law and Polymarket's terms. This actor is not affiliated with, endorsed by or sponsored by Polymarket.
  • It reads only Polymarket's documented public read APIs (gamma-api.polymarket.com, and clob.polymarket.com for price history), with no key, no login, no wallet and no trading, at most four requests per second with an honest user agent (ActorForge-Polymarket).
  • Prices are the latest values Polymarket publishes and can move within seconds; check the scrapedAt time. Multi-outcome events (for example "Who will win...?") are returned as one row per candidate market, each with its own yes and no price.
  • If Polymarket refuses a request or rate-limits the run, the run stops, keeps the markets already delivered and adds a free status row. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap. Unknown events and empty searches return a free status row.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~polymarket-markets/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"maxItems": 20}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "maxItems": 20
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~polymarket-markets/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "maxItems": 20
}

run = client.actor("actor-forge/polymarket-markets").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
