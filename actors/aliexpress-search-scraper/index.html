AliExpress Product Search Scraper: Prices, Sold Count, Ratings

Search AliExpress by keyword or search URL and get product rows: product ID, title, price, original price, discount, currency, sold count, star rating, Choice badge, images and product URL. About 60 products per page, no browser. $0.70 per 1,000 products.

Run on Apify →See pricing

What it does

An AliExpress product search scraper that returns clean product rows from a keyword, with no browser and no proxy bill. Give it keywords like "phone case" or "led strip", or paste AliExpress search URLs with your own filters, and it reads the public search result pages (about 60 products each) and returns, for every product: product ID, title, sale price, original price, discount %, currency, sold count (e.g. "10K+ sold" plus the exact count when AliExpress gives it), star rating, the Choice badge, main image and gallery images, AliExpress category IDs, the date the listing went live, and the product URL. Sort by best match, orders or price, and page through up to 60 result pages per search. Use it for dropshipping product research, finding winning products and trending items, price monitoring and competitor tracking, sourcing and supplier shortlists, and building product datasets for analysis or AI agents. Sponsored listings are left out by default (switch them on if you want them, flagged isSponsored). $0.70 per 1,000 products, with no compute bill on top; problems such as a blocked page or no results return a free status row instead of failing.

Limits and honest notes

  • Responsible use: you are responsible for using the data in line with AliExpress's terms and with data-protection law where you are. This actor is not affiliated with, endorsed by or sponsored by AliExpress or Alibaba Group.
  • It reads only public search result pages (/w/wholesale-….html), which AliExpress's robots.txt allows. robots.txt is checked before every page. There is no login, no cookies, no proxies and no CAPTCHA solving; it sends an honest user agent (ActorForge-AliExpressSearch) and waits at least 1.5 s between pages.
  • If AliExpress answers with a block or a slider challenge, the run stops at once, keeps the products already delivered and adds a free status row. Large runs are more likely to be refused; split them into several smaller runs.
  • Prices and currency are the ones AliExpress shows to the server's location (usually USD on Apify's US servers). They can differ from what you see in your own country, and sale prices change often.
  • Search data only: no product descriptions, variants, shipping costs or seller details (those are only on product pages, which load in the browser). The sold count is AliExpress's own figure; when only a rounded text like "10K+ sold" is shown, soldCount is the lower bound.
  • Sponsored products are skipped unless you switch on includeSponsored; their search data often has no price.
  • Respects your run budget: set a maximum total charge and the run stops cleanly at the cap, with nothing charged twice. A run with no results returns one free status row.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~aliexpress-search-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"queries": ["phone case"], "maxItems": 20, "maxPagesPerSearch": 1}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "queries": [
    "phone case"
  ],
  "maxItems": 20,
  "maxPagesPerSearch": 1
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~aliexpress-search-scraper/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "queries": [
        "phone case"
    ],
    "maxItems": 20,
    "maxPagesPerSearch": 1
}

run = client.actor("actor-forge/aliexpress-search-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
