Contact Details Scraper — Company Emails, Phones & Socials

Company contacts only, no personal emails. Domains in, one row each: role emails (info@, sales@), phones in E.164, address, company socials and contact page, from the home page and up to 4 contact/imprint/about pages. $3 per 1,000 domains with contacts; none found = free.

What it does

Company contacts only, no personal emails. This contact details scraper reads a company's own website and returns one row per domain with the company's role emails (info@, sales@, support@, hello@, contact@, press@…), phone numbers in E.164 (+4930123456), the postal address (street, city, postcode, country), the company's social profiles (LinkedIn company page, X/Twitter, Facebook, Instagram, YouTube, TikTok, GitHub) and the contact page URL. Paste a list of domains, URLs or work emails. For each site it reads the home page plus up to 4 contact, imprint/Impressum, about, support or legal pages found from the site's own links. It takes data from JSON-LD Organization/LocalBusiness markup, mailto: and tel: links, Cloudflare-protected emails, simple "info [at] acme [dot] com" spellings and the footer. GDPR-minded by design: addresses that look like a person's (firstname@, first.last@, initials) are dropped and only counted (personalEmailsDropped), LinkedIn /in/ profiles are never returned, and Person markup is never read. That makes it a fit for B2B lead lists, CRM and Clay enrichment, supplier directories and AI agents that need *how to reach the company*, not its staff. Plain HTTP at 256 MB, robots.txt respected, an honest user agent, and it stops on 403, 429 or CAPTCHA pages instead of pushing harder. $3 per 1,000 domains with contacts found. Domains where nothing is found, unreachable, blocked and robots-disallowed sites are free.

Limits and honest notes

  • Company contacts only: an email is kept only when its local part is a role or department (info, sales, support, hello, contact, press, office, billing, careers, privacy and about 200 more, in several languages) and it sits on the company's own domain, or on a free-mail domain with the brand name in it (acmeplumbing@gmail.com). Name-like addresses are dropped and counted in personalEmailsDropped. If you need named people, this is not the tool.
  • Many large companies publish no email at all, only forms (contactFormDetected tells you). Expect emails for roughly half of company sites; phones, address or socials fill most of the rest.
  • Reads static HTML only (no browser). Contacts that a site injects with JavaScript, or shows only as images, are not seen. Only the simple obfuscations are decoded: Cloudflare email protection and "[at]" / "(at)" / "[dot]" spellings.
  • Phones come from JSON-LD, tel: links and labelled numbers (Tel., Phone, Telefon, Fax). National numbers are converted to E.164 when the country is clear from the address, the ccTLD or the page language; otherwise the number is returned as written. Fax numbers appear in contactDetails only.
  • Pages are picked from the home page links (contact, imprint/Impressum, about, support, legal) on the same site. With no such links, /contact is tried once.
  • robots.txt is respected for every page. A 403, 429 or CAPTCHA page on the home page gives a free blocked row; on a later page the scan of that site stops (scanStoppedBy) and the row keeps what was already found. No proxies are used.
  • The run's spend limit is respected: each domain is charged once, before its row is delivered; when the limit is reached the run stops.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~contact-details-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"domains": ["stripe.com", "bosch.de", "allbirds.com"]}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "domains": [
    "stripe.com",
    "bosch.de",
    "allbirds.com"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~contact-details-scraper/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "domains": [
        "stripe.com",
        "bosch.de",
        "allbirds.com"
    ]
}

run = client.actor("actor-forge/contact-details-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
