AI Web Extractor - Structured Data from Any Website with AI

Give URLs and a plain-English instruction (optionally a JSON schema) and get clean structured JSON per page: products, prices, contacts, articles, listings. Cheap LLM via Apify's OpenRouter, billed at cost to your own account. $3 per 1,000 pages plus tokens.

Run on Apify →See pricing

What it does

Turn any web page into structured JSON with one plain-English sentence. Give it a list of URLs and an instruction like *"Extract the product name, price and stock status"* or *"List every job opening with title, location and link"*, optionally with the exact fields you want (a simple field list or a full JSON schema), and it returns clean structured data per page: one JSON object per page, or (list mode) one row per item for listings, search results, catalogues, directories and tables. No CSS selectors, no XPath, no scraper to maintain when the site changes its layout. Each page is fetched as static HTML, cleaned and converted to compact Markdown (navigation, cookie banners, scripts and images removed), cut to your token budget and sent to a fast, cheap AI model (default Google Gemini 2.5 Flash Lite; any OpenRouter model works: GPT-4o mini, GPT-4.1 nano, Gemini 2.5 Flash, Claude, Llama, Mistral…) in JSON mode, then validated and repaired if the model's reply was cut off. Optional same-site crawl (depth 1–2) with include/exclude patterns. Use it for AI web scraping of product and price data, lead lists and company details, real estate and job listings, event pages, article metadata, LLM-ready datasets and RAG pipelines, and for AI agents that need structured web data. It is a lighter, cheaper alternative to browser-based AI scrapers: $3 per 1,000 pages plus the AI tokens at cost.

Limits and honest notes

  • AI tokens are a second, separate charge on your own Apify account, made by apify/openrouter at OpenRouter's rates (10× on the Apify free plan). They are not part of this actor's pay-per-event price and are not limited by the run's maximum total charge: use maxLlmCostUsd (default $0.10) to cap them. Each row's llmCostUsd is an estimate from the usage OpenRouter reports; your Apify billing page is authoritative.
  • No browser: pages are fetched as static HTML. Sites that render their content with JavaScript only (empty app shells) get a free status row "needs-javascript" and are not charged. Pages behind logins, CAPTCHAs or bot walls are not supported, and the actor does not try to get around them (no proxies, no browser fingerprints).
  • robots.txt is respected by default (RFC 9309), and requests identify themselves honestly as ActorForge-AIWebExtractor. Internal and private network addresses are refused at every redirect hop.
  • AI models can make mistakes. The model is told to use only what is on the page and return null for missing values, but check important data. Long pages are cut to maxInputTokens (rows say truncated: true); raise it if the data you need is far down the page.
  • Page text is treated as data: the model is told to ignore instructions inside pages (prompt-injection defence), but no defence is perfect.
  • Personal data: by default the model is told not to return private individuals' personal contact details, and personal-looking email addresses in the output are replaced (role mailboxes like info@ and sales@ are kept). Only switch allowPersonalData on if you have a lawful basis.
  • Crawling is same-host only and limited to depth 2 and maxPages charged pages; failed pages are free and don't count toward maxPages.
  • If the AI service rejects the request (no credit, rate limit, unknown model id, outage), the run stops with one free status row "llm-unavailable" explaining why, and still finishes as SUCCEEDED.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~ai-web-extractor/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"startUrls": [{"url": "https://books.toscrape.com/"}], "instruction": "List the first 5 books on the page with their title and price.", "outputMode": "list", "maxPages": 1, "maxInputTokens": 3000, "maxOutputTokens": 300}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "startUrls": [
    {
      "url": "https://books.toscrape.com/"
    }
  ],
  "instruction": "List the first 5 books on the page with their title and price.",
  "outputMode": "list",
  "maxPages": 1,
  "maxInputTokens": 3000,
  "maxOutputTokens": 300
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~ai-web-extractor/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "startUrls": [
        {
            "url": "https://books.toscrape.com/"
        }
    ],
    "instruction": "List the first 5 books on the page with their title and price.",
    "outputMode": "list",
    "maxPages": 1,
    "maxInputTokens": 3000,
    "maxOutputTokens": 300
}

run = client.actor("actor-forge/ai-web-extractor").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
