Job Market Analyst — Hiring Demand, Salaries & Skills Report

Hiring report for any role × location ("data engineer" in Berlin, "nurse" in Texas, remote): fresh postings count, top employers, seniority mix, remote share, posted salary ranges, top skills and posting age, from public job APIs and 74 career sites. $0.05 per report.

What it does

Get a job-market intelligence report for any role in any location in about a minute: *"data engineer" in Berlin*, *"nurse" in Hamburg*, *"product manager" remote*. Instead of scraping thousands of job ads and building the analysis yourself, this job market analysis tool collects a fresh sample of current postings from public job APIs and employer career sites and returns one report row with deterministic statistics: posting count (sample and total matched), top hiring employers, seniority mix (intern, junior, mid, senior, lead/staff, manager, director), remote / hybrid / on-site share, employment types, salary ranges posted by employers (min, quartiles, median and max per currency and pay period, plus the share of ads that disclose pay; never estimated or inferred figures), top skills and tools from a built-in taxonomy of 105 skills (Python, SQL, AWS, Kubernetes, Salesforce, Excel, SAP, BLS/ACLS, EHR, driving licences, languages…) plus your own keywords, and posting age (median days, posted in the last 7 / 30 days). Every report has a plain-English summary; an optional AI-written analyst briefing can be added (off by default). The newest sampled postings come along as free sample rows with links to the original ads.

Where the postings come from: 74 employer career sites on Greenhouse, Lever and Ashby (SpaceX, Databricks, OpenAI, Stripe, Anthropic, Cloudflare, Datadog, Airbnb, Coinbase, Spotify, Palantir and more), the SmartRecruiters cross-company job search (all industries, including healthcare, retail and hospitality employers), the Bundesagentur für Arbeit job search for German locations (every occupation, with radius search), Arbeitnow (Germany / Europe), and Remote OK and Jobicy for remote roles. Each source is only used where it covers the location.

Limits and honest notes

  • A report describes a fresh sample of current postings from the sources listed above (the newest matches, up to maxPostingsPerReport; posting-age figures use every match), not every job on the market. Coverage is strongest for tech, product, data and office roles worldwide (career sites + SmartRecruiters), for every occupation in Germany (Bundesagentur für Arbeit) and for remote roles. Non-tech roles outside Germany (e.g. nursing or trades in the US or UK) get smaller samples: the report always states postingsAnalyzed and postingsMatched so you can judge the sample size, and searches with fewer than minPostings matches are free.
  • LinkedIn, Indeed, Glassdoor and other sites that forbid automated access are not used. No proxies, no logins, no CAPTCHA solving; robots.txt is respected and requests identify themselves honestly as ActorForge-JobMarketAnalyst.
  • Salaries are only figures employers posted (structured pay fields, Greenhouse pay-transparency ranges, or a pay range stated in the ad text). They are grouped by currency and pay period and never converted, annualised or estimated. When an ad gives no period, it is read from the size of the figure (≥ 10,000 per year, ≤ 300 per hour) or reported as 'unspecified'.
  • Seniority comes from transparent title rules (and the source's own level label when the title says nothing); untitled mid-level roles count as 'mid/unspecified'. Skills come from keyword patterns over the title and ad text, measured on the postings whose full text was available (skillsFromDescriptions).
  • A posting matches a role when its job title contains the role as a phrase (plural and German feminine endings count, so "product manager" does not match "Product Marketing Manager"). The Bundesagentur source uses its own occupation search. Use "|" for alternative titles ("nurse | RN"). German-language searches work best with German titles on the Bundesagentur source ("Pflegefachkraft").
  • The optional AI briefing is written from the computed statistics only (no job ads are sent to the model). AI tokens are a second, separate charge on your own Apify account, made by Apify's OpenRouter actor at OpenRouter rates (10× on the Apify free plan), capped by maxLlmCostUsd. If the AI service is unavailable the report is still delivered with its rule-based summary.
  • Sources are credited by name in every report (attribution field) and every sample job links to its original ad, as Remote OK, Jobicy and Arbeitnow ask. Up to 20 reports per run; larger batches can be split across runs.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~job-market-analyst/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"roles": ["software engineer"], "locations": ["Remote"], "maxPostingsPerReport": 60, "maxDescriptionFetches": 15, "sampleJobsPerReport": 5}'

const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "roles": [
        "software engineer"
    ],
    "locations": [
        "Remote"
    ],
    "maxPostingsPerReport": 60,
    "maxDescriptionFetches": 15,
    "sampleJobsPerReport": 5
}

run = client.actor("actor-forge/job-market-analyst").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
