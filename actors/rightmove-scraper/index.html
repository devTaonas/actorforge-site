Rightmove Property Scraper: For Sale & To Rent (UK)

Scrape Rightmove search results for UK homes for sale, to rent, new homes and commercial property: price, price qualifier, bedrooms, bathrooms, type, tenure, size, address, coordinates, agent and branch, key features, listing dates and photos. No browser. $0.50 per 1,000 properties.

What it does

A Rightmove scraper for UK property listings, with no browser and no proxy bill. Run any search on rightmove.co.uk (a town, a postcode area, a drawn region, with your price, bedroom and property-type filters), paste the URL, and get one clean row per property from the public results pages: price and price qualifier (Guide price, Offers over, POA), rent frequency, bedrooms, bathrooms, property type, tenure (freehold, leasehold, share of freehold), size in sq ft, address and map coordinates, the estate agent and branch with the branch phone and page, key features, the agent's summary, first listed date and last change (new, price reduced…), let-available date, flags for featured, auction, new homes, student and commercial listings, photo and floorplan counts, and photo URLs. It works for property for sale, to rent, new homes, commercial and student searches, up to Rightmove's 42 pages per search. Use it for UK property price research, rental yield and market analysis, tracking new and price-reduced listings, estate agent and competitor monitoring, lead lists of agents by area, and property datasets for analysis or AI agents. $0.50 per 1,000 properties, with no compute bill on top; problems return a free status row instead of failing.

Limits and honest notes

  • Responsible use: you are responsible for using the data in line with Rightmove's terms and with UK data-protection law (UK GDPR). This actor is not affiliated with, endorsed by or sponsored by Rightmove.
  • It reads only the public search results pages (find.html and the area pages), which Rightmove's robots.txt allows, and checks robots.txt before every page. It never calls Rightmove's /api/ endpoints, which robots.txt disallows. There is no login, no cookies, no proxies and no CAPTCHA solving; it sends an honest user agent (ActorForge-Rightmove) and waits at least 1.5 s between pages.
  • Results-page data only: no full description, floorplan images, EPC or sold-price history from the property page. Rightmove shows at most 42 pages (about 1,000 properties) per search, so split large areas.
  • Agent names, branch phones and branch pages are business data. No private individuals' details are collected.
  • If Rightmove answers with a block or a challenge, the run stops at once, keeps the properties already delivered and adds a free status row.
  • Respects your run budget: set a maximum total charge and the run stops cleanly at the cap, with nothing charged twice. A run with no results returns one free status row.

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os

client = ApifyClient(os.environ["APIFY_TOKEN"])

for item in client.dataset(run["defaultDatasetId"]).iterate_items():

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
