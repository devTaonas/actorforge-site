YouTube Playlist Scraper (Official API) — All Videos & Stats

Bring your own free YouTube API key. Get every video in one or more YouTube playlists, in playlist order, with views, likes, comments, duration, tags and publish date, plus the playlist title, owner and size, from the official YouTube Data API v3. $0.40 per 1,000 videos.

Run on Apify →See pricing

What it does

Bring your own free YouTube API key and get every video in a YouTube playlist from the official YouTube Data API v3, with no scraping and no blocks. Paste playlist links (or watch links that contain &list=), and each video comes back in playlist order with its position, views, likes, comment count, duration, title, description, tags, category, publish date, channel and thumbnails, plus the playlist title, owner and size on every row.

Use it to export a course or tutorial series, audit a music or brand playlist, compare episodes of a series, track the stats of a channel's uploads playlist (UU…), or feed a playlist into Sheets, Notion, Make, n8n or Zapier. Private and deleted entries are skipped and never charged.

Limits and honest notes

  • Public and unlisted playlists that the API returns for an API key. Private playlists, Watch Later, Liked videos of other users and personalised mixes (RD…) cannot be read.
  • Private and deleted videos inside a playlist are skipped and not charged, so a playlist can return fewer rows than its listed size. Positions keep counting them, so gaps show where they were.
  • You need your own free YouTube Data API v3 key (see the 4-step guide above). Without one the run finishes at once with a free row of instructions, and nothing is charged.
  • Only public data the API returns for an API key: no dislike counts (removed by YouTube), no revenue and no watch time. Like counts hidden by the creator come back as null.
  • You must refresh or delete stored API data within 30 days (YouTube Developer Policies III.E.4). We keep nothing after the run.
  • The run's spend limit is respected: each page of videos is charged before it is delivered, and the run stops cleanly at the cap. If your key's quota runs out, the run stops cleanly and keeps what was delivered.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~youtube-playlist-api/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"playlistUrls": ["https://www.youtube.com/playlist?list=PLRqwX-V7Uu6ZiZxtDDRCi6uhfTH4FilpH"], "maxVideosPerPlaylist": 20}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "playlistUrls": [
    "https://www.youtube.com/playlist?list=PLRqwX-V7Uu6ZiZxtDDRCi6uhfTH4FilpH"
  ],
  "maxVideosPerPlaylist": 20
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~youtube-playlist-api/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "playlistUrls": [
        "https://www.youtube.com/playlist?list=PLRqwX-V7Uu6ZiZxtDDRCi6uhfTH4FilpH"
    ],
    "maxVideosPerPlaylist": 20
}

run = client.actor("actor-forge/youtube-playlist-api").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
