YouTube Trending Videos (Official API) — Top Videos by Country

Bring your own free YouTube API key. Get YouTube's most-popular chart for any list of countries, optionally per category (Music, Gaming, News…), with rank, views, likes, comments, duration and tags, from the official YouTube Data API v3. $0.40 per 1,000 videos.

Run on Apify →See pricing

What it does

Bring your own free YouTube API key and get YouTube's most-popular videos per country from the official YouTube Data API v3 (videos.list with chart=mostPopular), with no scraping and no blocks. List the countries you care about and, optionally, one category (Music, Gaming, News & Politics, Sports, Education …), and every chart position comes back as one row with country, rank, views, likes, comment count, duration, title, tags, category, publish date, channel and thumbnails.

YouTube retired its public Trending page in 2025, but the API still serves this most-popular chart. Use it for trend and content research, tracking what breaks out in each market, music and gaming chart monitoring, or a daily snapshot into Sheets, BigQuery, Make, n8n or Zapier (schedule the actor once a day).

Limits and honest notes

  • This is YouTube's API "most popular" chart: it is not the personalised home feed and can differ from what the YouTube app shows. YouTube serves at most 200 positions per country and category.
  • Countries or categories without a chart (some categories are not charted in some countries) come back as a free row of type error; the other countries still run.
  • You need your own free YouTube Data API v3 key (see the 4-step guide above). Without one the run finishes at once with a free row of instructions, and nothing is charged.
  • Only public data the API returns for an API key: no dislike counts (removed by YouTube), no revenue and no watch time. Like counts hidden by the creator come back as null.
  • You must refresh or delete stored API data within 30 days (YouTube Developer Policies III.E.4). We keep nothing after the run.
  • The run's spend limit is respected: each page of videos is charged before it is delivered, and the run stops cleanly at the cap. If your key's quota runs out, the run stops cleanly and keeps what was delivered.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~youtube-trending-api/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"regionCodes": ["US", "GB"], "maxResultsPerQuery": 10}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "regionCodes": [
    "US",
    "GB"
  ],
  "maxResultsPerQuery": 10
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~youtube-trending-api/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "regionCodes": [
        "US",
        "GB"
    ],
    "maxResultsPerQuery": 10
}

run = client.actor("actor-forge/youtube-trending-api").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
