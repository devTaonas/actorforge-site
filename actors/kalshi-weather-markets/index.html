Kalshi Weather Markets — Temperature & Rain Odds by City

Kalshi weather markets by city: daily high and low temperature and rain brackets with yes/no prices, volume, bracket bounds, unit and settlement station, plus the live airport observation (METAR) and 24h high/low. US and world cities. $1 per 1,000 markets.

Run on Apify →See pricing

What it does

Kalshi weather markets for any city, in clean rows, from Kalshi's own public API, with the live weather beside the odds. Type city names (New York, Chicago, Miami, Austin, Denver, Los Angeles, London, Paris, Tokyo, Seoul...) or codes (NYC, DC, EGLL) and get every daily high temperature, daily low temperature and rain bracket Kalshi lists for them, daily temperature first. Every row is one bracket: the question and outcome ("65° to 66°"), yes and no bid and ask (the implied probability), last price, 24h change, volume and open interest, and a weather block with the city, measure, bracket bounds as numbers (floor and cap), unit and settlement station (the NWS climate site, e.g. CLIMDW = Chicago Midway). With observations on (the default) each row also carries the latest airport observation (METAR) at that station: temperature in °F and °C, dew point, wind, present weather, the raw METAR and the high and low of the last 24 hours, from NOAA's aviationweather.gov. Use it for weather-trading models, mispricing alerts, forecast-vs-market dashboards and research. Also accepts weather series, event and market tickers. $1 per 1,000 markets, observations included, with no compute bill on top; problems return a free status row instead of failing.

Limits and honest notes

  • Responsible use: this is market data only. Nothing in it is financial, investment or betting advice, and prices are not predictions by ActorForge. Event-contract trading is restricted in some places; follow your local law and Kalshi's terms. This actor is not affiliated with, endorsed by or sponsored by Kalshi.
  • It reads only Kalshi's documented public market-data endpoints and NOAA's public aviationweather.gov METAR API, with no key, no login and no trading, at most four requests per second with an honest user agent (ActorForge-Kalshi). The National Weather Service API (api.weather.gov) is not used because its robots.txt disallows automated access.
  • Observations are indicative. Kalshi settles on the official daily climate report (or The Weather Company), which can differ from airport METAR by a degree or so, and "24h high/low" covers the last 24 hours, not the local calendar day. Rain brackets get no observation.
  • The settlement station is read from each market's rules ("Chicago (CLIMDW)" → KMDW) or, for international series, from the ticker (KXHIGHTEGLL → EGLL). When METAR has no recent report for a station, the observation is empty and the row is still delivered.
  • If Kalshi refuses a request or rate-limits the run, the run stops, keeps the markets already delivered and adds a free status row. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap. Unknown tickers and empty searches return a free status row.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~kalshi-weather-markets/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"cities": ["New York", "Chicago"], "maxItems": 20}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "cities": [
    "New York",
    "Chicago"
  ],
  "maxItems": 20
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~kalshi-weather-markets/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "cities": [
        "New York",
        "Chicago"
    ],
    "maxItems": 20
}

run = client.actor("actor-forge/kalshi-weather-markets").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
