eFinancialCareers Jobs Scraper: Finance, Banking & Fintech

Scrape finance, banking, fintech, insurance and quant jobs worldwide from eFinancialCareers' public search API: title, firm, city and country, salary range, permanent/contract, remote/hybrid, sectors, posted date, summary and full description. $0.40 per 1,000 jobs.

What it does

An eFinancialCareers scraper for finance and banking jobs, straight from its public search API. eFinancialCareers is the specialist job board for banking, asset management, fintech, insurance, accounting, compliance, risk and quant roles, with jobs in London, New York, Singapore, Hong Kong, Frankfurt, Dubai and dozens of other financial centres. Give it keywords (analyst, quant developer, compliance…) and locations with a radius, and get one clean row per job: title, firm (with logo and full group name), city, state, country and region, salary range and currency where the firm shows one (plus the salary text, e.g. Competitive), permanent, contract or temporary, full-time or part-time, remote, hybrid or in-office, sectors, posted date, the job link, eFinancialCareers' short summary and the full description. Filter by position type, hours, work arrangement and posting date, and sort by newest. Up to 100 jobs per request, so large pulls are fast. Use it for financial-services hiring intelligence, recruiting and headhunting, salary benchmarking in finance, lead lists of hiring banks and funds, and job alerts. $0.40 per 1,000 jobs, with no compute bill on top; problems return a free status row instead of failing.

Limits and honest notes

  • Responsible use: you are responsible for using the data in line with eFinancialCareers' terms and with data-protection law (GDPR, UK GDPR). This actor is not affiliated with, endorsed by or sponsored by eFinancialCareers or DHI Group.
  • It calls only the public job-search API that the eFinancialCareers website itself uses (job-search-api.efinancialcareers.com, which has no robots.txt, so RFC 9309 allows it) and never crawls www.efinancialcareers.com pages. There is no login, no cookies, no proxies and no CAPTCHA solving; it sends an honest user agent (ActorForge-eFinancialCareers), waits at least 2 s between requests and checks robots.txt before each one.
  • The API is public but undocumented, so parameter names can change; if they do, the run returns a free status row instead of failing, and the actor is updated. The API takes one value per filter.
  • Salary figures are shown only when the firm publishes them (many say Competitive). Recruiter contact details are never collected, and phone numbers and e-mail addresses are removed from descriptions.
  • If the site answers with a block, the run stops at once, keeps the jobs already delivered and adds a free status row. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap. A run with no results returns one free status row.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~efinancialcareers-jobs/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["developer"], "locations": ["London"], "maxItems": 20}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "keywords": [
    "developer"
  ],
  "locations": [
    "London"
  ],
  "maxItems": 20
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~efinancialcareers-jobs/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "keywords": [
        "developer"
    ],
    "locations": [
        "London"
    ],
    "maxItems": 20
}

run = client.actor("actor-forge/efinancialcareers-jobs").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
