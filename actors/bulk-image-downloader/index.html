Bulk Image Downloader — All Images from Any Web Page

Download every image from web pages, or a list of image URLs, in bulk. Finds img, srcset (largest size), lazy-loaded, picture, og:image, icons and CSS backgrounds. Width/height filters, duplicate removal, optional ZIP. $3 per 1,000 images. File mode downloads any file type too.

What it does

Download all images from any web page, or a list of image URLs, in bulk. Give it pages and it finds every image in the HTML: <img> tags, the largest size from srcset (one file per picture, never a thumbnail plus its hi-res twin), lazy-loaded images (data-src and friends), <picture> sources, video posters, og:image / Twitter previews, favicons, linked full-size gallery images and CSS backgrounds. Give it direct image URLs and it downloads them. Each image is saved with a direct download link, its real format (sniffed from the file), width, height, file size, SHA-256, alt text and source page. Filter by minimum width/height, file size or format, skip duplicates by content, and optionally get everything as ZIP files. Use it for website migrations and backups, building image datasets for machine learning, product-image collection for e-commerce catalogues, SEO and alt-text audits, competitor creative research, or as an image tool for AI agents. Need PDFs, ZIPs, CSVs, Office documents or media instead? Switch What to download to Any files to grab every file type from a URL list or a page's links, with type and URL-glob filters and size caps. You pay per image saved, not per URL, so 1,000 direct image links cost $3 instead of $10-$70 with the leading per-URL downloader. Filtered, duplicate and failed images are never charged.

Limits and honest notes

  • Pages are scanned as static HTML without a browser, which is fast and cheap. Images inserted only by JavaScript (infinite-scroll galleries, some single-page apps) are not found. Pass those image URLs directly instead.
  • Pages disallowed by the site's robots.txt are skipped by default (you can turn this off). If a site's robots.txt can't be fetched (HTTP 5xx or a network error, after one retry), all of that site's pages are skipped (RFC 9309), each with a free error row. Login-protected pages are not supported.
  • Files over the maximum file size (default 25 MB for images, 100 MB in file mode, up to 500 MB) are skipped; file mode also has a total size cap (default 2 GB). ZIP files are split into parts of up to 200 MB.
  • Formats: JPEG, PNG, GIF, WebP, AVIF, SVG, BMP, ICO, TIFF and HEIC, detected from the file bytes, so mislabelled files are handled correctly.
  • Download links work for the lifetime of the run's storage (Apify's default retention for your plan).
  • Only download images you have the right to use. Most images on the web are copyrighted.
  • Internal and private network addresses are always refused, including through redirects or DNS tricks.
  • Respects your run budget: set a maximum total charge and the actor stops cleanly at the cap.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~bulk-image-downloader/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"urls": ["https://en.wikipedia.org/wiki/Lighthouse"]}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "urls": [
    "https://en.wikipedia.org/wiki/Lighthouse"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~bulk-image-downloader/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "urls": [
        "https://en.wikipedia.org/wiki/Lighthouse"
    ]
}

run = client.actor("actor-forge/bulk-image-downloader").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
