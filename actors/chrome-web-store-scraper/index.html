Chrome Web Store Extensions Scraper: Users, Ratings, Versions

Scrape Chrome Web Store extensions from category pages or extension IDs: users, rating, rating count, category, website, version, manifest version, permissions, publish date, plus developer, last updated, size, languages and support links from the detail page. $1.00 per 1,000 extensions.

Run on Apify →See pricing

What it does

A Chrome Web Store scraper for extension market data, with no browser and no API key. Point it at Chrome Web Store category pages (Workflow & Planning, Shopping, Developer Tools, Privacy…) or paste extension IDs and store URLs, and get one clean row per extension: name, user count, star rating and rating count, category, the extension's website, version, manifest version (MV2/MV3), requested permissions and host permissions, first publish date and icon. Switch on detail pages (or give IDs) to add the developer (publisher) name, full description, last updated date, size, supported languages, support and privacy-policy links, minimum Chrome version and screenshots. Use it for browser-extension market research, competitor and category tracking, finding fast-growing or abandoned extensions, permission and security audits of the extensions your company allows, lead lists of extension publishers by their websites, and datasets for analysis or AI agents. $1.00 per 1,000 extensions, with no compute bill on top; unknown IDs and other problems return a free status row instead of failing.

Limits and honest notes

  • Responsible use: you are responsible for using the data in line with Google's terms and with data-protection law where you are. Developer names are public publisher names; developer e-mail addresses are never collected. This actor is not affiliated with, endorsed by or sponsored by Google or the Chrome Web Store.
  • The Chrome Web Store's robots.txt disallows its search and review pages, so there is no keyword search and no review scraping. Discovery is by category pages (about 30 extensions each) and extension IDs. robots.txt is checked before every page.
  • There is no login, no proxies and no CAPTCHA solving; it sends an honest user agent (ActorForge-ChromeWebStore) and waits at least 1.5 s between pages. Google's own cookie-consent hop for European visitors is followed automatically; no cookies are kept.
  • User counts are the store's rounded figures (e.g. 22,000,000+ shows as 22000000). Permissions come from the published manifest.
  • If the store answers with a block, the run stops at once, keeps the extensions already delivered and adds a free status row.
  • Respects your run budget: set a maximum total charge and the run stops cleanly at the cap, with nothing charged twice.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~chrome-web-store-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"categoryUrls": ["https://chromewebstore.google.com/category/extensions/productivity/workflow"], "maxItems": 20}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "categoryUrls": [
    "https://chromewebstore.google.com/category/extensions/productivity/workflow"
  ],
  "maxItems": 20
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~chrome-web-store-scraper/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "categoryUrls": [
        "https://chromewebstore.google.com/category/extensions/productivity/workflow"
    ],
    "maxItems": 20
}

run = client.actor("actor-forge/chrome-web-store-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
