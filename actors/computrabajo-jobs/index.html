Computrabajo Jobs Scraper: Latin America (MX, CO, AR, PE, CL…)

Scrape Computrabajo job offers in 18 Latin American countries (Mexico, Colombia, Argentina, Peru, Chile…) by keyword and city: company, location, salary in local currency, remote, posting date, link, optional full description. $0.50 per 1,000 jobs.

Run on Apify →See pricing

What it does

A Computrabajo scraper for Latin American jobs, in 18 countries, with no browser. Computrabajo is the largest job board in Spanish-speaking Latin America, with sites for Mexico, Colombia, Argentina, Peru, Chile, Ecuador, Venezuela, Bolivia, Costa Rica, the Dominican Republic, Guatemala, Honduras, Nicaragua, Panama, Paraguay, El Salvador, Uruguay and Puerto Rico. Pick a country, give it keywords (desarrollador, vendedor, contador…) and optional cities or states, and get one clean row per offer: title, company (or a confidential-company flag), city, region and country, salary as a number with its local currency and period (parsed from formats like $ 4.836.000,00 or 10,000.00 Q), remote / on-site / hybrid, posting date (from the "Hace 3 días" label, or exact with details), and the offer link. Turn on details for the full description, contract hours, industry and expiry date from each offer page. Filter by posting age, remote-only and salary-shown. Every keyword runs in every place. Use it for LATAM job market and salary research, recruiting and sourcing across Latin America, hiring-company lead lists, job alerts and job-board aggregation. $0.50 per 1,000 jobs, with no compute bill on top; problems return a free status row instead of failing.

Limits and honest notes

  • Responsible use: you are responsible for using the data in line with Computrabajo's terms and with the data-protection laws of each country. This actor is not affiliated with, endorsed by or sponsored by Computrabajo or Redarbor.
  • It reads only Computrabajo's public results and offer pages and checks robots.txt before every page. robots.txt disallows the site's filter parameters (salary, contract, date, distance), so those filters are applied by the actor after reading each page, never in the URL. There is no login, no cookies, no proxies and no CAPTCHA solving; it sends an honest user agent (ActorForge-Computrabajo) and waits at least 1.5 s between pages.
  • Posting dates on results pages are relative ("Hace 3 días"), so postedAt is approximate unless details are on. Salaries are shown as each employer gives them; the currency is the country's (Venezuela's is left empty because offers mix currencies).
  • Confidential offers keep the company empty. Recruiter contact details are never collected, and phone numbers and e-mail addresses are removed from descriptions.
  • If the site answers with a block or a challenge, the run stops at once, keeps the offers already delivered and adds a free status row. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap. A run with no results returns one free status row.

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "country": "co",
    "keywords": [
        "desarrollador"
    ],
    "maxItems": 20
}

run = client.actor("actor-forge/computrabajo-jobs").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
