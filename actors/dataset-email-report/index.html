Dataset Email Report — Email Results as Excel/CSV + HTML Table

Email any Apify dataset or run's results as a clean HTML table with summary stats and an Excel or CSV attachment. Attach it as an integration to any Actor or schedule; filter, sort, rename columns, only new rows. $0.01 per report sent + $0.01 per 1,000 rows.

Run on Apify →See pricing

What it does

Get any scraper's results in your inbox as a clean report, automatically. Attach this Actor as an integration to any Actor, task or schedule (set Dataset to {{resource.defaultDatasetId}}) and every finished run emails its dataset as a readable HTML table with summary stats (row counts, source run, min/average/max/sum of numeric columns) and an Excel (XLSX) and/or CSV attachment. No SMTP server, no code, no API keys: delivery goes through Apify's own Send Email Actor (apify/send-mail) on your account. Choose and rename columns (dot paths like price.value work), sort, filter (equals, contains, greater than, is empty…), cap the rows, and turn on only new rows so a daily job emails only the listings, jobs, leads or prices that were not in an earlier report. Only send when there are rows (on by default) means empty runs cost nothing and send nothing. Every value from the data is HTML-escaped, recipients are capped at 10 per report, and attachments over 5 MB fall back to a link to the dataset in Apify Console. Want to see it first? Leave recipients empty and the rendered report is saved to the run's key-value store as a preview. $0.01 per report sent + $0.01 per 1,000 rows; skipped and failed sends are free.

Limits and honest notes

  • Delivery uses Apify's free Send Email Actor (apify/send-mail), which runs as a short child run on your own account (a fraction of a cent of platform usage at 256 MB). Its rules apply: on the Apify free plan it only delivers to the email address of your Apify account; paid plans can send to other addresses. A failed send is reported in the summary row and the run fails, and nothing is charged.
  • Up to 10 recipients per report. This Actor is for reports to yourself and your team; Apify bans promotional or spam email through its mailer.
  • Attachments: up to 5 MB in total (before encoding). If the files are larger, the biggest set that fits is attached and the rest is saved in the run's key-value store; the email links to the dataset in Apify Console instead. Excel and CSV files are always saved in the key-value store too.
  • The email table shows up to 200 rows and the first 12 columns; the attachment holds every report row (up to 50,000) and column. Long cell text is shortened in the email only.
  • Datasets: the run can read only the dataset passed in the Dataset field. As an integration, set Dataset to {{resource.defaultDatasetId}} in the integration form; the automatic integration payload alone does not give this run read access to the triggering run's dataset (the run then fails with a 'no read access' message and nothing is charged). The payload is still used for the source run's ID, status and finish time in the report.
  • Sorting holds up to 100,000 matching rows in memory; without sorting, reading stops as soon as Max rows rows are found. Raise the memory for very wide rows.
  • Only new rows remembers row identities (53-bit hashes, newest 5 million) in the key-value store 'af-dataset-email-report-history' on your account, per history name, and only after a successful send. Delete that record to start over.
  • CSV text that a spreadsheet would treat as a formula (starting with =, +, @ or a non-numeric -) gets a leading apostrophe. Excel files store text as plain text, never as formulas.
  • When there is nothing to send (no rows, no source, invalid input) the run still succeeds with one free summary row explaining why.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~dataset-email-report/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"subject": "Daily results: {{rowCount}} rows — {{date}}", "attachmentFormat": "xlsx", "sampleRows": [{"product": "Trail Running Shoe X2", "price": 129.99, "currency": "USD", "inStock": true, "url": "https://shop.example.com/p/trail-x2"}, {"product": "Road Running Shoe R1", "price": 89.5, "currency": "USD", "inStock": false, "url": "https://shop.example.com/p/road-r1"}, {"product": "Hiking Boot H7", "price": 159, "currency": "USD", "inStock": true, "url": "https://shop.example.com/p/hike-h7"}]}'

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
