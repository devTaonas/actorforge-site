SmartRecruiters Jobs Scraper: All Companies or One Board

Search public SmartRecruiters jobs across every company (or one company's board) by keyword and remote/hybrid/on-site: title, company and logo, city, region, country, workplace type, posted date and apply link. Newest first, multi-query. $1.50 per 1,000 jobs.

What it does

A SmartRecruiters jobs scraper that searches every company at once. Thousands of employers (Visa, Bosch, AECOM, IKEA franchises, hospital groups, retailers) post their jobs on SmartRecruiters, and its public job search covers all of them. Give it keywords (engineer, nurse, sales manager…), optionally companies and remote / hybrid / on-site, and get one clean row per posting, newest first: title, company with logo and careers page, city, region, country, workplace type, posted date and the job link. Every keyword runs for every company and workplace type, so one run builds a broad daily feed; filter by country and posting age. Use it for hiring alerts and job feeds, tracking new roles at target accounts, recruiting market intelligence and job-board aggregation. $1.50 per 1,000 jobs, with no compute bill on top; problems return a free status row instead of failing.

Limits and honest notes

  • Responsible use: you are responsible for using the data in line with SmartRecruiters' terms, each employer's terms and data-protection law (GDPR, CCPA). This actor is not affiliated with, endorsed by or sponsored by SmartRecruiters or the employers listed.
  • It uses only the public search endpoint of jobs.smartrecruiters.com (the one its job search page calls; that host has no robots.txt, so RFC 9309 allows it). It never calls api.smartrecruiters.com, whose robots.txt disallows crawlers. No login, no cookies, no proxies and no CAPTCHA solving; it sends an honest user agent (ActorForge-SmartRecruiters) and waits at least 1 s between requests.
  • Each search returns at most the 100 newest matching postings (the site's own limit; there is no paging). For more coverage, add keywords, companies and workplace types: every combination is its own search. This makes the actor best for frequent alert-style runs rather than full historical dumps.
  • The search gives no description, department or salary; follow the job link for those. No recruiter details are collected.
  • If the site answers with a block, the run stops at once, keeps the jobs already delivered and adds a free status row. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap. A run with no results returns one free status row.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~smartrecruiters-jobs/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["engineer"], "maxItems": 20}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "keywords": [
    "engineer"
  ],
  "maxItems": 20
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~smartrecruiters-jobs/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "keywords": [
        "engineer"
    ],
    "maxItems": 20
}

run = client.actor("actor-forge/smartrecruiters-jobs").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
