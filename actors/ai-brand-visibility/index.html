AI Brand Visibility Tracker - GPT, Gemini & Claude Mentions

Check how AI models answer your buyers' questions: is your brand mentioned, at what rank and list position, with what sentiment, which competitors appear, which sites are cited, and your share of voice per model. GPT, Gemini, Claude, Llama or Sonar via OpenRouter. $0.01 per check + tokens.

What it does

See how AI assistants talk about your brand (generative engine optimisation, GEO / AEO). Give it your brand, your competitors and the questions your buyers ask (*"best note-taking app for teams"*, *"cheapest CRM for startups"*, *"Notion vs Confluence"*), pick the AI models, and for every prompt × model you get: is your brand mentioned, how often, its rank (order of first mention among you and your competitors), its position in the recommendation list, the sentiment around it, which competitors were named, which websites were cited (web mode), whether your own site was cited, plus a per-model share of voice and mention rate. Models come through Apify's official OpenRouter actor: OpenAI GPT (the model family behind ChatGPT), Google Gemini, Anthropic Claude, Meta Llama, Mistral, DeepSeek and Perplexity Sonar. Use it to track AI search visibility over time (schedule it weekly), benchmark against competitors, find which sources AI models trust, and measure the effect of content and PR on LLM answers. Answers are analysed deterministically (no second AI call), so the analysis itself costs nothing. $0.01 per check plus the AI tokens at cost (a memory-mode check with the default models costs about $0.0003 in tokens on a paid plan).

Limits and honest notes

  • API answers are not identical to the consumer apps: ChatGPT, Gemini and Perplexity's apps add their own system prompts, memory, personalisation and live search. This actor asks the underlying models through their APIs (via OpenRouter), the same way for every brand, which makes it a consistent benchmark rather than a screenshot of one user's chat. It does not scrape or log in to chatgpt.com, gemini.google.com or perplexity.ai.
  • AI tokens and web-search fees are a second, separate charge on your own Apify account, made by apify/openrouter at OpenRouter's rates (10× on the Apify free plan). They are not part of this actor's pay-per-event price and are not limited by the run's maximum total charge: use maxLlmCostUsd (default $0.10) to cap them.
  • Answers vary from run to run (temperature 0.7, like a normal chat). Use samplesPerPrompt and repeat runs over time for trends; single answers are anecdotes.
  • Mentions are matched as whole words (case-insensitive) on the brand, its aliases and competitor names; generic brand names (for example "Bear" or "Linear") may match ordinary words. Sentiment is a simple word-list heuristic over the sentences that name the brand.
  • In memory mode models only cite URLs they write into the answer (often none); web mode reports the sources the search returned.
  • If a model id is unknown or the AI service rejects the request, that check gets a free status row; with a single model the run stops early and still finishes as SUCCEEDED.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~ai-brand-visibility/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"brand": "Notion", "competitors": ["Evernote", "Obsidian"], "prompts": ["best note-taking app for teams"], "models": ["google/gemini-2.5-flash-lite"], "maxOutputTokens": 500, "maxLlmCostUsd": 0.005}'

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "brand": "Notion",
    "competitors": [
        "Evernote",
        "Obsidian"
    ],
    "prompts": [
        "best note-taking app for teams"
    ],
    "models": [
        "google/gemini-2.5-flash-lite"
    ],
    "maxOutputTokens": 500,
    "maxLlmCostUsd": 0.005
}

run = client.actor("actor-forge/ai-brand-visibility").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
