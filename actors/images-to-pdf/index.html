Images to PDF Converter — Merge JPG & PNG into One PDF

Merge JPG, PNG, HEIC, WebP and other images from URLs into one PDF (or one PDF per image): A4, Letter or fit-to-image pages, margins, auto-rotation, compression. Download link per PDF. $0.022 for a 10-image PDF.

Run on Apify →See pricing

What it does

Merge images into a PDF online, in bulk. Paste links to JPG, PNG, HEIC (iPhone), WebP, AVIF, GIF, TIFF or SVG images and get one PDF with one image per page, in the order of your list, with a direct download link. Pick A4, US Letter or fit-to-image pages; A4 and Letter pages turn portrait or landscape to match each image, which is centred inside your margin. Photos are rotated upright from their EXIF orientation and compressed as JPEG at the quality you choose, and screenshots, scans and graphics in PNG, GIF, TIFF or SVG are embedded losslessly so text stays sharp. Want one PDF per image instead (JPG to PDF, PNG to PDF)? Switch the mode. Optionally resize large photos first to keep the PDF small. Use it to turn photographed receipts, invoices, delivery notes and forms into a single PDF for accounting, insurance claims or archives, to bundle product or property photos into a PDF catalogue, to make a printable PDF from a gallery, or as an images-to-PDF step for Make, n8n, Zapier and AI agents. Pricing: $0.002 per page image + $0.002 per PDF, so a 10-image PDF costs $0.022 with no compute bill on top (other images-to-PDF actors charge up to $0.055 for the same 10 images). Failed images are never charged and simply leave no page.

Limits and honest notes

  • Input: direct image URLs, in page order. Images that fail to download or decode are reported as error rows (not charged) and leave no page; the PDF keeps the order of the rest.
  • Each image can be up to 25 MB and 50 megapixels; sources over 25 MP add large-image ($0.002) and HEIC photos add heic-decoded ($0.001). Animated GIFs use the first frame.
  • One image per page. 'Fit image' pages are the image size at 96 dpi; on A4/Letter pages images are scaled to fill the page inside the margin (small images are enlarged to fit).
  • Photos are re-encoded as baseline JPEG at your quality setting (rotated upright, sRGB); PNG, GIF, TIFF and SVG are embedded as lossless PNG. Transparent areas in JPEG pages become the background colour.
  • A merged PDF holds up to about 128 MB of images at 1 GB memory (more with more memory); bigger merges are split into name.pdf, name-part-2.pdf, and so on, and each part is one pdf-created.
  • No OCR: the PDF contains images, not searchable text.
  • Download links work for the lifetime of the run's storage (Apify's default retention for your plan). ZIP files are split into parts of up to 200 MB.
  • Internal and private network addresses are always refused, including through redirects or DNS tricks. Only convert images you have the right to use.
  • Respects your run budget: set a maximum total charge and the actor stops cleanly at the cap.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~images-to-pdf/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"imageUrls": ["https://upload.wikimedia.org/wikipedia/commons/3/3f/JPEG_example_flower.jpg", "https://www.gstatic.com/webp/gallery3/1.png", "https://www.gstatic.com/webp/gallery/2.jpg"]}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "imageUrls": [
    "https://upload.wikimedia.org/wikipedia/commons/3/3f/JPEG_example_flower.jpg",
    "https://www.gstatic.com/webp/gallery3/1.png",
    "https://www.gstatic.com/webp/gallery/2.jpg"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~images-to-pdf/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "imageUrls": [
        "https://upload.wikimedia.org/wikipedia/commons/3/3f/JPEG_example_flower.jpg",
        "https://www.gstatic.com/webp/gallery3/1.png",
        "https://www.gstatic.com/webp/gallery/2.jpg"
    ]
}

run = client.actor("actor-forge/images-to-pdf").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
