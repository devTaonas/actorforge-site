What it does

Find out what any website is built with, for a whole list at once. Paste domains or URLs and get one row per site with every detected technology: CMS (WordPress, Shopify, Webflow, Wix…), ecommerce platform and plugins, JavaScript frameworks (React, Next.js, Vue, Nuxt, Angular, Svelte), analytics and tag managers, advertising pixels, CDN, hosting and PaaS (Cloudflare, Vercel, AWS), web server and language (Nginx, PHP), payment processors, live chat, marketing automation and more. Each detection includes the version where the page reveals it, a confidence score, its categories, the vendor website, an icon URL and the CPE identifier for vulnerability matching. A per-site category summary ({"CMS": ["WordPress"], "CDN": ["Cloudflare"]}) makes filtering in a spreadsheet easy. Detection uses the open webappanalyzer fingerprints (the community continuation of Wappalyzer's, 7,600+ technologies) matched against the response headers, cookies, HTML, meta tags, script URLs, inline scripts and the static DOM from one HTTP request per site, with no browser, so it is fast and cheap. Use it for lead generation and sales prospecting (find Shopify stores, sites on a competitor's platform, companies running HubSpot), market research, competitor analysis, CRM enrichment, agency audits and security inventory (CPE + version). $1.50 per 1,000 sites with only the negligible platform start fee: cheaper than other paid tech-stack lookups. Sites that can't be fetched, aren't HTML or show a bot-protection challenge are returned with a reason and not charged.

Limits and honest notes

  • HTTP only, no browser: one request to each site's page (redirects followed). Technologies that only reveal themselves after JavaScript runs (Wappalyzer's js global-variable and dom property checks, XHR calls, CSS) are found only when the server-rendered page shows them. Inline code that creates a known global (e.g. window.__remixContext =, <script id="__NEXT_DATA__">) is recognised; scripts loaded later are not fetched. Single-page apps that render everything client-side show fewer technologies than a browser-based scan.
  • Bot protection: sites behind a Cloudflare, DataDome, PerimeterX, Imperva, Akamai, AWS WAF or Vercel challenge (and plain 401/403/429 refusals) are returned as status: blocked with blockedBy and the CDN/WAF technologies visible on the challenge page. They are not charged. No proxies or CAPTCHA solving are used.
  • Only the given page is analysed (bare domains → the homepage). Detections on other pages of the site (checkout, blog) are not included unless you pass those URLs.
  • Fingerprints are the open-source webappanalyzer set (GPL-3.0, github.com/enthec/webappanalyzer, pinned commit, 7,600+ technologies), plus a few HTTP-visible additions for Next.js. Detection quality matches theirs; occasional false positives from generic patterns are possible. Confidence below 50 is hidden by default (minConfidence).
  • With includeDns, MX/TXT/NS/SOA/CNAME records add email providers, DNS hosts and SaaS domain-verification records (e.g. a stripe-verification TXT record ⇒ Stripe). These describe the company's tooling, not necessarily the website.
  • Pages larger than 3 MB are analysed from their first 3 MB. Each site has a 20-second time limit; at most 10 sites are fetched at once and at most 2 per host. Internal and private network addresses are refused.
  • Respects your run budget: set a maximum total charge and the run stops cleanly at the cap, with every delivered site charged exactly once.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~tech-stack-detector/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"urls": ["wordpress.org", "https://www.allbirds.com", "nextjs.org", "techcrunch.com"]}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "urls": [
    "wordpress.org",
    "https://www.allbirds.com",
    "nextjs.org",
    "techcrunch.com"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~tech-stack-detector/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "urls": [
        "wordpress.org",
        "https://www.allbirds.com",
        "nextjs.org",
        "techcrunch.com"
    ]
}

run = client.actor("actor-forge/tech-stack-detector").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
