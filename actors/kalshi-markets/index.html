Kalshi Markets Scraper — Prediction Market Prices & Volume

Kalshi prediction-market data from the official public API: yes/no bid and ask, last price, 24h change, volume, open interest, close time, event, series and category, plus optional order book and rules. Search, categories, series or tickers. $1 per 1,000 markets.

Run on Apify →See pricing

What it does

Kalshi prediction-market data in clean rows, from Kalshi's own public Trade API. Find markets by search terms, Kalshi categories (Economics, Politics, Financials, Crypto, Climate and Weather, Sports...), series tickers, event tickers or kalshi.com URLs, or exact market tickers, or list open markets across the exchange. Every row is one market: the question and outcome, yes and no bid and ask (in dollars, which is the implied probability), last price, 24-hour price change and spread, top-of-book sizes, total and 24-hour volume, open interest, open, close and expected expiration times, status and result, plus the parent event, series and category. Optionally add the resolution rules and an order book snapshot of yes and no bids. For weather markets, give city names to get every daily high/low temperature and rain bracket for that city, with the bracket bounds as numbers, the unit, the settlement station and, optionally, the live airport observation (METAR) at that station. Filter by status (open, closed, settled), close-date window, minimum 24h volume or open interest, and skip auto-generated combo markets. Use it for forecasting research, macro and Fed-rate tracking, weather and election dashboards, alerts, academic studies and comparing Kalshi with Polymarket or polls. $1 per 1,000 markets, with no compute bill on top; problems return a free status row instead of failing.

Limits and honest notes

  • Responsible use: this is market data only. Nothing in it is financial, investment or betting advice, and prices are not predictions by ActorForge. Event-contract trading is restricted in some places; follow your local law and Kalshi's terms. This actor is not affiliated with, endorsed by or sponsored by Kalshi.
  • It reads only Kalshi's documented public market-data endpoints (api.elections.kalshi.com/trade-api/v2: markets, events, order books), with no key, no login, no account and no trading, at most four requests per second with an honest user agent (ActorForge-Kalshi).
  • Kalshi has no keyword-search endpoint, so Search and Categories scan Kalshi's event list (200 events per request, about 85 requests for every open event) and match event titles and tickers; set "Event pages to scan" lower for quicker partial searches. With no filters the run lists open markets newest first.
  • Prices are the latest values Kalshi publishes and can move within seconds; check the scrapedAt time. Kalshi's order book lists bids only: a yes bid at X is the same as a no ask at 1 − X.
  • If Kalshi refuses a request or rate-limits the run, the run stops, keeps the markets already delivered and adds a free status row. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap. Unknown tickers and empty searches return a free status row.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~kalshi-markets/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"searchTerms": ["fed"], "maxItems": 10}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "searchTerms": [
    "fed"
  ],
  "maxItems": 10
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~kalshi-markets/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "searchTerms": [
        "fed"
    ],
    "maxItems": 10
}

run = client.actor("actor-forge/kalshi-markets").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
