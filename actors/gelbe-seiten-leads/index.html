Gelbe Seiten Scraper: German Business Leads, Phones & Websites

Scrape German business listings from Gelbe Seiten by trade and city: company name, category, street, postcode, district, business phone, website, role e-mail (info@, kontakt@), rating, reviews, opening status and listing link. No browser. $0.60 per 1,000 businesses.

What it does

A Gelbe Seiten scraper for German B2B leads, with no browser and no proxy bill. Gelbe Seiten (the German Yellow Pages) lists millions of local businesses, from electricians and tax advisers to dentists, restaurants and law firms. Give it trades (elektriker, steuerberater, zahnarzt…) and cities or postcodes, and get one clean row per business: company name, main category, street, postcode, city and district, distance from the city centre, the business phone number, the website, a role e-mail (info@, kontakt@…) where listed, star rating and review count, today's opening status, a short self-description, the logo and the Gelbe Seiten listing link. Every trade runs in every city, past the first 50 results using the site's own "Mehr anzeigen" requests. Use it for German lead generation and cold outreach lists, local SEO and market mapping, territory planning for field sales, competitor research and CRM enrichment. $0.60 per 1,000 businesses, with no compute bill on top; problems return a free status row instead of failing.

Limits and honest notes

  • Responsible use: you are responsible for using the data in line with Gelbe Seiten's terms, the GDPR and German rules on advertising (UWG §7: cold calls and e-mails to businesses need at least presumed consent). This actor is not affiliated with, endorsed by or sponsored by Gelbe Seiten or its publishers.
  • It reads only the public /branchen/ listing pages and the page's own "Mehr anzeigen" endpoint (/ajaxsuche), which robots.txt allows; it never uses /suche, which robots.txt disallows. There is no login, no cookies, no proxies and no CAPTCHA solving; it sends an honest user agent (ActorForge-GelbeSeiten) and waits at least 1.5 s between requests.
  • Business data only: the listed business phone, the website and role mailboxes (info@, kontakt@…). Personal e-mail addresses are dropped, and no owner or employee details are collected. Sole traders appear under their trading name, as listed.
  • Results-list data only: no full opening hours, services or reviews text from the listing page.
  • If the site answers with a block or a challenge, the run stops at once, keeps the businesses already delivered and adds a free status row. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap. A run with no results returns one free status row.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~gelbe-seiten-leads/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"trades": ["elektriker"], "cities": ["berlin"], "maxItems": 20}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "trades": [
    "elektriker"
  ],
  "cities": [
    "berlin"
  ],
  "maxItems": 20
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~gelbe-seiten-leads/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "trades": [
        "elektriker"
    ],
    "cities": [
        "berlin"
    ],
    "maxItems": 20
}

run = client.actor("actor-forge/gelbe-seiten-leads").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
