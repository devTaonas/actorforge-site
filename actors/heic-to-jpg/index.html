HEIC to JPG Converter — iPhone Photos to JPEG in Bulk

Convert HEIC/HEIF iPhone photos to JPG in bulk from URLs: upright, true colours (Display P3 to sRGB), EXIF and GPS location stripped, optional resize and ZIP download. Also WebP, PNG or PDF. $3 per 1,000 HEIC photos.

What it does

Convert HEIC photos from iPhones to JPG in bulk. Paste links to .heic / .heif files and get every photo back as a JPEG with a direct download link, or all of them in one ZIP file. Photos come out upright exactly as the phone shows them, the primary image of burst and multi-image files is used, and iPhone Display P3 colours are converted to standard sRGB so they look right in every browser, email client and CMS. EXIF metadata including GPS location is stripped by default, so converted photos never reveal where they were taken; each row still tells you whether the original had GPS. Optionally resize (max width/height), set a target file size in KB, or convert to WebP, PNG or PDF instead (merge a batch of phone photos into one PDF for receipts, reports or claims). Use it when Windows, Shopify, WordPress, marketplaces or web forms refuse HEIC uploads, to prepare iPhone photos for e-commerce listings, real-estate and insurance documentation, or as a HEIC conversion step for automation pipelines and AI agents. It decodes HEIC with the open-source libheif library, so there is no per-run photo limit and no app to install. $3 per 1,000 HEIC photos ($0.002 conversion + $0.001 HEIC decode) with no compute bill on top, versus $10 per 1,000 with the leading HEIC converter. Failed and unsupported files are never charged.

Limits and honest notes

  • Input: direct links to the files (e.g. from cloud storage, a CMS, or a public URL). Files behind a login are not supported; iCloud shared-album pages are web pages, not file links.
  • Each photo can be up to 25 MB and 50 megapixels. 12-24 MP iPhone photos cost $0.003; 48 MP HEIC photos also pay large-image ($0.002) and need 2 GB of memory or more.
  • The primary image of each HEIC file is converted: bursts and multi-image files give one JPEG, Live Photo video is ignored, and depth maps and HDR gain maps are not used (HDR photos come out as standard-range JPEG).
  • Colours: Display P3 photos are converted to sRGB (or keep their P3 profile if you turn metadata stripping off). EXIF (date taken, camera) from HEIC files is not copied to the JPEG; each row reports whether the original had EXIF and GPS.
  • A target file size is a best effort: if an image can't reach it at minimum quality after one resize, it is delivered as small as possible and the row says targetMet: false.
  • Download links work for the lifetime of the run's storage (Apify's default retention for your plan). ZIP files are split into parts of up to 200 MB.
  • Internal and private network addresses are always refused, including through redirects or DNS tricks. Only convert images you have the right to use.
  • Respects your run budget: set a maximum total charge and the actor stops cleanly at the cap.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~heic-to-jpg/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"imageUrls": ["https://raw.githubusercontent.com/strukturag/libheif/master/examples/example.heic", "https://raw.githubusercontent.com/tigranbs/test-heic-images/master/image3.heic"]}'

  }

const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "imageUrls": [
        "https://raw.githubusercontent.com/strukturag/libheif/master/examples/example.heic",
        "https://raw.githubusercontent.com/tigranbs/test-heic-images/master/image3.heic"
    ]
}

run = client.actor("actor-forge/heic-to-jpg").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
