Spotify Stream Counts: Play Counts, Monthly Listeners, Charts

Total and daily Spotify streams for every song of an artist, artist stream totals, monthly listeners and rank, top artists by listeners, and daily or weekly country charts with streams and movement. From kworb.net public pages. No Spotify login. $1.20 per 1,000 rows.

Run on Apify →See pricing

What it does

Spotify play counts without the Spotify API. Give it artists (Spotify URL, ID or name) and get every song with its total and daily Spotify streams, plus an artist summary: total streams, daily streams, lead/solo/feature splits, track count, and monthly listeners with global rank. Add country charts (global, us, gb, br...) for the daily or weekly chart with position, movement, days on chart, peak, streams, 7-day streams and all-time totals, or rank the top artists by monthly listeners with daily change and peak. Use it for music marketing and A&R research, label and catalogue valuation, playlist pitching, tracking a release day by day, fan sites and dashboards. The data comes from kworb.net, a long-running public music-statistics site that compiles Spotify figures daily. $1.20 per 1,000 rows, with no compute bill on top; problems return a free status row instead of failing.

Limits and honest notes

  • Responsible use: stream counts are compiled by kworb.net from Spotify's public figures; please credit kworb.net when you publish them. This actor is not affiliated with, endorsed by or sponsored by Spotify or kworb.net.
  • It reads only kworb.net's public HTML pages (robots.txt allows everything), at most one page per second with an honest user agent (ActorForge-SpotifyStreams). There is no login, no cookies and no proxies, and it never contacts Spotify.
  • Coverage is what kworb.net tracks: artists that have charted on Spotify. Figures update once a day, not in real time. Artist names are matched only against the top 5,000 artists by monthly listeners; paste the Spotify artist URL for anyone else.
  • An artist summary needs the monthly-listeners pages (2,500 artists per page), which are loaded once per run when needed.
  • If kworb.net refuses a request, the run stops, keeps the rows already delivered and adds a free status row. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap. Unknown artists and charts return a free status row.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~spotify-stream-counts/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"artists": ["https://open.spotify.com/artist/06HL4z0CvFAxyc27GXpf02"], "maxSongsPerArtist": 20}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "artists": [
    "https://open.spotify.com/artist/06HL4z0CvFAxyc27GXpf02"
  ],
  "maxSongsPerArtist": 20
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~spotify-stream-counts/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "artists": [
        "https://open.spotify.com/artist/06HL4z0CvFAxyc27GXpf02"
    ],
    "maxSongsPerArtist": 20
}

run = client.actor("actor-forge/spotify-stream-counts").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
