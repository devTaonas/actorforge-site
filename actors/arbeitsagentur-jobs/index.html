Arbeitsagentur Jobs Scraper: Germany's Federal Job Board

Search Germany's Bundesagentur für Arbeit Jobsuche (about 1M ads) by keyword, place and radius: title, employer, address and coordinates, salary range, full-/part-time, home office, contract, start and posting dates, optional full description. No browser. $0.50 per 1,000 jobs.

What it does

An Arbeitsagentur scraper for German job ads, straight from the official Jobsuche API. The Bundesagentur für Arbeit runs Germany's largest job board, with about a million ads from employers of every size. Give it job titles or skills (Entwickler, Pflegefachkraft, Elektriker…) and places (city, postcode or region, with a radius), and get one clean row per ad: title, employer, postcode, city, region and map coordinates, salary range and period where the employer gives one, full-time / part-time / mini-job, home office, permanent or fixed-term contract, occupation, suitable-for-career-changers flag, start date, first published and last changed dates, the arbeitsagentur.de link and the employer's own application link, and optionally the full job description. Filter by offer type (jobs, apprenticeships, internships, self-employment), working time, posting age and temporary-work agencies. Every keyword is searched in every place, so one run covers a whole job family across many cities. Use it for German job market research, recruiting and sourcing, salary benchmarking, lead lists of hiring companies, job alerts and job-board aggregation. $0.50 per 1,000 jobs, with no compute bill on top; problems return a free status row instead of failing.

Limits and honest notes

  • Responsible use: you are responsible for using the data in line with the Bundesagentur für Arbeit's terms and with data-protection law (GDPR). This actor is not affiliated with, endorsed by or sponsored by the Bundesagentur für Arbeit.
  • It uses the public JSON API that the arbeitsagentur.de Jobsuche web app itself calls (search v6, details v4), with the app's public key. No login, no cookies, no proxies and no CAPTCHA solving; it sends an honest user agent (ActorForge-Arbeitsagentur) and waits at least 0.4 s between requests. rest.arbeitsagentur.de answers robots.txt with HTTP 403, which RFC 9309 treats as "no robots.txt" (allowed); robots.txt is still checked on every request.
  • The API is public but undocumented, and older versions (v4 and v5 search) were retired in 2026. If the search moves, the run returns a free status row instead of failing, and the actor is updated.
  • Contact persons are never output, and phone numbers and e-mail addresses are removed from descriptions. Employer names and locations are business data.
  • The API returns at most 100 pages (10,000 ads) per search: split very broad searches by place or keyword.
  • If the site answers with a block, the run stops at once, keeps the jobs already delivered and adds a free status row. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap. A run with no results returns one free status row.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~arbeitsagentur-jobs/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["Entwickler"], "locations": ["Berlin"], "maxItems": 20}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "keywords": [
    "Entwickler"
  ],
  "locations": [
    "Berlin"
  ],
  "maxItems": 20
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~arbeitsagentur-jobs/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "keywords": [
        "Entwickler"
    ],
    "locations": [
        "Berlin"
    ],
    "maxItems": 20
}

run = client.actor("actor-forge/arbeitsagentur-jobs").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
