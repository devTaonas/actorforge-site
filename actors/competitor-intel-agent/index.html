Competitor Intelligence AI Agent — Pricing, Plans & Changes

Enter competitor domains; the AI agent reads their pricing, product, customers, integrations, changelog and careers pages and returns plans, prices, free trials, positioning, customers, launches and open roles with sources, a comparison matrix and pricing-change alerts. $0.01/site.

Run on Apify →See pricing

What it does

Structured competitor intelligence from your competitors' own websites, with pricing-change alerts. Enter a list of competitor domains (and optionally your own). For each site the AI agent reads the home page, finds the pricing, features/product, customers, integrations, changelog/blog and careers pages from the site's own navigation (falling back to /pricing and /plans), reads them as static HTML and turns them into one fixed-schema profile with one AI call: tagline and positioning, target segments, key features, pricing model, every pricing plan (name, price, billing period, unit, limits, key features), free trial and its length, free plan, entry price per month, named customers, integrations and their count, recent launches from the changelog or blog, and open roles (an exact count from the public Greenhouse, Lever or Ashby job board when the site links one). Every section carries the source URL it came from, checked against the pages actually read, so you can verify any value in one click.

With 2 or more sites you get a free comparison matrix row (cheapest paid entry, free plans, free trials, contact-sales-only pricing, most integrations, who is hiring most). Add a monitor name and schedule the actor weekly: each run compares with the last one and flags price changes, plans added or removed, free trial or free plan added or removed, pricing-model changes, new launches, tagline changes and hiring changes (snapshots are kept in your own key-value store). Use it for competitive analysis, pricing research, SaaS market maps, battlecards, sales enablement, investor and M&A research, and pricing-page monitoring. $0.01 per site analysed plus the AI tokens at cost.

Limits and honest notes

  • AI tokens are a second, separate charge on your own Apify account, made by apify/openrouter at OpenRouter's rates (10× on the Apify free plan). They are not part of this actor's pay-per-event price and are not limited by the run's maximum total charge: use maxLlmCostUsd (default $0.20) to cap them. Each row's llmCostUsd is an estimate; your Apify billing page is authoritative.
  • Only the company's own public marketing pages are read: no third-party review sites, no traffic estimates, no ad libraries, no logins. Pages behind logins, CAPTCHAs or bot walls are not read, and the actor does not try to get around them (no proxies, no browser fingerprints).
  • No browser: pages are fetched as static HTML. Pricing pages that only render with JavaScript are skipped with a note (and a site that is entirely a JavaScript app shell gets a free status row). Prices shown only after a currency or monthly/annual toggle may be read in the page's default state only.
  • Pages are found from the site's own links (navigation and footer) by their usual paths (/pricing, /plans, /features, /customers, /integrations, /changelog, /careers…). Unusual page names may be missed: the row lists pagesMissing. Long pages are cut to the site's token budget (pagesAnalyzed shows truncated: true).
  • AI models can make mistakes. The model is told to use only what is on the pages and to return null when something is absent, and every source URL is checked against the pages actually read, but verify important figures. Change tracking compares structured values (plan names, prices, trial and free-plan flags), so a re-worded plan name can show up as one plan removed and one added.
  • Open roles are exact only when the site links a public Greenhouse, Lever or Ashby job board; otherwise they are counted from the careers page and may be missing when jobs load with JavaScript.
  • robots.txt is respected (RFC 9309) and requests identify themselves honestly as ActorForge-CompetitorIntel. Internal and private network addresses are refused at every redirect hop.
  • Page text is treated as data: the model is told to ignore instructions inside pages (prompt-injection defence), but no defence is perfect.
  • If the AI service rejects the request (no credit, rate limit, unknown model id, outage), the run stops with one free status row "llm-unavailable" explaining why, and still finishes as SUCCEEDED.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~competitor-intel-agent/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"competitors": ["usefathom.com"], "maxPagesPerSite": 3, "maxLlmCostUsd": 0.03, "maxInputTokensPerSite": 5000}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "competitors": [
    "usefathom.com"
  ],
  "maxPagesPerSite": 3,
  "maxLlmCostUsd": 0.03,
  "maxInputTokensPerSite": 5000
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~competitor-intel-agent/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "competitors": [
        "usefathom.com"
    ],
    "maxPagesPerSite": 3,
    "maxLlmCostUsd": 0.03,
    "maxInputTokensPerSite": 5000
}

run = client.actor("actor-forge/competitor-intel-agent").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
