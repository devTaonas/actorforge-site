What it does

What is trending in China rarely looks the same on every platform. A story can top Weibo's hot search while Douyin is focused on a sports result and Baidu on a consumer scandal. Watching all of them means juggling five Chinese-language sites with different layouts and badges.

This actor captures the live hot lists of Weibo hot search (微博热搜), Douyin hot list (抖音热榜), Baidu hot search (百度热搜), Toutiao hot board (头条热榜) and Bilibili hot words (B站热搜) in one run, using the platforms' own public hot-list data. Every topic comes back in the same shape regardless of platform: rank, title, heat score, label, category and link. Ads and pinned or government slots are excluded, so rank is the organic position.

It is built for China brand monitoring, market research, news and trend detection, social listening and cross-border e-commerce product discovery, and as a real-time context source for AI agents. Topics cost $2 per 1,000, so all five boards at 50 topics each is $0.50 a run.

How it works

  1. You choose which boards to capture in platforms; the default is all five.
  2. Each board's live public hot list is fetched and normalised into the same row format.
  3. Ads are removed and pinned or government slots on Weibo, Douyin, Baidu and Toutiao are excluded, so ranks are organic.
  4. The optional keywords filter keeps only topics whose title or description contains one of your words, and filtered-out topics are not charged.
  5. If one platform is temporarily unavailable, it is skipped and not charged while the other boards are still delivered.

Limits and honest notes

  • Topics are returned in their original language (mostly Simplified Chinese). Titles are not machine-translated, so pass them to your own translator or LLM if needed.
  • Each board holds roughly 50 topics at a time. maxTopicsPerPlatform above the board size returns what the board has.
  • Weibo ads are removed and the pinned/government slots on Weibo, Douyin, Baidu and Toutiao are excluded, so rank is the organic position (1 = top).
  • heatScore is each platform's own popularity metric. Compare ranks across platforms, not raw heat values.
  • label is the platform's own badge: English for Douyin and Baidu (new, hot…), Weibo's own characters (新/热/沸/爆), Toutiao's own tags (hot, new…), and null on Bilibili.
  • Topics, ranks and heat only. No user accounts, profiles or personal data are collected.
  • If one platform is temporarily unavailable it is skipped and never charged; the other boards are still delivered.
  • Respects your run budget: set a maximum total charge and the actor stops cleanly at the cap.

FAQ

Which Chinese platforms' trending lists are included?

Weibo hot search, Douyin hot list, Baidu hot search, Toutiao hot board and Bilibili hot words. You can select any subset with platforms.

Can I compare heat scores across Weibo, Douyin and Baidu?

Not directly. heatScore is each platform's own popularity metric, so values are not on the same scale. Compare ranks across platforms and use heat only within one board.

How many trending topics does each board return?

Each board holds roughly 50 topics at a time. maxTopicsPerPlatform defaults to 50 and accepts up to 100, but a value above the board's size simply returns what the board has.

Are the trending topics translated into English?

No. Titles come back in their original language, mostly Simplified Chinese. Pass them to your own translator or LLM if you need English.

How much does hourly monitoring of China trends cost?

Topics are $0.002 each. Weibo's top 10 every hour for a month is about 7,200 topics, or $14.40; all five boards at 50 topics in a single run is $0.50.

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "platforms": [
        "weibo",
        "douyin",
        "baidu",
        "toutiao",
        "bilibili"
    ],
    "maxTopicsPerPlatform": 30,
    "keywords": []
}

run = client.actor("actor-forge/china-trending-topics").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
