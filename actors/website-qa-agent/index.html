Website Q&A AI Agent — Ask Any Site, Get Cited Answers

Ask questions about many websites ("Do they offer SSO?", "Is there a free trial?") and get a grounded answer per site with verified quotes and source URLs. Bulk vendor due diligence & lead qualification. $0.01 per verified answer; not-found is free; AI tokens at cost.

Run on Apify →See pricing

What it does

Ask the same questions about hundreds of websites and get a grounded answer for each, with the exact quote and the page it came from. Give it a list of websites (home pages or bare domains like *stripe.com*) and plain-English questions such as *"Do they offer SSO / SAML?"*, *"What does the Pro plan cost per month?"*, *"Is there a free trial?"*, *"Are they SOC 2 certified?"*, *"Do they ship to Canada?"* or *"Do they integrate with Salesforce?"*. For every website × question you get one row: a short answer, found true/false, a confidence level, verbatim evidence quotes and the source URLs. Every quote is checked against the site's own text, so you can see at a glance which answers are backed by the website and which are not.

This is a question-answering agent, not a scraper you configure: for each site it reads the start page, the sitemap and the menu links, picks the few pages most likely to answer your questions (pricing, security/trust, FAQ, about, integrations…), splits them into passages, finds the best passages for each question and asks a fast, cheap AI model (default Google Gemini 2.5 Flash Lite; any OpenRouter model works: GPT-4o mini, GPT-4.1 nano, Gemini 2.5 Flash, Claude, Llama…) to answer only from those passages. Pages are read once per site, however many questions you ask.

Limits and honest notes

  • AI tokens are a second, separate charge on your own Apify account, made by apify/openrouter at OpenRouter's rates (10× on the Apify free plan). They are not part of this actor's pay-per-event price and are not limited by the run's maximum total charge: use maxLlmCostUsd (default $0.25) to cap them. Each row's llmCostUsd is an estimate from the usage OpenRouter reports; your Apify billing page is authoritative.
  • Answers come only from the pages that were read (maxPagesPerSite, default 8, chosen by URL, link text and sitemap). If the answer sits on a page that wasn't picked, you get found: false. Raise maxPagesPerSite, or start from a more specific URL (e.g. the docs or trust-center home), for better recall.
  • found: false means "not stated on the pages read", not "the company definitely doesn't do this". Treat it as unknown.
  • No browser: pages are fetched as static HTML. Sites that render their content with JavaScript only return a free "no-readable-pages" row. Pages behind logins, CAPTCHAs or bot walls are not supported, and the actor does not try to get around them (no proxies, no browser fingerprints). PDFs are not read.
  • robots.txt is respected by default (RFC 9309), and requests identify themselves honestly as ActorForge-WebsiteQA. Internal and private network addresses are refused at every redirect hop.
  • AI models can make mistakes. Every quote is checked against the site text: answers without a verified quote are marked grounded: false, capped at low confidence and not charged, but always read the evidence for important decisions.
  • Site text is treated as data: the model is told to ignore instructions inside pages (prompt-injection defence), but no defence is perfect.
  • Personal data: by default the model is told not to return private individuals' personal contact details, and personal-looking email addresses in answers and quotes are replaced (role mailboxes like info@ and sales@ are kept). Only switch allowPersonalData on if you have a lawful basis.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~website-qa-agent/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"startUrls": ["https://apify.com"], "questions": ["Does Apify have a free plan?"], "maxPagesPerSite": 3, "maxInputTokens": 2000}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "startUrls": [
    "https://apify.com"
  ],
  "questions": [
    "Does Apify have a free plan?"
  ],
  "maxPagesPerSite": 3,
  "maxInputTokens": 2000
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~website-qa-agent/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "startUrls": [
        "https://apify.com"
    ],
    "questions": [
        "Does Apify have a free plan?"
    ],
    "maxPagesPerSite": 3,
    "maxInputTokens": 2000
}

run = client.actor("actor-forge/website-qa-agent").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
