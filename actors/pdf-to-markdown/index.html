PDF to Markdown Converter — LLM-Ready Text & RAG Chunks

Convert PDF URLs to clean, LLM-ready Markdown: headings, paragraphs and lists rebuilt from the layout, running headers and page numbers removed, plus plain text, per-page content, RAG chunks and metadata. Finds PDFs linked from web pages. $3 per 1,000 PDFs + $0.20 per 1,000 pages.

What it does

Turn PDFs into clean, LLM-ready Markdown. Paste PDF links (or a web page that links to PDFs) and get one row per PDF. The document structure is rebuilt from its layout: headings (from font sizes, section numbering and the PDF's bookmarks), paragraphs re-joined across line and page breaks with hyphenation undone, bullet and numbered lists, and tables of contents. Running headers, footers and page numbers are removed, and so is rotated margin text. Each row also has title, author, subject, keywords, language, creation and modification dates, page count and word count, plus optional plain text, per-page content, or ready-to-embed RAG chunks that carry their heading path. Use it to feed RAG pipelines and vector databases, build chatbot knowledge bases from manuals, research papers, reports, regulations and policies, give AI agents a PDF-reading tool, or bulk-extract text from document archives. Simple pricing: $3 per 1,000 PDFs + $0.20 per 1,000 pages, so a 10-page PDF costs $0.005, with no compute bill on top. Scanned pages without text, failed downloads, invalid or locked files and duplicates are never charged.

Limits and honest notes

  • Text is read from the PDF's text layer. Scanned PDFs (images of pages) have no text layer: they are reported and not charged. For those, use our OCR to Text actor (apify.com/actor-forge/ocr-to-text).
  • Tables come out as lines of text in reading order, not as Markdown tables. Images and figures are skipped. Mathematical formulas come out as their plain characters.
  • Headings are inferred from the layout. Font sizes, section numbers such as "3.1", and the PDF's bookmarks all count, but bold text at body size without numbering stays a paragraph.
  • PDFs up to 100 MB and up to 5,000 pages each (1,000 by default). Password-protected PDFs need the password input.
  • Web pages in the input are scanned for links to .pdf files (one level deep, robots.txt respected). If a site's robots.txt can't be fetched (HTTP 5xx or a network error, after one retry), the PDFs linked on that site are skipped (RFC 9309) and the page gets a free row saying why. Pages behind a login are not supported.
  • Respects your run budget: set a maximum total charge and conversion stops cleanly at the cap, with no PDF charged twice.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~pdf-to-markdown/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"urls": ["https://arxiv.org/pdf/1706.03762"]}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "urls": [
    "https://arxiv.org/pdf/1706.03762"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~pdf-to-markdown/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "urls": [
        "https://arxiv.org/pdf/1706.03762"
    ]
}

run = client.actor("actor-forge/pdf-to-markdown").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
