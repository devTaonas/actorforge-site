Weather Forecast API — Hourly & 10-Day, Any City Worldwide

Hourly and daily weather forecasts for any city or coordinates worldwide, up to 10 days: temperature, feels-like, precipitation, wind, humidity, cloud, pressure, UV and weather symbol, from MET Norway (commercial use OK). Metric or imperial. $1 per 1,000 locations.

Run on Apify →See pricing

What it does

Weather forecasts for any city or point on Earth, in clean rows, from the Norwegian Meteorological Institute's free public API (MET Norway, the data behind Yr), licensed CC BY 4.0, so commercial use is fine. Type city names ("London", "Paris, France", "Portland, OR") or latitude/longitude pairs; names are matched offline against about 49,000 places, so there is no geocoding quota. Get up to 10 days: hourly steps for about the first 2.5 days, then 6-hourly, each with temperature, feels-like, min/max, dew point, humidity, precipitation, wind speed and direction, cloud cover, fog, pressure, clear-sky UV index and a weather symbol (clearsky_day, rain, heavyrainandthunder...). Each place also gets daily summaries in its own time zone: min and max temperature, total precipitation, max wind, mean cloud and humidity, and the day's symbol. Pick the layout: one row per location (current conditions plus everything nested), one row per day, or one row per time step for spreadsheets, in metric or imperial units. Use it for logistics and field-work planning, events, agriculture, energy and demand models, travel apps, dashboards and alerts. From $1 per 1,000 locations, with no API key and no compute bill on top; bad place names return a free status row explaining why.

Limits and honest notes

  • Forecasts come from MET Norway's public Locationforecast 2.0 API (api.met.no). It is a global numerical forecast, usually very good, but no forecast is a guarantee. Do not use it for safety-of-life decisions; follow your national weather service's warnings. This actor is not made by, affiliated with or endorsed by MET Norway or Yr.
  • Attribution: the weather data is CC BY 4.0 (MET Norway). Every row carries an attribution field; keep it when you republish the data. City names and coordinates come from GeoNames (CC BY 4.0).
  • One request per distinct location per run, at most 10 requests per second, with an identifying user agent, as MET's terms ask. Coordinates are rounded to 4 decimals (about 11 m).
  • Time steps are hourly for about the first 60 hours, then every 6 hours. Precipitation is the amount over each step. In the daily summary a 6-hour step counts toward the day it starts in. "UV" is MET's clear-sky UV index (the UV if there were no clouds). Gusts and precipitation probability are filled only where MET provides them (mainly the Nordic region); elsewhere they are empty.
  • Place names: the biggest place with that name wins (e.g. "Paris" is Paris, France); add a country or US state ("Paris, TX") to choose another. The alternatives field lists other matches. Places under 5,000 people need latitude and longitude. Unknown names and invalid coordinates return a free status row. Respects your run budget: set a maximum total charge and the run stops cleanly at the cap.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~weather-forecast-global/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"locations": ["London", "New York", "Tokyo"]}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "locations": [
    "London",
    "New York",
    "Tokyo"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~weather-forecast-global/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "locations": [
        "London",
        "New York",
        "Tokyo"
    ]
}

run = client.actor("actor-forge/weather-forecast-global").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
