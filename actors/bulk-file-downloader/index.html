Bulk File Downloader — URL List to Storage or ZIP

Download any files in bulk from URL lists or the file links on a web page: PDF, ZIP, CSV, XLSX, DOCX, MP3, MP4 and more. Public download links, real type from the bytes, size, SHA-256, type/glob filters, dedupe, size caps, optional ZIP. $2 per 1,000 files + $0.001 per 10 MB.

What it does

Download any files in bulk, from a list of URLs or from the links on a web page. Paste direct links to PDFs, ZIP archives, CSV/XLSX exports, Word documents, MP3s, videos or any other file, or give it pages (a reports archive, a dataset index, a podcast page) and it follows every file link it finds: <a href> links, audio/video sources, embeds and objects. Each file is stored in the run's key-value store with a public download link, and its real type is detected from the file bytes (magic numbers: PDF, ZIP, DOCX/XLSX/PPTX, ODF, EPUB, legacy Office, GZIP/7z/RAR/TAR, MP3/WAV/FLAC/OGG, MP4/MOV/WebM, images, SQLite, Parquet, JSON/CSV/XML…), with the server's content type as a fallback. Every row carries the MIME type, size, SHA-256, source URL, page and link text. Filter by file type or URL glob (*.pdf, /reports/**), skip duplicates by content, cap the size per file (default 100 MB) and in total, and optionally get everything as ZIP files. Use it for archiving public documents, collecting datasets for analysis or machine learning, backing up website downloads, mirroring podcast episodes, or as a file-fetching tool for AI agents and automations. Pricing follows the real cost of moving data: $0.002 per file plus $0.001 per started 10 MB, so 1,000 small files cost about $3. Broken links, web pages, filtered types, oversized files and duplicates are never charged.

Limits and honest notes

  • Pages are scanned as static HTML without a browser, which is fast and cheap. Links added only by JavaScript are not found; pass those file URLs directly instead.
  • Pages disallowed by the site's robots.txt are skipped by default (you can turn this off). If a site's robots.txt can't be fetched (HTTP 5xx or a network error, after one retry), all of that site's pages are skipped (RFC 9309), each with a free error row. Direct file URLs you list are always fetched. Login-protected files are not supported.
  • Files over the per-file cap (default 100 MB, up to 500 MB) are aborted early and not charged. The total size cap (default 2 GB) stops the run cleanly; give the run 2-4 GB of memory for many large files. ZIP files are split into parts of up to 200 MB.
  • Without a type or glob filter, page links are followed only when they end in a common document, archive, data or media extension (images are left out; add jpg or png to File types to include them).
  • Download links work for the lifetime of the run's storage (Apify's default retention for your plan).
  • Only download files you have the right to use.
  • Internal and private network addresses are always refused, including through redirects or DNS tricks.
  • Respects your run budget: set a maximum total charge and the actor stops cleanly at the cap.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~bulk-file-downloader/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"urls": ["https://raw.githubusercontent.com/py-pdf/sample-files/main/001-trivial/minimal-document.pdf", "https://www.w3schools.com/html/horse.mp3", "https://people.sc.fsu.edu/~jburkardt/data/csv/addresses.csv"]}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "urls": [
    "https://raw.githubusercontent.com/py-pdf/sample-files/main/001-trivial/minimal-document.pdf",
    "https://www.w3schools.com/html/horse.mp3",
    "https://people.sc.fsu.edu/~jburkardt/data/csv/addresses.csv"
  ]
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~bulk-file-downloader/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "urls": [
        "https://raw.githubusercontent.com/py-pdf/sample-files/main/001-trivial/minimal-document.pdf",
        "https://www.w3schools.com/html/horse.mp3",
        "https://people.sc.fsu.edu/~jburkardt/data/csv/addresses.csv"
    ]
}

run = client.actor("actor-forge/bulk-file-downloader").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
