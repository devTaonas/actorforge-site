YC Startup Jobs — Y Combinator Company Job Listings

Open jobs at about 730 Y Combinator startups, read from their public Ashby, Greenhouse and Lever job boards. Filter by YC batch (W24, S25…), industry, keyword, location and remote. Every row carries the YC batch, team size and HQ. $1.50 per 1,000 jobs.

Run on Apify →See pricing

What it does

Every open role at Y Combinator startups, in one dataset. This actor scans about 730 YC companies that hire through Ashby, Greenhouse or Lever and reads their public job-board feeds (the same JSON their careers pages load). You get one clean row per job with the company's YC batch, team size, HQ and industry already attached, so you can sort by batch, size or sector without a second lookup.

- Filter by YC batch: W24, S25, X25 (spring), F24 (fall), "Winter 2024", or a bare year such as 2024 for every batch that year. - Filter by job: keywords on title, department and team, excluded words, location or country, remote only, posted within N days. - Salary where the company publishes it in structured form (common on Ashby).

Limits and honest notes

  • Covers the YC companies in the built-in index that hire through Ashby, Greenhouse or Lever (about 730, verified 2026-10-18). YC companies on Workday, other ATS or a custom careers page are not included; use Career Site Jobs with their careers URL instead.
  • YC batch, team size and HQ are taken from the index snapshot, not refreshed on every run. Job data is live on every run.
  • Lists only currently open, publicly listed jobs, exactly what each company's careers page shows. Recruiter names and application-form fields are never returned.
  • Salary is only returned where the employer publishes it in structured form; otherwise the salary fields are null.
  • Keyword and location filters are case-insensitive substring matches. A full scan of every YC company with no filters reads about 730 job boards and takes a few minutes.
  • Respects your run budget: set a maximum total charge and the run stops cleanly at the cap.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~yc-startup-jobs/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"ycBatches": ["2024", "2025"], "keywords": ["engineer"], "remoteOnly": true, "maxJobs": 20}'

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "ycBatches": [
        "2024",
        "2025"
    ],
    "keywords": [
        "engineer"
    ],
    "remoteOnly": True,
    "maxJobs": 20
}

run = client.actor("actor-forge/yc-startup-jobs").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
