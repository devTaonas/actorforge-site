YouTube Search Results by Keyword — Ranked Videos With Full Stats

Type a keyword and get YouTube's own ranked results, each enriched with views, likes, comments, duration and tags, through the official API.

Run on Apify →See pricing

What it does

Seeing what ranks on YouTube for a keyword usually means searching by hand and copying titles, with no view counts or durations in view. This actor runs YouTube search by keyword through the official YouTube Data API v3 using your own free key, and returns one row per result in YouTube's search order, with searchRank recorded for each.

Search results on their own only carry basic snippet data, so every result is enriched with a videos.list lookup: title, description, channel, published date, duration in seconds, views, likes, comment count, tags, category, default language, thumbnails, live status, made-for-kids flag and a Shorts flag. You can apply YouTube's own filters: order (relevance, date, view count, rating or title), publishedAfter and publishedBefore, regionCode, relevanceLanguage and videoDuration. Setting searchType to channel returns channel rows instead.

It is aimed at YouTube keyword research, trend and competitor tracking, influencer discovery and content gap analysis. Results cost $0.30 per 1,000 plus $0.002 per page of 50, roughly $0.34 per 1,000 all in.

How it works

  1. Each query in searchQueries is sent to search.list with your filters, 50 results per page, up to maxResultsPerQuery.
  2. The video IDs on each page are looked up with videos.list so every row carries full stats, duration and tags.
  3. Rows keep the query and the result's rank, and duplicates across queries are removed.
  4. The run log shows a quota estimate before any call; each page costs 100 search units plus 1 for the video details.
  5. Search pages that return no rows are not charged, and a quotaExceeded error stops the run cleanly with the rows already delivered.

Limits and honest notes

  • You need your own free YouTube Data API v3 key (see the 4-step guide above). Without one the run stops at once with instructions, and nothing is charged.
  • Search is quota-hungry: each search.list page of up to 50 results costs 100 of your 10,000 free daily units (plus 1 unit for the video details), so one free key gives about 5,000 search results a day (about 100 pages). Quota resets at midnight Pacific Time. A quotaExceeded error stops the run cleanly; rows already delivered are kept, and the failed call is free.
  • About 500 results per query at most. That is YouTube's own cap on search depth, so maxResultsPerQuery goes up to 500. For more coverage, split a topic into several narrower queries or date ranges.
  • Results and their order are YouTube's own search ranking for an API request (no personalisation, no ads). Results may differ slightly from what a logged-in user sees on youtube.com.
  • Like counts that the creator hides come back as null. There are no dislike counts (removed by YouTube), no revenue and no watch time.
  • isShort is a heuristic (3 minutes or less and not live), because the API does not flag Shorts. Use the video length filter short to get only videos under 4 minutes.
  • Free rows (type error) cover failed queries and invalid inputs. Search pages that return no rows are not charged.
  • You must refresh or delete stored API data within 30 days (YouTube Developer Policies III.E.4). We keep nothing after the run.
  • The run's spend limit is respected: each page of rows is charged before it is delivered, and the run stops cleanly at the cap.

FAQ

How many YouTube search results can I get per keyword?

YouTube caps search depth at about 500 results per query, so maxResultsPerQuery goes up to 500. For more coverage, split a topic into narrower queries or separate date ranges with publishedAfter and publishedBefore.

Why does YouTube search use so much API quota?

YouTube charges 100 quota units for each search.list page of up to 50 results, plus 1 unit here for the video details. With 10,000 free units a day, one key gives about 100 pages, or roughly 5,000 results.

Will the results match what I see on youtube.com?

They are YouTube's own search ranking for an API request, with no personalisation and no ads. They can differ slightly from what a logged-in user sees in the browser.

How do I search for YouTube Shorts only?

The API does not flag Shorts. Set videoDuration to short to get videos under 4 minutes, and use the isShort heuristic in each row (3 minutes or less and not live) to narrow further.

What does a search run cost?

Results cost $0.0003 each and each page of up to 50 results that returned rows costs $0.002. So 50 results cost $0.017, and 1,000 results cost about $0.34.
