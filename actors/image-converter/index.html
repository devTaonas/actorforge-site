Image Converter & Compressor — Resize, WebP/AVIF, Bulk

Convert and compress images in bulk: JPEG, PNG, HEIC (iPhone), GIF, SVG, TIFF to WebP, AVIF, JPEG, PNG or PDF. Resize, hit a target file size, strip EXIF and GPS, merge images into one PDF, optional ZIP. $2 per 1,000 images.

What it does

Convert images to WebP, AVIF, JPEG or PNG, compress them and resize them in bulk. Paste a list of image URLs (JPEG, PNG, WebP, AVIF, HEIC/HEIF iPhone photos, GIF, TIFF or SVG; the format is read from the file itself) and get each one back converted, compressed and optionally resized, with a direct download link and a row showing the file size before and after and the % saved. Set a max width/height (fit inside, crop to cover, or pad to contain), a quality level, or a target file size in KB and the actor lowers the quality, then the dimensions, until each image fits. EXIF metadata, including GPS location, is stripped by default after photos are rotated upright, so you never publish where a photo was taken; each row still tells you whether the original had EXIF or GPS. PNG compression uses palette quantisation, the technique behind TinyPNG, so it works as a bulk TinyPNG alternative with no 20-image limit. Animated GIFs stay animated as WebP, SVGs are rasterised at the size you ask for, and you can download everything as ZIP files. Choose PDF as the output to merge images into one PDF (fit-to-image, A4 or Letter pages, with margins) or make one PDF per image. Use it to compress images for website speed and Core Web Vitals, convert product photos for an e-commerce catalogue, generate thumbnails, prepare images for a CMS or CDN migration, or as an image tool for AI agents and automation pipelines. $2 per 1,000 images with no compute bill on top, versus $10 per 1,000 with the leading converter. Failed and unsupported images are never charged.

Limits and honest notes

  • Input: direct image URLs. To convert every image on a web page, collect the links first with our Bulk Image Downloader and pass them in.
  • Each source image can be up to 25 MB and 50 megapixels (animations up to 100 MP across all frames). Larger files are reported as errors and not charged.
  • Sources over 25 megapixels cost a second large-image event ($0.002), because they take far more compute. Everyday photos (12-24 MP phone pictures) are not affected.
  • Supported inputs: JPEG, PNG, WebP, AVIF, HEIC/HEIF, GIF (incl. animated), TIFF and SVG. BMP and ICO are not supported and are reported as errors (not charged).
  • HEIC/HEIF (iPhone photos): the primary image of each file is converted (bursts and multi-image files give one image), upright as the phone displays it, with Display P3 colours converted to standard sRGB. EXIF from HEIC files is not copied to the output even with metadata stripping off (the colour profile is). HEIC decoding is slower, so it adds a heic-decoded event ($0.001); for 48 MP HEIC photos run with 2 GB of memory or more.
  • PDF output: one image per page, in the order of your list. Photos are embedded as JPEG at your quality setting, PNG/GIF/TIFF/SVG as lossless PNG so text stays sharp. Merged PDFs larger than about 128 MB (at 1 GB memory) are split into parts. PDF output ignores the ZIP option when merging.
  • Animation is kept for GIF/WebP to WebP; AVIF, JPEG and PNG output use the first frame. SVGs are rasterised; references to external files or URLs inside an SVG are never loaded.
  • Images are never enlarged beyond their original size. Converting to JPEG fills transparent areas with the background colour (default white).
  • A target file size is a best effort: if an image can't reach it at minimum quality after one resize, it is delivered as small as possible and the row says targetMet: false.
  • Stripping metadata also converts colours to standard sRGB. Turn stripping off to keep EXIF, ICC colour profiles, XMP and IPTC.
  • Download links work for the lifetime of the run's storage (Apify's default retention for your plan). ZIP files are split into parts of up to 200 MB.
  • Internal and private network addresses are always refused, including through redirects or DNS tricks. Only convert images you have the right to use.
  • Respects your run budget: set a maximum total charge and the actor stops cleanly at the cap.

import os

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
