Contractor Leads — Plumbers, Electricians, HVAC & Roofers

Plumbers, electricians, HVAC companies, roofers, painters, landscapers, cleaners and other home-service businesses in any city worldwide, with phone, website, email where published, address and a normalised trade field. Open data. $0.003 per city + $1 per 1,000 businesses.

Run on Apify →See pricing

What it does

Find plumbers, electricians, HVAC companies, roofers and other trades in any city, with their business phone numbers. Type a city or draw a radius, pick trades, and get one row per business with phone (E.164), website, business email where published, full address and coordinates, plus a normalised trade field (Plumbing, Electrical, HVAC, Roofing & exteriors, General contractor & remodeling, Painting, Landscaping & garden, Cleaning, Pest control, Locksmith & security, Solar and more) worked out from the business's own categories, so mixed lists sort cleanly.

Made for companies that sell to the trades: field-service and scheduling software, lead-gen and marketing agencies, suppliers and distributors, insurers and franchise developers. Unlike directory scrapers limited to the US, it works in any country Overture covers.

Limits and honest notes

  • No reviews, ratings, licence or insurance numbers (open data). trade is derived from Overture categories; "Other home service" covers the rarer ones.
  • Works worldwide: any city, a radius around a point, or a bounding box (one metro area per run).
  • Open data, not Google: no reviews, ratings, review counts, opening hours, photos, popular times or price levels. The Google Maps link in each row is a plain search URL built from the name and address; nothing is fetched from Google.
  • Freshness follows Overture's monthly releases. The newest release is found automatically (or pin one with release). operatingStatus is often empty, so a closed business can still appear until a source drops it; minConfidence (default 0.5) filters most stale records.
  • One query per run, up to 1.5 x 1.5 degrees (about one metro area). For a region or country, run once per city. A city query typically reads 15-45 MB of public GeoParquet in 5-15 seconds at 1 GB memory.
  • City names resolve offline from a built-in list of 32,000+ cities (Overture divisions, OpenStreetMap-based); smaller towns are looked up in Overture's divisions data and need a region or country ("Dripping Springs, TX"). No external geocoder is called.
  • The run's spend limit is respected: the area query is reserved first, places are charged before delivery, and the run stops cleanly at the limit.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~home-services-contractor-leads/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"location": "Dallas, TX", "categories": ["plumbing", "electrician", "hvac_service", "roofing"], "maxPlaces": 50}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "location": "Dallas, TX",
  "categories": [
    "plumbing",
    "electrician",
    "hvac_service",

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~home-services-contractor-leads/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "location": "Dallas, TX",
    "categories": [
        "plumbing",
        "electrician",
        "hvac_service",
        "roofing"
    ],
    "maxPlaces": 50
}

run = client.actor("actor-forge/home-services-contractor-leads").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
