Website Crawler — Site Content to Markdown for AI & RAG

Crawl a whole website and extract the main content of every page as clean Markdown and plain text for chatbots, RAG knowledge bases and AI agents. Sitemap-aware, skips menus, footers and thin pages. Static HTML, no browser. Flat $1 per 1,000 pages, no compute bill.

Run on Apify →See pricing

What it does

Crawl a whole website into your chatbot, RAG pipeline or AI knowledge base. Give it a start URL and it crawls the site: it follows links and the sitemap, stays on the site and under the path you gave, and returns one row per page with the main content only, as Markdown and plain text. Menus, sidebars, footers, cookie banners and buttons are removed with Firefox Reader View's algorithm, and thin pages under 20 words (tag lists, empty archives, pagination) are skipped and not charged. Each row also has the title, description, language, author, publish date, canonical URL and word count. Typical jobs: build a chatbot or customer-support knowledge base from your docs and help center, load a site into a vector database (Pinecone, Qdrant, Weaviate) for RAG, power site search, collect LLM training data, or give AI agents a whole documentation site as context. Defaults are set for whole-site crawls: up to 200 pages, sitemap on, Markdown plus text. It fetches static HTML with no browser, which is fast and cheap and works for most documentation, blogs, help centers and marketing sites; pages that only render with JavaScript are detected, reported and not charged. Flat, predictable pricing: $1 per 1,000 pages, with no compute bill on top. Duplicate pages, non-HTML files, JavaScript-only pages and pages blocked by robots.txt are never charged.

Limits and honest notes

  • Static HTML only: pages are fetched without a browser. Single-page apps whose content is rendered only by JavaScript are detected, reported and not charged; use a browser-based crawler for those.
  • The crawl stays on the start URL's host and under its path, unless you set include globs. To cover subdomains or both the www and bare domain, add include globs such as https://*.example.com/**.
  • Pages disallowed by robots.txt are skipped by default. If a site's robots.txt can't be fetched (HTTP 5xx or a network error, after one retry), the whole site is skipped (RFC 9309) and its start URL is reported as skipped, not charged. Login-protected content is not supported. Some sites block datacenter IPs; those start URLs are reported with their HTTP error and not charged.
  • Duplicates are removed by normalised URL (tracking parameters and fragments ignored), redirect target and identical content, and are never charged twice.
  • Very large sites: results stream as they are crawled, and runs resume after a platform migration without re-charging pages already delivered.
  • Respects your run budget: set a maximum total charge and the crawl stops cleanly at the cap.
  • This is the Website to Markdown crawler with defaults for whole-site knowledge-base crawls (Markdown and text, 200 pages, 20-word minimum). Every option can be changed per run.

Use it from code

Run the actor through the Apify API with the input above.

cURL

curl -X POST "https://api.apify.com/v2/acts/actor-forge~website-crawler/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"startUrls": ["https://docs.apify.com/platform/actors"], "maxPages": 5, "maxDepth": 1}'

JavaScript (Node.js)

// Node.js 18+ (built-in fetch). Set APIFY_TOKEN in your environment.
const input = {
  "startUrls": [
    "https://docs.apify.com/platform/actors"
  ],
  "maxPages": 5,
  "maxDepth": 1
};

const res = await fetch(
  "https://api.apify.com/v2/acts/actor-forge~website-crawler/run-sync-get-dataset-items",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.APIFY_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(input),
  }
);
const items = await res.json();
console.log(items.length, items[0]);

Python

# pip install apify-client   (set APIFY_TOKEN in your environment)
import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run_input = {
    "startUrls": [
        "https://docs.apify.com/platform/actors"
    ],
    "maxPages": 5,
    "maxDepth": 1
}

run = client.actor("actor-forge/website-crawler").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.
