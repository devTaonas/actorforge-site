What is ActorForge?

An Apify actor is a cloud program you run from the Apify console, on a schedule, or through an API call. You give it an input (URLs, keywords, a city, a company number) and it returns a dataset you can download as JSON, CSV or Excel, or pipe into Make, n8n, Zapier or your own code.

ActorForge actors are priced per event: you pay for each row or page delivered, at the price printed on the listing, with no monthly subscription. Failed lookups are not charged, and every actor stops cleanly when it reaches the maximum charge you set for a run. Every actor is checked by an automated nightly self-test.
