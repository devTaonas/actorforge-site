How to Export YouTube Comments to CSV (Official API, With Replies)

Uses YouTube Comments Scraper (Official API) — No Usernames

Short answer: Create a free YouTube Data API v3 key, paste it and your video URLs into YouTube Comments Scraper, choose newest or top comments and whether to include replies, then download the dataset as CSV. Each comment is one row with text, likes, reply count and dates; replies point to their parent with parentId.

YouTube has no export button for comments, not even for your own videos. The usual options are a browser extension, a web tool with a small free cap, or the YouTube Data API, which is reliable and free up to a daily quota but means writing code to page through comment threads and fetch long reply chains.

YouTube Comments Scraper is that API client, already written. You bring your own key, so the data comes from YouTube's official API under your own quota: nothing is scraped from youtube.com and there are no proxies or logins. The commenter's display name, channel id and avatar are removed from every row, which is what you want for sentiment analysis, product feedback and LLM datasets, where the text matters and the identities do not.

This guide goes from an empty Google Cloud project to a CSV of comments and replies, and covers quota, sorting, keyword filtering and analysis. ActorForge is not affiliated with YouTube or Google; the official API guide covers the other YouTube modes.

Step by step

  1. Create a free YouTube Data API v3 key

    In the Google Cloud Console, create a project, open APIs & Services → Library, enable YouTube Data API v3, then go to Credentials → Create credentials → API key. The key starts with AIza. No billing account is needed. If you restrict the key, allow YouTube Data API v3 only and do not add IP or referrer restrictions, because Apify runs on changing IPs. Paste the key into the actor's API key field; it is a secret input, stored encrypted and never written to the output.

  2. Add the videos

    Put the videos in videoUrls. Watch URLs, youtu.be links, Shorts, live and embed URLs and bare 11-character video ids all work, and duplicates are removed. Comments on Shorts are fetched the same way as on regular videos.

  3. Choose order, volume and replies

    commentOrder is time (newest first) by default; use relevance for YouTube's top comments. maxCommentsPerVideo caps top-level comments per video (100 by default). Turn on includeReplies to get replies as their own rows, limited by maxRepliesPerComment (20 by default) so one huge thread cannot use up the run. Use searchTerms to have YouTube return only comments containing a word, for example a product name.

    {
  "apiKey": "AIza...your key...",
  "mode": "comments",
  "videoUrls": [
    "https://www.youtube.com/watch?v=jNQXAC9IVRw",
    "https://youtu.be/dQw4w9WgXcQ"
  ],
  "commentOrder": "relevance",
  "maxCommentsPerVideo": 500,
  "includeReplies": true,
  "maxRepliesPerComment": 10
}

  4. Download the comments as CSV

    When the run finishes, open the dataset and export it as CSV, Excel or JSON, or use the API. Pick the columns you need with fields so the spreadsheet stays tidy. Comment text can contain line breaks and commas; the CSV export quotes them correctly, but open the file with an import dialog (Data → From Text/CSV in Excel) rather than double-clicking if accented characters look wrong.

  -o youtube_comments.csv

  5. Analyse the comments

    Load the rows into pandas. Top-level comments have isReply false; replies carry the parentId of the comment they answer, so you can rebuild threads. A first pass that works well: most-liked comments, comment volume per day after publication, and a keyword count for the themes you care about. For sentiment or topic labelling, send the text column to an LLM in batches.

    import os
import pandas as pd
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run = client.actor("actor-forge/youtube-comments-api").call(run_input={
    "apiKey": os.environ["YOUTUBE_API_KEY"],
    "mode": "comments",
    "videoUrls": ["https://www.youtube.com/watch?v=jNQXAC9IVRw"],
    "maxCommentsPerVideo": 1000,
    "includeReplies": True,
})
df = pd.DataFrame(client.dataset(run["defaultDatasetId"]).list_items().items)
df = df[df["type"] == "comment"]

top = df[~df["isReply"]].nlargest(10, "likeCount")[["likeCount", "text"]]
print(top.to_string())

df["day"] = pd.to_datetime(df["publishedAt"]).dt.date
print(df.groupby("day").size().tail(14))
df.to_csv("comments.csv", index=False)

The run-sync-get-dataset-items endpoint waits for the run (up to 5 minutes) and returns the dataset rows directly. For longer runs, start the run asynchronously and read the dataset when it finishes, as the Python example does. Replace APIFY_TOKEN with your own token from the Apify console.

Tips and pitfalls

  • Quota: comment threads cost 1 unit per 100 comments, so the free 10,000 units a day cover roughly a million comments. Quota resets at midnight Pacific Time.
  • maxCommentsPerVideo counts top-level comments only. Replies are capped separately, per thread, by maxRepliesPerComment (0 turns them off).
  • For a channel-wide study, first get the channel's video ids with the YouTube Channel Scraper, then feed them to this actor.
  • Comment counts on the video page include replies and may lag; expect your row count to differ from the number YouTube shows.

Limitations

  • You need your own YouTube Data API v3 key. Without one the run stops immediately with instructions and nothing is charged.
  • Author names, channel ids, avatars and channel URLs are never returned. If you need a list of commenters, this actor will not give you one.
  • The API does not say whether a comment is pinned or hearted, and like counts the creator hides come back as null.
  • If your key runs out of quota (403 quotaExceeded), the run stops cleanly, keeps the rows already delivered and does not charge for the failed call.

Responsible use

YouTube's Developer Policies require stored API data to be refreshed or deleted at least every 30 days. Set a retention period on the datasets or re-run to refresh them. By using the actor you also accept the YouTube Terms of Service.

Comment text can still contain personal details that people typed into it. If you publish or share a dataset, quote in aggregate and remove anything that identifies a private person.

FAQ

Do I need to pay Google for the API key?

No. A key from a Google Cloud project without billing gets 10,000 free quota units a day, which is about a million comments with this actor.

Can I export comments from someone else's video?

Yes, for any public video with comments turned on. The API returns public comments only; held-for-review and deleted comments are not included.

Why are there no usernames in the export?

They are stripped on purpose so the dataset is about what was said, not who said it. That keeps analysis and sharing simpler under privacy rules.

Does it work for YouTube Shorts?

Yes. Paste the Shorts URL or its video id; comments are fetched the same way.
